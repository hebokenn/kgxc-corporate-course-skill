本次更新面向 DSH 课程工作台：先展示当前作品和下一步，素材取舍与检查记录默认折叠。缺数据时明确标注，避免猜测进度或验收。小样页改为“制作现场”，已保存的实际合成画面、分段配音与样段在左侧查看/试听，每 3 秒更新一次；新产物不会自动播放或抢走当前选择。Qwen3/Azure 分段配音及现有渲染器已接入，其它制作路径需登记产物清单。保存不等于完成或验收。内部审阅与设置按需展开，必要确认保留。

工作台的关键确认统一走右侧问答。讲稿、三段有声小样或成片准备好且满足检查条件时，AI 在右侧主动提问；你在左侧看当前版本和状态，在右侧作出选择。左侧的确认记录可悬停或聚焦查看，也可以点击固定，不提交或改变选择。关闭问答、暂不确认和版本更新不会冒充批准；原件对照和实际听审仍按当前课的分工与证据核对。分镜内部审阅、主体与后期制作检查不额外增加人工确认。

制作中要查看另一门课时，从课程列表打开它自己的对话；不会改绑当前课。没有关联对话的课程，需要明确选择用独立对话打开。只读查看与开工分开，小样保留视频、字幕和检查记录，完整工程包在成片阶段生成。

「资料」内的课程素材库把上传原件和使用记录放在一起。可按文件检查门店实拍、制度文档等素材，查看原件、核实未使用原因，以及在有当前视频证据时跳到对应时间。讲稿参考和画面实际使用分开显示；没有当前证据的素材标为尚未核实，不把文件存在或分镜计划当成已出镜。

工作台优先显示当前可查看的作品和下一步。顶部只负责导航；「画面与配音」和「后期与成片」分开浏览。只有当前版本的原生问答实际出现在右侧时，左侧才提示用户确认，其他制作和检查记录集中收起。

第一次做课，可以从「上传资料」或「描述课程」直接开始，右侧会准备一条生成可编辑大纲的草稿，不替你发送。看小样或成片时可点「这里要改」，把对应视频版本、片段和播放位置带到右侧；写好具体意见再提交。中断后的制作会保留已有文件，继续时先核对可复用的成果，不从空白课重新开始。

## 它能帮你做什么

**要求能追到当前画面和声音。** 适合多轮返修、外部组装和恢复旧工程。先登记用户原话、稳定要求ID与可观察条件，再派发带真实输入哈希、负责范围、对象和必检动作的任务；交回文件、对象、帧窗及证据，缺项不能完成。正式登记、定制CLI和桌面复制共用同一当前字节检查器，渲染期间冻结输入并排队修改。候选已编码、验收受阻、正式保存、用户接受分别显示。

**后续课程沿用已验证的质量基线，而不是反复试错。** 适用于同系列扩展和既有课程返修：分镜按关系、对比、判断、过程选择不同表现，先完成主体再单独制作检查花字和原库音效；底部按内容分区，每一区域显示自己的进度。用同一时间轴核对口播、正文、字幕和导航，检查真实编码中的字形、重叠、划线与章节边界。流程标准与技术检查不冒称完整看听或用户验收。[整课基线与验收方法](skills/corporate-training-motion/references/57-series-quality-baseline.md)

**变化跟着讲解推进。** 章节表共用真实显示时轴，剪切和停顿后导航仍随播放前进；章节文字遵守本课选择。结构签名排除换文案/颜色等换皮，语义事件绑定当前配音原文区间、出现次数和逐项触发，专门花字与原库音效检查实际编码。抽帧、采样和包哈希保留真实范围，不能代替听感或连续观看。[具体输入与命令](skills/corporate-training-motion/references/55-execution-contract-and-release.md) · [预览验证范围](docs/verification-next-dsh-release.md)

**逐条显示时，编号跟着讲解走。** 适合拆成上下篇、局部改开场或总结后出现“第三条先跳出”的课程。制作端为每行登记具体段落、句子区间和出现次数，用 `reveal-plan / reveal-check` 一并核对相关各篇；不靠首次短语命中、时间排序或钳制修饰错误。检查覆盖当前编码的出现前/出现时/稳定后图像，音效引用跟随新事件，已有必要条目保留；同时呈现的整页不会机械判成乱序。它验证已声明节点与指定像素探针，不是任意画布的OCR或完整听审。[字段与实际用法](skills/corporate-training-motion/references/56-ordered-reveals-and-intro.md)

**缩短片头时，一并核对整段等待和时间线。** 适合品牌标题停留太久，或只缩标题仍迟迟不开讲的返修。先区分整片头与标题后的等待；只改等待时保留原动画、标题显现与落定过程，停留秒数不直接套成整个片头时长。在本课 `introPolicy` 保存实际选定的总时长、静止停留及正文间隙预算，`intro-check` 测量当前包装显示轴和编码静止区间，并检查字幕、章节、进度、音效、音频速度及总时长的当前依赖。缩包装不再给讲解重复降速；外部封面仍只占首帧。某课选择1—2秒，不会成为其他课的统一硬时长。[操作与边界](skills/corporate-training-motion/references/56-ordered-reveals-and-intro.md)

**macOS 应用内更新。** 从工作台顶栏或插件详情检查新版、下载并校验。课程忙时等待；只有用户主动选择安装且正常退出 DSH 后才替换并重开，不退出 Codex。顶栏空白可拖窗，按钮仍可点击。

**有新版时主动提醒，不强制更新。** 打开课程工作台时和工作台保持打开期间会后台检查官方 GitHub 稳定 Release，成功结果缓存 15 分钟，连接失败约 2 分钟后重试。工作台顶部右上角「检查更新」可跳过缓存；有更新时显示版本和下载入口，不自动下载安装、不打断当前制作。旧版本用户需先手动安装本次更新才具备提醒能力；预览版不会提示降级到较旧稳定版。

**DSH 插件详情页也能检查 GitHub 更新。** 在「插件 → kgxc-course-plugin」点击「检查 GitHub 更新」，不需要打开课程。这个按钮只读版本信息，不会安装。通过 npm 安装的版本由 DSH 原生包管理检查 npm 更新；首次部署课程制作环境仍需配置 Python、浏览器和渲染依赖。

**DSH 对话可收起，也能随时重新打开。** 源码新增顶部常驻的“收起 AI 对话 / 打开 AI 对话”按钮，不再放在容易被课程画面覆盖的区域；折叠后、刷新后仍可恢复。制作与独立审阅沿用当前会话已选的原生模型，不要求同事切换到 Codex，也不会替换个人模型或计费配置。JavaScript 状态与原生模型路由回归已通过；重复折叠、刷新及窄窗的浏览器测试已编写，但当前环境阻止 Chromium 启动，尚未完成浏览器或同事原生 DSH 桌面的实装验证。此说明对应 rc.3 候选包，旧 rc.2 安装不会自动获得修复。

**DSH 课程工作台。** 顶栏左上显示酷果星创原版 Logo，侧栏收起时为系统窗口控件留出空间。下载更新后可选择立即或稍后重启，稍后会保留下载。 在当前会话工作区内完成资料、大纲、逐字稿、分镜、有声小样和整课交付，顶部固定阶段导航，右侧保留原生 AI 对话、模型选择和附件。大纲卡片可编辑、拖动、增删、拆并，稳定章节关联带动讲稿移动，并标出后续影响；AI 修改先给建议，由用户采用。分镜独立选择，小样使用实际视频和时间点反馈，整课显示真实任务与文件。制作进度栏显示实际步骤、耗时、等待模型回复和最近执行结果；合成时读取实际任务百分比，同一步连续失败会累计提示，报错不会被后续读取掩盖。画面、配音和绑定就绪后由程序直接合成，避免重复模型等待，仍保留原有确认与校验。保存与确认分开，未生成内容不会冒充成品。时长、受众等选择主动弹出，最后一道单选题点选后发送整组答案，预选不发送。本版插件 0.9.7，核心 6.9.6；当前插件只开发和验证 DSH，Codex 宿主插件暂缓。此前版本已用独立微课走通完整151.2秒视频、字幕、封面和桌面交付；本版验证范围单独记录，不据旧片声称新版课程已验收。保存后核对Finder可见性，显示实际位置，并可一键打开成品文件夹。交付默认保留逐字稿、小样、配音和工程；保留无需清理检查，如需清理，先弹出本课范围供选择，明确确认后才执行。历史会话保留成品回看及继续编辑入口。实际编码与技术观察不代替业务用户验收。[使用与验证范围](docs/PLUGIN.md)

**看清原始资料怎样变成课程。** 适合需要压缩、合并或补充业务材料，又希望审阅者能核对内容取舍的课程。在“原件对照”查看独立业务要点的原文与出处、讲稿对应段、保留/合并/舍弃理由，以及新增示例、解释或外部事实的理由与依据。覆盖率按全部已登记要点计算，舍弃不从分母删除，关键规则、条件与例外单列；漏读、未知或无法核验不填满覆盖。比例仍需人工判断拆点和语义是否完整。用户查看后可在右侧同一逐字稿问答中明确确认；原件、稿件或报告改变会使当前确认失效，旧回执留存。制作端能生成对照，模型不能代确认；独立学员盲审继续只看当前作品。原件对照本身不改稿、不出片，也不启动另一盲审。[原件对照标准](skills/elearning-course-design/references/source-coverage-and-scope.md) · [本版发布验证](docs/verification-next-dsh-release.md)

**高质量写稿在前，一次盲审收齐问题。** 适合已有资料却经常写成口号、同义反复，或返修后不断出现新审阅要求的培训制作。先把每个要点对应到实际任务、具体情境、动作与判断依据、结果和练习反馈，再写自然口语；送审前由制作端自检信息增量，程序定位品牌问候遗漏、占位和明显重复。酷果课程正文开场保留已确认的酷果星创问候语。之后每阶段只对当前选定方案盲审一次，按稳定问题清单集中修复与定向验收，不把新哈希、升级或次数不限变成再审理由。技术检查不冒称自然度已通过，本版使用隔离合成测试，不启动真实课程制作验证。[写稿标准](skills/elearning-course-design/references/script-authoring-quality.md) · [一次盲审与验收标准](skills/corporate-training-motion/references/50-independent-review.md)

**独立学员盲审与执行监督（插件 0.9.4 / 核心 6.9.3）。** 适合制作方熟悉原件却容易忽略学员理解困难、分镜长期静止或视觉问题的课程。在逐字稿、全课分镜、有声小样和完整成片四个节点，各开新的独立 agent，只给该阶段成品，让它先复述“讲了什么、学到了什么”，再找可定位的问题。原件、目标答案、制作历史与旧评语留在制作端；审阅者不能改稿或提供补丁，每阶段当前已选方案只盲审一次，意见一次汇总为固定清单；实际制作 agent 集中修复一批，以当前成品证据逐项定向验收。未解决项保留卡点，不自动启动新盲审，也不要求未选备选达到验收标准。

**宿主核对实际请求，再绑定审阅报告。** 适合独立审阅或生产监督已经读完当前成品、却因手抄长版本编号错误而被拒绝的情况。宿主先核对本次注册调用、冻结输入、实际原生输入与零工具边界；只有报告确实未提供绑定字段时，才附上已核实的本次绑定。模型已提供的空值或错误绑定继续拒绝，真实成果变化仍由后端阻止。原模型正文与宿主封装分别留档，历史无效报告不追认。该检查是原生应用调用边界的证据，不声称捕获供应商最终 HTTP 请求。

**让讲解带动画面，并检查实际视觉效果。** 分镜审阅逐段对应旁白与对象的起态、过程、结果、信息和焦点变化，指出长时间停在同一页面、字幕变化代替演示或方案重复的位置。小样和全片检查构图、文字字幕、人物演出与遮挡、风格、动作转场、花字、声音和音画配合；增加切镜数不等于讲得更清楚。另设只读监督侦探 agent 跟踪用户要求、实际执行、角色隔离和版本证据，便于总导演发现要求未落实或报告与当前成品不符的问题。

**把已选要求交到实际制作和交付。** 适合多人分工、换对话恢复，或从中段小样扩展整课时容易漏掉声音、品牌与导航的制作任务。开工和恢复读取同一份 `production-contract.json`，把原库叮／嘟咚、重点强调、原句对应的语义动作、正文原Logo、分节导航与R5/R8头尾交给负责者；正式登记前用当前文档、素材和实际视频逐项核对，缺什么就报告什么并保留候选。花字可以是标记、聚焦或划线，须对应原句、用途、目标、帧与阅读窗口；动作不能靠透明度变化次数代替演示。机器核对结构和证据绑定，不证明美观、教学语义或声音自然。该核对沿用每阶段一次盲审与固定清单验收，不增加模型评审轮次。[合同用法与验证边界](skills/corporate-training-motion/references/51-production-contract.md)

正常改选分镜时，仍然有效的制作偏好会随新的已选方案更新绑定，避免把正常选择误报为需要重新决定；旧绑定已经过期时继续提示核对，不借改选把它刷新成有效。恢复、派工及导出仍核对当前选择，旧确认与历史分别保留。

编码和解码成功后，如果六项制作合同尚未核完，工作台保留实际候选供作者检查，明确显示“制作候选已生成，待核验，未登记”。技术任务可结束，但候选不提前替换旧成功导出、正式引用、阶段登记或桌面成品；当前合同就绪后才沿原登记流程继续。编码失败和其他执行错误仍按失败处理，不会被待核验状态掩盖，也不因此增加盲审轮次。

**图示既能动，也能读懂。** 适合团队分工、信息流转、比较和因果关系等图解。分镜与派工先说明重要节点和关系分别代表什么，再安排与口播同步的正文标签；不能只剩纸页、对话框、连线和高亮，让学员靠字幕猜含义。需要解释的业务图示登记图示与文字节点及共同可见窗口，制作端从当前编码核对文字、指向和阅读。装饰图标不逐一强加标签，页眉、字幕或节点数量不冒充业务说明。这样把缺字问题前移到设计与作者自检，并沿用原固定清单验收，不新增盲审。[文字标签与制作合同](skills/corporate-training-motion/references/51-production-contract.md#业务图示与文字标签)

**AI审文字与画面，用户听音轨。** 当前课使用的模型没有音轨感知能力时，可依据用户真实选择分工，保持原模型和计费通道。AI按实际文字、帧和帧序列检查内容与画面，工作台分别显示AI检查范围和待用户听审；用户完整播放当前全部小样或全片后，在原确认动作中明确声明声音与音画配合是否通过。记录绑定每个视频的版本、SHA和完整范围，视频变化后重验，反馈问题继续交制作端处理。选择这种安排本身不算完成听审，抽帧和ASR也不算听过声音。这样保留声音检查职责，同时让用户看清谁检查了什么。

**配音也可由制作端负责自动核查。** 用户明确表示无需亲自审核配音时，可以只为当前课记录免人工音轨审批，停止逐句试听，把当前MP4的音轨、解码、时长和非静音等交给程序核对。AI继续检查实际文字和画面；工作台分别保留自动检测结果、未执行连续听审和主观听感的能力范围。免审批不会生成“用户听审通过”，也不会把技术检测变成完整听审；内容、视觉与其他关键未知继续按原门槛处理。分镜审阅同时保留结构化的数字阅读窗口，避免制作端已安排的入场和停稳时间在交给学员审阅时丢失。

用户明确要求本轮优先改善效果时，可临时关闭本课调用次数与返修轮数门槛；保留旧上限、累计调用、用量和失败，随时可恢复。该选择不改变新课默认值、模型通道或质量检查，工作台明确显示“本轮次数暂不限”。 纯执行设置升级可显式沿用仍有效的内容复核，保留代码与审阅绑定，课程内容变化后须以新证据核验固定问题与直接回归，不自动重开盲审。分镜证据支持从明确的片段字段定位识别片段；不能核实的意见保留阻断并交制作端核对，避免一处格式问题吞掉整份意见。

用户要求保留原文、来源和ID，按适用阶段与职责登记：内容要求进入本阶段制作核验，隔离、职责与通道要求交给独立监督。后续阶段义务继续保留；当前文字不承担尚未产生的成片验收。制作端给出可回查的逐字引文，监督取得核验结果与拟执行动作，能区分正常待修、保留卡点和违规放行。

**普通过程合批，关键动作继续独立检查。** 制作过程中完整保留每条事实，普通读取、搜索及后台任务通知按批交监督，避免在正式内容尚未变化时反复执行相同范围的模型核查。开始、结束、失败、用户新指令、实际导出生命周期，以及原生正式保存和直接写入工具的前后，仍同步等待独立监督。合批不改变调用限额选择、质量验收、模型通道或日志。

**正确处理原生重复调用提醒。** 同一制作代理重复读取相同内容时，DSH会生成程序提醒。制作快照核对真实工具执行、实际策略、原文与入队时序后保留这条上下文，帮助代理调整做法；已核实但尚未处理的提醒由原生流程正常领取。真人插话、伪造、外来及重复消费的提醒继续停止旧任务，已有历史和输入不删除。

**看清当前任务与历史失败。** 恢复长会话时，工作台从可信制作派发读取当前课程、阶段与任务，避免继续展示旧版本错误。旧失败留在可展开历史；只有实际成功且候选、目标正文和较新版本都匹配，才标明被哪个修订替代。新任务开始本身不会把旧错误改成成功，无法关联的旧问题继续如实保留。

**让监督看见真实执行证据。** 制作任务的工具记录保留经过筛选的读取路径、工具请求声明的写入目标、简单脚本参数、实际返回的断言结果与文件哈希，便于监督判断本轮是否写入正确目录、基线核对是否成立。已支持的结构化布尔值、版本和备份数量在桌面端与核心两层传递中保留实际值；任意正文、复杂命令和自由输出不直接传入。请求路径、工具返回与宿主独立文件检测分别标明来源和范围，不支持的格式继续无法验证。证据不足保留阻断，不能把退出码零当成课程通过。

恢复曾中止或异常结束的制作时，保留旧任务及未知用量。已核实原生 `turn/end` 因 Codex app-server 错误而结束时，保留 `failed/error` 原种类、错误和未知用量，通过正常事件追加同一制作身份、操作、step/turn、seq、时间与来源观察回证。在暂停且全部调用已结算后可继续原授权设置。工具错误、缺少终态、错误身份或序列、后续仍有进展的任务继续阻止；失败本身不表示已经结束。

模型长时间不返回事件时，先保留失败和未知用量，再检查原通道与实际等待阶段。本课制作核验可在暂停且无在途调用时显式调整独立等待时限并保留依据，默认10分钟；次数不限不会自动改变等待设置。上游适配器的无事件等待与课程总等待分别配置，不伪造进度或切换模型。

**长会话仍可继续实际制作。** 已授权的制作派发沿用原制作agent、会话、工具及工作区权限，实际请求只带当前任务和本轮后续工具结果；旧材料和历史仍保留在工程与日志中，制作端可以按需读取。当前任务结束或取消后恢复普通行为；同一派发请求不重复执行。分镜通过后的自动小样继续也使用这条路径，降低旧核对包反复累积造成上下文超限的风险。这条制作路径保持原有确认与监督，不给学员盲审者开放制作权限。

**后台任务完成后继续取回制作结果。** 适合导入、配音或渲染转入后台的制作任务。程序把完成通知与本轮真实工具调用、原制作agent和终态任务逐项对应，再让制作端读取结果、回读文件并返回独立审阅流程，避免自己的完成通知把制作误停。只有可核实的本轮任务通知参与该流程；真实用户插话继续打断，其他任务和未知来源保留停止行为。已有候选、正式文件及失败记录分别保存。

**制作端只读核验中的自动技能清单。** 适合原制作会话已有技能清单、转入只读核验后原生SDK更新工具可用性的情况。核验仅保留完整当前包与原生系统指令，按实际原生生成位置核对并剔除精确的空技能清单更新，避免把程序更新误当用户插话。真实用户和不能核实的消息继续中止旧快照并保留输入；已接受盲审的同轮制作核验可按原有绑定恢复。

**长会话中的制作核验可以从真实失败处恢复。** 本轮制作核验发送完整当前核对包及原生系统指令，保留原制作 agent 身份与持久历史，避免反复附带旧核对包和工具返回。若独立审阅已经接受、制作调用却失败，且成果版本、协议、原通道和绑定仍一致，可在同一轮追加制作端重试，随后继续监督；旧失败、未知用量和新调用分别记账。分镜包保留完整必要原件、逐字稿、方案、要求和本次发现，去除不能在该阶段编辑的工程副本及重复旧报告。成果实际修改后逐项核验固定问题与直接回归，旧版本证据不冒称当前已解决，不重开盲审。

分镜盲审同时取得该成品中已有的导航标题、目录帧窗及结构化显示状态，便于核对遮挡与完整阅读区间。导航按可见字段单独筛选，未知状态不补造；原件、教学目标、资源路径和旧评语继续隔离，避免把成品中本已写明的信息误判为缺失。

中文长稿和分镜经本机服务传给制作与审阅代理时，按完整UTF-8字符流解码，保持跨响应分块的汉字。审阅中发现的文本问题应回查实际收到的成品，传输失真须修复并重验，不能误改正常原稿。

返修事务遭版本或保护字段拒绝时，本轮立即停在原错误，保留学员意见、制作提案和用量；制作方完成真实修改后按固定清单定向验收。不会用重复审阅未改稿件来掩盖执行失败。分镜局部返修的既有保护字段会在制作提示中明确列出。

制作阶段可沿用原会话，在只读核验后继续编辑及读取后台任务；恢复时从当前已注册技能及其真实显示规则重建本轮工作上下文，避免原生目录更新误停制作。已知程序消息逐项核实，真实用户插话和陌生输入仍保留并中止旧任务。

原生DSH默认给新agent注册的团队工具由只读执行器隔离，最终模型请求仍须为零工具、无额外运行上下文。创建阶段的阻塞单独记为preflight失败，不冒称已调用模型，预算及未知用量保留。报告绑定真实 agent、只读访问、阶段和成品哈希。刷新、重开和协议升级不重置累计返修、调用及用量；旧报告和所有过程文件保留。分镜新增独立AI检查沿用已确定选择与委托，不增加一次强制人工审批。当前Codex通道支持文本与图片，抽帧和ASR不能充当完整连续视听；默认模式关键项缺证据继续阻塞。用户明确选择本人听审时，由真实用户声明承担；用户明确免人工配音审批时，保留自动技术结果与未执行连续听审，关键未知不据此通过。其余关键内容、视觉及技术项仍须核实。AI审阅、用户确认及桌面正式交付分别记录。[规则与角色边界](skills/corporate-training-motion/references/50-independent-review.md) · [本机验证范围](docs/verification-plugin-v0.8.22.md)

DSH内直接使用共用课程编辑与审阅界面，原件、讲稿、实际小样和成片在同一插件查看；后台继续复用原有媒体制作服务。修改意见进入后续验收依据，执行失败可在累计次数内分析原因、调整方法并复核，保留每次失败和恢复证据。新版本要求DSH 0.2.2-rc.1或更新的0.2系列。

分镜前可在“制作偏好”中选择同风格可动顾客、花字密度和提示音；点选即保存，已选事项不反复问。新增顾客可写描述、上传参考图，先查看设计再采用。人物统一用多部件可动结构，V01/V02/V03是可复用起点，新课可按情境设计其他人物，通过发型、眼镜、便装款式与颜色区分，同课同人保持连续；选择窗口的缩略图由同一运行器生成，成片中不使用整张人物贴图。修改会提示更新相关分镜和音视频。启用花字或音效后，当前视频必须有真实对象、匹配的混音回执和非静音音效分轨，不能只保存开关。场内人物对白逐句检查说话人、同场受话人与头部方向；真正的人物转向、手势和行走直接进入动作校验，避免用无意义线条顶替。工作台空闲关闭后，切换阶段由程序恢复原服务入口。整课页把当前任务和历史失败分开：旧诊断可展开查看，最新失败不会被旧成功掩盖。总部授课立场保留在内容设计中，默认不自报部门；结尾另查完整末句后是否混入保护提示的残音。

## 核心能力与实际价值

### 1. 先把资料变成课程，让学员知道如何用

先诊断素材、梳理工作任务和学习目标，再推荐讲解方法、课程大纲、示范与练习。逐字稿包含实际讲解、案例、过渡、提问和答案反馈；业务事实、条件、例外及资料疑义保留依据。

例如，收货资料中的“订单、SN 和外包装一致”，可以展开为：为什么要核对、到哪里看三个信息、怎样逐项对应、发现不一致时按什么依据处理，以及交接前如何再确认。培训负责人可以在制作画面前检查课程是否教到了真正需要的工作动作。

资料内容较多、课程需要压短或拆分时，先逐页对照要点在课程中的去处，说明保留、合并或舍弃的理由。业务目标与岗位动作分别讲清，缺失的内部指标不补造，案例数字不改成统一标准。店长课可以用“听完一单、指出漏讲的一句话、示范后请员工重说”解释带教，再按需要把完整话术或操作演示安排为选修；精简重复，保留原因、回应和收尾。这样能减少漏项，也让没有原件的学员知道怎样做。[原件覆盖、现场讲解与主选修取舍](skills/elearning-course-design/references/source-coverage-and-scope.md)

默认学员拿不到制作端的原始附件。首次出现表单或图表时，先讲清名称、用途和当前项目，把完成任务必需的字段与条件放进课程。这样只有视频的学员也能跟上讲解。酷果课程按总部面向门店授课的立场组织表达，来源追溯保留在制作记录中。

### 2. 按知识点安排动作，把过程、关系和结果演出来

内置 **100 种可调用动作和 17 类教学构图**，覆盖核对、操作、判断、对比、路径、信息流转、记录回填和反馈。制作时先确定本句要讲的对象、起始状态、变化和结果，再把动作安排到对应旁白时刻；动作完成后留出读图时间。

收货课可以让订单字段与商品标签逐项对应；指标课可以把记录聚合成分子、分母；服务课可以让人物提问、观察和回应。不同知识点使用适合的表达，让学员有机会看清“怎么发生”和“结果是什么”。动作数量用于提供选择，不要求每门课凑齐。

已有参考片方法可用于“讲师引题—情境演示—回到要点”“说—听—回应”“聚焦当前对象”和“逐项对照”。学习其组织方法后，用本课内容及已确认美术重新实现。普通操作保持利落，讲解时长由内容、示范和读图需要共同决定。

**字段与流程课同时安排阅读与讲解节奏。** 分镜列出每组新增文字、要读懂的任务、动作时间、完整停稳后的阅读时间，以及后续需要回看的结果。比如任务卡上的责任人与日期稳定保留，旁白解释其工作含义；前一步留下摘要，后一步可回看比较。动作结束不必换字，阅读时间也不机械变成无声等待。阅读不足时先精简正文、分组和调整顺序，禁止自动插静音凑秒数。导出会按真实文字、父容器运动、替换、剪切与渲染曝光检查，拦住“卡片动完了，文字却只剩一瞬”的候选。6.0新视频还绑定同轴旁白干声与明确任务停顿，导出前和最终编码分别检查讲解中断；背景音乐不能掩盖旁白断续。练习先提示学员自行暂停，较长观察或作答须有具体用途。工程阈值用于发现异常，不能代替正常速度连续听看和学员理解判断。[具体方法与检查命令](skills/corporate-training-motion/references/45-reading-and-information-pacing.md)

**用花字把当前重点落到具体词句。** 服务沟通、条件判断与总结段可以安排短词弹出、重点标记、移动定位和步骤划线，先绑定讲稿原句与动画，再留足稳定阅读。条件和否定一起保留，平等选项保持同样权重，普通叙述可留白。花字与声音随分镜和小样一起审阅，方便培训负责人看清“此刻让学员注意什么”。[花字设计与选音方法](skills/corporate-training-motion/references/46-flower-text-and-native-sfx.md)

### 3. 全课先看演绎与分镜，再用三个随机片段验证效果

当一门课同时包含人物对话、概念解释和操作演示时，单看一个片段无法判断整课。新视频先把已确认逐字稿全部对应到画面，**每个教学片段至少提供三种实质不同的表现方案**，说明起始状态、动作、结果、观看焦点、人物、实现条件、预计成本和风险，并给出推荐组合。用户可以逐段选择，也可以明确采用推荐组合。

例如同一句“目标要变成现场动作”，可以比较目标改写过程、前后行为对照和触发条件路径；不是只换三种颜色。全课分镜表先用文字与必要粗图审阅，避免先生成全部候选视频。共同美术规范另行保存；情境可以用人物演绎，概念可以用无人物图解，具体依本课偏好组合。

全课分镜确认后，**分层随机抽取三个不同的完整片段**生成有声动态小样，优先覆盖情境、概念和剩余高风险实现。抽样保存种子、候选池和选择原因，恢复工程不会重抽；需要重抽时记录理由。三个片段使用与整课相同的生产代码、素材和时间线。小样确认后才制作整课，未抽中类型及高风险片段仍须逐段检查，目录、章节衔接及密集信息段也检查阅读与声音连续性，不能只挑好看的画面。

系列课程不必反复套用同一种颜色。未指定品牌色的新课会从六套合格色板中随机抽取一套，默认候选不含绿色；可以直接说“这节课随机配色，不要绿色”或提供品牌色板。工具先排除禁用色，再保存候选池、种子和结果；同一课的分镜、图表、人物讲解与进度条沿用整套配色，恢复与重编译不重抽。用户指定和实际已确认小样优先，旧课程保留原画面。

17 类教学构图与 24 种视觉方案通过同一份色板绑定，避免换了构图又回到固定灰绿；工作台与文稿审阅界面保持白色和中性灰。人物、设备与真实界面保留本色。[选色、禁用色与恢复的具体用法](skills/corporate-training-motion/references/47-course-palette.md)

内置 **24 种视觉方案**仍可用作字体、材质和构图参考，目录中的旧配色不覆盖新课已保存色板。旧工程保留原有效确认，明确要求升级后才切换流程。[全课分镜与三段抽样的具体用法](skills/corporate-training-motion/references/44-storyboard-and-sampling.md)

### 4. 用人物、设备和业务物件解释现场

素材库包含讲师、店长、店员、Coach、顾客，以及 Apple 设备、文书、票据、外箱和门店场景。角色身份与胸标对应：黑衣 KG 店长、蓝衣店员、黑衣 MyCoach 教练；讲解、服务和顾客角色可以在画面中各司其职。

仅恢复既有纹理工程时，C01 顾客与 S01 店员仍支持各自原图标定的二维眉眼、视线、眨眼、点头和部分关节动作，可表现关注、倾听和回应。适合把服务要点放进短情境；这些能力的适用范围是正面二维演出，其他人物和新姿态需重新制作与检查。

需要全身演绎的情境，默认先排人物意图与站位，再以简化二维形体粗演和精修。可复用人物实现包括走近、停步、全身转向、说听回应、短手势及部分手部任务；肩袖连续，摆臂随步态走弧线，脚交替支撑，实心手臂按前后层级遮挡。动作有自己的时长，完成后自然进入倾听或展示，避免为配音慢放。`stage-acting` 按本课外观、站位和距离生成候选节点及步态/转向轨道，`acting-check` 给出连续帧复看范围，预览与导出使用同一代码。这样后续可以从可运行做法开始调整，减少重复修正；不是只增加限制。当前为正面到左右侧面的新绘人物，保留已确认身份特征和原版胸标，不等于旧PNG已获得万能骨架。实际演出仍需正常速度观看。[怎样编排、怎样画、怎样调整](skills/corporate-training-motion/references/48-situational-acting.md)

### 6. 让学员知道学到哪里，让成品方便上架

视频课程带有随视觉风格设计的底部进度条；两个及以上小节包含目录页和每节独立标题页。目录、口播任务与实际章节时间对应，目录和章节以简洁口播衔接，避免无声占位；正式教学区间显示进度，封面、片头、导入、目录、总结和片尾保留各自的画面空间。

多节课程中，学员可以知道当前学习任务及所处位置。导航同时避让主体与字幕，外观跟随整课美术，便于系列课程保持一致。

课程名称、片头标题页与课程封面分别处理。为学习平台上架或系列课程列表设计独立封面，沿用已确认名称和品牌，以业务相关场景、人物或物件说明学什么，区分主课与选修；不能默认复制片头定格或只放大标题。实际查看完整尺寸和 320×180 缩略图，再核对播放器真实poster，让学员在入口处就能辨认课程内容。

品牌片头片尾替换本课名称，酷果正文默认持续保留右上角原版Logo，仅按本课用户明确选择改变位置或显隐；其他企业使用自己的品牌。新增场景和拆分导出继续沿用确认配色与人物。首尾口播优先当前已确认稿，从实际视频核对完整且一次，不因旧固定句自动重录或追加。只改封面不自动改配音或重编码视频；后期调整速度时，画面、声音、字幕和章节共用时间映射，保留原版及分轨，方便检查与返修。

酷果成品默认按一门课程一个文件夹归集到桌面 `ai 制课/<课程名称>/`，当前视频、字幕和封面同放，旧版与小样分别归档，工程和过程文件留在项目内；也可沿用你明确指定的交付位置。

### 7. 检查实际成片，帮助发现影响理解与观感的问题

交付前分别复核课程是否讲清、构图与节奏是否合适、声音是否自然。逐场检查文字边界、高亮、人物对齐、物件支撑、箭头所指和动画结束状态；修改共用素材后，沿全片复用位置检查同类问题。

新工程的对象状态与画面证据绑定当前实际编码 MP4，动作按真实发生时刻检查；长课程的批量取证支持数百个对象事件。这样可以核对“导出的那一版”是否呈现了预期内容，也便于定位返修范围。

自动检查用于发现问题和核对证据；正式交付前仍须正常速度完整连续看听最终候选，核对讲解因果、数字条件、完整尾字、章节与练习衔接，以及实际构图、字体和留白。只做抽查就说明实际范围，不能把识别、抽帧或技术通过写成完整试听。**技术检查、实际听看和用户最终认可分别记录**，便于你理解当前结果经过了哪些检查、还需要审阅什么。

### 8. 用可恢复工作台持续改课，完成后释放资源

工作台保留场景、画面对象、字幕、素材、音轨和时间轴，支持修改已登记文字与位置、替换素材、调整停留、同步裁剪、撤销重做及再次导出。改字幕不会自动改变录音；讲解内容变化时，可让 AI 同步修订配音、画面与时间线。

方案、分支、用户选择、确认原话、时间和关联版本写入课程文件。换对话时提供工程目录，或双击课程中的“打开课程工作台.command”，可以读回已有进度。适合跨天制作、多人交接和业务更新，减少重新解释背景和重复确认；实际内容变更时复核受影响部分。

未变化文件的复核结果可复用，并发查询共用一次检查，隐藏页面暂停轮询。课程完成、无导出任务且空闲两分钟后，工作台自动退出，减少后台持续占用；导出、未保存编辑、播放和下载会延后关闭。文件与确认记录继续保留，返修时重新打开。

## 一门课怎样完成

**原始资料 → 教学方案确认 → 完整逐字稿确认 → 选择课件或视频 → 审阅与交付。**

| 阶段 | AI 协助完成 | 你重点判断 |
| --- | --- | --- |
| 1. 整理资料与目标 | 诊断来源、疑义、工作任务、学习目标，推荐讲法、大纲、示范与练习 | 课程教给谁、需要学会什么、内容是否准确完整 |
| 2. 编写完整逐字稿 | 写出实际讲解、案例、过渡、提问和反馈；生成原件要点与讲稿对照；独立agent只读当前稿件，进行本方案唯一一次学员盲审 | 核对原件覆盖、舍弃与新增依据、关键条件及例外；明确勾选原件对照声明，可与讲稿确认一次提交 |
| 3A. 独立课件 | 按确认讲稿制作所需格式的课件，交付课件和逐字稿 | 是否方便自己讲授、带教或录制；这条路线交付即可完成 |
| 3B. 全课演绎与分镜 | 全部逐字稿对应画面，每个片段至少三种实质不同的表现；独立agent只读分镜，检查旁白与画面起态、过程、结果及节拍，排查长静止页面 | 可调整表现与共用美术规范；沿用已有选择与委托，不另设强制人工审批 |
| 4. 三段随机有声小样 | 按已保存抽样用生产实现制作有声MP4，独立agent仅审当前片段的教学、视觉、表演与音画问题 | 正常速度听看不同表现、动作、字幕及声音，确认后制作整课 |
| 5. 完整视频与工程 | 扩展整课并由新agent只看当前全片审阅，制作端负责修复；监督agent另查实际执行，交付当前视频、字幕和封面，过程保留 | 查看实际课程及真实检查范围，提出具体修订或最终认可 |

**视频制作默认并行，不重复返工。** 逐字稿确认后，可以一边生成已确认文本的配音，一边做分镜、素材和导出准备；实际配音确定后再对齐字幕、动作和花字。制作有声小样时先用实际导出链检查片头、正文和片尾两处接缝，不等整课渲完才排查。主体完成后单独制作花字和音效；可独立生成的分段流程只重做受影响的部分；工作台仍做必要的整课最终合成与检查。逐字稿、小样、成片三个确认节点不变。

教学方案和逐字稿是共同前段。选择视频可以直接进入导演；已有独立课件时，追加视频仍从已确认逐字稿与原始资料重新设计画面。后续增加适合内容的镜头和动作，沿用有效美术方向；重要内容、声音或风格改变时，复核相应部分。

工程保留来源、方案、媒体、确认记录和独立编辑器，可按需打包交接。换机器继续制作时仍需准备匹配的媒体环境。

## 开始做第一门课

把原始资料放进课程工作目录，在 Codex 或 WorkBuddy 新对话中输入，并替换受众、课程名和资料位置：

```text
请用 $corporate-training-motion，把我提供的资料做成《收货核对流程》培训课。
受众：新入职门店同事。
目标：能找到并核对订单、商品 SN 和外包装信息，按原文要求完成交接。
原始资料：我提供的文件；业务条件和例外以原文为准，疑义请列出来。

先打开课程工作台，诊断素材，推荐讲解方法、大纲、示范与练习，等我确认。
再写完整逐字稿，让没有原始附件的学员也能听懂，确认后进入制作。
本次需要完整视频：先给全课内容演绎和分镜，每个教学片段至少三种画面表现。
分镜确定后随机抽三个完整片段生成有声动态小样，记录抽样依据。
小样确认后完成整课，交付 MP4、SRT、封面和可编辑工程包。
请说明实际完成的检查、听看范围和待我审阅的内容。
```

只需要自己讲课时，把交付要求改为“本次只交付独立课件和逐字稿”。先说明目标和已有材料，讲法、画面、声音等制作选择可以在查看具体方案时确定。

以后继续制作或返修，在新对话中提供课程工程目录：

```text
继续制作这门课程，工程目录：填写实际课程目录。
请读回已有方案、逐字稿和确认记录，从当前阶段继续。
```

也可以双击课程目录中的“打开课程工作台.command”，或使用：

```sh
kgxc-course resume ./courses/my-course
```
