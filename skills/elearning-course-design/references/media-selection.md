# 内容与媒介

下表为本技能的建议矩阵，吸收用户参考图分类，不声称是 ATD 官方媒体规范。

| 学习任务/内容 | 首选候选 | 练习证据 | 制作前提示 |
|---|---|---|---|
| 制度和原则 | 文字、图示、简短讲解 | 判断适用范围和例外 | 频繁变化明细适合可更新速查表 |
| 复杂流程/协作 | 分步流程、泳道、必要动画 | 排序、找断点、异常处理 | 补齐交接条件和分支，不能用线性动画掩盖缺口 |
| 软件操作 | 当前录屏、真实截图、练习环境 | 同类界面完成任务 | 没有素材时只做标明的示意，不伪造现状 |
| 易混规则 | 同屏对比、正反例 | 分类、判断并解释 | 选边界案例，不只背定义 |
| 复杂决策 | 情境、分支互动、复盘 | 选择并解释后果或提交方案 | MP4只能暂停思考，无法记录点击分支；提前确认平台 |
| 标准操作 | 实操、局部特写、清单 | 模拟操作与可观察评分 | 缺素材时列拍摄需求，文字不等于动作标准 |
| 数据诊断 | 简化图表、计算、对比 | 解释变化并提出下一步证据 | 先核口径、周期、百分比/百分点、分母；旧数字标日期 |
| 反复查阅 | 可搜索手册、决策表、清单 | 查信息完成任务 | 不必全背、全做视频；记录版本和更新责任 |
| 沟通辅导 | 对话案例、示范、角色练习 | 基于可观察行为反馈 | 虚构案例标明；真实素材核实适用性 |

每单元记录“媒介→为什么支持任务→更轻替代→素材与维护影响”。预算不明时比较相对制作量，不编报价与交期。画面呈现关系和变化，讲解帮助理解；不让整屏文档和逐字朗读争抢注意，但必要字幕不能机械按“重复信息”删掉。图表重绘保留内部原表供核对。

考虑移动、弱网、无声和辅助技术等实际条件；设计阶段列需求，实际开发后验证。桌面缩图检查不等于手机验收。
