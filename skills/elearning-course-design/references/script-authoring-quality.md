# 逐字稿输入与作者自检

高质量稿件从输入组织开始。此页用于制作端写稿及交稿前自检，不新增一个评审 agent 或审批步骤。

## 写稿前已有的内容

先复用已选方案与来源，按教学单元建立简短内容表；简单课可直接写在大纲旁，不强制另建文件。

| 项目 | 需要回答的问题 |
| --- | --- |
| 当前方案 | 当前受众、工作任务、学习目标和已选讲解方法是什么？哪些内容已取舍？ |
| 触发情境 | 学员在工作中看到、听到或遇到什么，才需要此方法？ |
| 动作与判断 | 具体做什么、对谁说什么、怎样判断是否继续或换方法？ |
| 内容依据 | 哪项来源支持此规则？哪些是教学补充或虚构示例？条件和例外是否保留？ |
| 示范与反馈 | 学员能看到怎样做、对方怎样回应，以及常见错误后怎么办？不需要示范时说明理由。 |
| 新增信息 | 本单元让学员多知道或多会做什么？它与上一单元的区别是什么？ |

不能把“规范流程、有效沟通、关注员工、及时跟进”当作完成了动作栏。应展开到当前工作情境下可观察的行为、适用条件与结果。来源没提供的内部阈值或审批步骤不补造。

## 展开正文

开场先保留当前品牌问候，再以具体困境或工作任务建立学习目的；不用长段“重要性”铺垫。酷果星创课程保留“欢迎来到酷果星创企业培训课堂”或已经确认的自然问候原句，不把它放进制作备注后从口播删除，也不默认报内部部门。

一个完整解释通常需要“什么时候适用、为什么、怎么做、怎样判断结果”，依任务取舍组合，不强制每段相同字数、同一结构或必有故事。示范包含完整必要信息；只说“比如说一句安慰的话”并没有示范说法。练习反馈说明依据和常见错误，不只报答案字母。管理情境里的另一方有合理回应，不能只让讲师单向说教。

每段应提供新增事实、动作、判断依据、完整示范或练习反馈。有目的的回顾可以保留，但要帮助检索、比较、迁移或引出下一步；不是换三个说法重说“情绪管理很重要”。删除句子前先判断它是否承载条件、例外、理由、反馈或必要衔接，不能为了精简把任务剪碎。

术语不是禁词。“闭环”可以出现在课程中，但应说明谁在何时做了什么、检查什么结果。自然口播也不是强行口语化；避免冗长从句和书面堆词，同时保留业务准确性。正文不要出现“这里展示、依据原文、请制作一张卡片”等编稿话术，制作备注另列。

## 送唯一一次盲审前

制作端以学员只拿到当前成品为前提，完整通读正文，在同一次制作任务中集中修正：

- 每个单元是否兑现当前目标，有具体可用信息；抽象要求是否已解释到当前岗位动作或判断。
- 相邻段落是否只有同义复述；总结是否帮助应用或检索；重复保留是否有明确教学用途。
- 口播是否自然连贯，主语、受话人、指代和术语是否清楚；首次出现的表单或规则是否已交代必要内容。
- 事实、条件、例外、示例假设是否清楚，关键依据有来源；未为了流畅编造制度或缺失答案。
- 实际正文开场是否保留当前品牌问候，结束是否完整；正文与来源备注、画面指令是否分开。
- 是否只实现当前已选方案，未把未选风格或额外课程要求偷偷加回来。

记录“检查过哪些当前段落、改了什么、仍待核实什么”，不空填“自然度100分”。静态检查找不到问题也不能证明口语自然或信息量充足。作者自检和来源一致性由制作端承担，独立盲审只收当前阶段成品，不附此内容表、答案或旧意见。

盲审一次返回定位明确的问题后，合并同一根因，形成固定问题清单；一次制作任务尽量解决全部可修项。后续验收只核对这份清单、当前版本和必要的相关回归，不重新进行开放式找茬，不靠新哈希重置盲审次数。未解决项如实保留，不能把一次盲审理解成自动通过。

## 保存可执行输入，而非自报通过

视频分支把作者自检绑定到 `production-contract.json.requirements.direction.author_input`；共用入口是 `corporate-training-motion/workbench/production_validation.py:inspect_extra(project,context)`，由[统一执行合同](../../corporate-training-motion/references/55-execution-contract-and-release.md)调用，不另开模型审阅。

提交当前 `script_text`、`terms`与 `specialist_terms`，每个术语保存首次原文字符位置、已核实解释和资料依据；未知含义保留 `TERM_UNVERIFIED`。原件对照沿既有独立业务要点分母登记保留、合并、舍弃、新增和关键条件/例外；未读全不填完整覆盖率。该结构自检不会代用户确认原件对照，也不会自行判断拆点已经完整。

示范提供真实人物/物件、动作前状态、过程与结果。练习同时交题干、材料、选项、答案的对象绑定与问题/思考/反馈时点；完整题面留到反馈，不提前展示答案。场内对白提供说话人与受话人、本人引用口播区间、倾听、朝向、回应及离开边界，图示说明正文标签和关系含义。没有具体行动、答案抢先、受话人缺席或字幕冒充正文标签会返回具体ID和稳定错误，不以作者勾选代替实际演出。

讲稿阶段不要求尚不存在的编码或声音；配音可用后再用完整原句 `raw_span/occurrence/word_ids/audio_sha256`建立语义锚点，禁止短串猜测或段长均分。编码图片、真实运行状态、稳定阅读与实际听审在后续阶段各自验证，不把高质量输入写成成片已通过。
