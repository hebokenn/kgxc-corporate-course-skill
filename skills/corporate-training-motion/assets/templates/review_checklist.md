# 课程复核清单

## 规则覆盖

- [ ] 原件、用户补充口径、逐字稿分别留存，已确认内容不重复确认
- [ ] 每条关键规则对应讲稿与分镜；条件、例外和建议/强制模态保持
- [ ] 只改视觉时核对业务口径、逐字稿、既有音轨哈希未变
- [ ] 阻断检查：逐个可见业务点有本段对应解释，未讲信息已隐藏/移除；不能用别段原稿、规则ID或字幕复印代替讲清
- [ ] “同上/见前述/按规定”依据具体且已讲清；不擅自补阈值、例子或业务口径

## 结构检查

- [ ] 执行本包统一导演、视觉动作与内部工具流程，执行记录包含真实命令与证据
- [ ] 分镜前已判断知识关系，按内容选择独立或连续场景并记录理由，不强制地图
- [ ] 每段写清观众理解、实际对象动作、镜头理由和交接；地图场景再写局部展开与归回
- [ ] 来源、对象ID、时间范围、画布和证据哈希检查通过；仅此不能写视觉合格

## 导演视觉检查

- [ ] 选择地图表达流程/交接/层级时，使用实际共享画布；全貌先交代结构，再切局部。先后、并列、包含、条件和跨角色交接的连线语义正确，未用孤立要点逐一淡入替代关系。
- [ ] 仅采用地图时检查总览→局部→归回/下一环的连续MP4中，当前点与父级、邻点或小地图可定位；不是每段新建canvas后仅标continuous。
- [ ] 逐页对照原件盘点所有信息图，图内彩色注释也已读；source_images.json与分镜双向绑定。表单、票据、实拍和截图在成片实际出现，重要字段可读，未被图标替代；排除图确无新增信息且有理由。
- [ ] 员工小人如出场，以真实动作演绎当前节点的采集、检查、提交或交接，身份/工服一致，没有遮挡原图和字段或以循环装饰凑运动率。
- [ ] 同时查看真实关键帧和连续动态小样，不以静帧替代动态验收
- [ ] 图示表达知识关系；只有标题、文字卡片或淡入的方案退回设计
- [ ] 空间连续：同一对象不跳位置，能看懂当前节点与前后/父子关系
- [ ] 镜头有定位或读图目的，移动结束停住；局部展开后能沿图继续或回到全局
- [ ] 阅读时间从最后信息落定开始算；小屏可读，未讲内容不提前给答案
- [ ] 字幕单行无标点，画面标题按内容保留；单行字幕按唯一语块检查实际停留与原稿重建；重复字段按稳定对象分别计时，不改音速或有声采样来凑时长
- [ ] 检查进入/中段/落定/退出及所有连接、图形、文字、角色、字幕遮挡
- [ ] 出片前以最终帧率主动扫描整课字幕安全区，覆盖全部推近、平移、拉回及章节衔接；当前内容与仍可见的相邻已讲节点说明均纳入，未只检查焦点或停稳帧。
- [ ] 使用相机变换后、裁切前的完整字形/描边及成组说明边界，与实际字幕底板、字形和后绘遮罩检查；普通图解补充标签和完全落入裁切区的必要说明未漏采，审计集合非空。
- [ ] 练习问题和答案分行/分组；从实际MP4检查主图与字幕均不提前揭示答案
- [ ] 无声设计稿注明估算时间，不声称真实声画同步或有声试看

## 成片检查

- [ ] 总结/练习后按项目配置核对结束语，例如“本节课程到此结束，感谢大家观看”，同一音色完整一次；字幕同步，尾字未剪断、未被音乐盖住，片尾余量足够。文稿匹配和静音片尾不算音频验收。
- [ ] 绑定实际MP4与源码哈希，独立探测、完整解码、音轨/时长/字幕验证
- [ ] 从实际编码视频检查全部章节、转场、后段关键词动作和最长字幕
- [ ] 字幕遮挡用原缺陷布局作负向对照并确认能检出；成组调整布局/取景后，重新扫描并复查最终MP4连续过程与真实播放器控制条显示状态。报告绑定当前源码/视频哈希，未闭环遮挡不出片。
- [ ] 正常速度听看记录如实；未通听不冒称已通听
- [ ] 对照新编码片段及前后衔接复核画面与实际旁白；逐点记录解释缺失与修复，未闭环的段落不通过教学验收
- [ ] 品牌原件、首句问候语、片头片尾、Logo比例与全过程遮挡核对
- [ ] assessment-status.json四层各自记录范围、证据、结果、未查项
- [ ] 用户批准只写入真实approval_records.json，不由工具PASS推断

- [ ] 连续画布各段镜头从上一段实际结束姿态承接，段边界位置/缩放无跳变；含中途访问其他角色及回到全局的连续编码片段证据，失败会阻断检查。

- [ ] 最终编码字幕不在数字/单位、范围或系统代号内部断行；分段后语义清楚。

- [ ] 本地播放器首段/后段章节与拖动均实测currentTime正确；HTTP Range返回206，seekable覆盖整片，仅元数据加载不算播放页验收。

- [ ] 无声正文视频哈希与本次已审计的源码绑定，续做/局部重渲后验证；旧正文同帧数不代表使用了新画面。

- [ ] 学员旁白/字幕/图示无“原文/正文/资料要求”等编稿话术，资料缺项没有变成新增业务规则。
- [ ] 字幕行数符合用户要求；单行模式没有滚动保留上一行，数字单位完整，问答不提前揭示。
- [ ] 局部容器替代旧节点时，旧光圈/图标/标题/穿区背景线同步退出；无重复箭头头部，图标、文字与容器语义和对齐一致。
- [ ] 更换配音供应商后记录真实模型/音色ID，不复用另一供应商的名称；鉴权、任务创建、文件下载及音频验收分开记录。余额不足、无任务ID时没有冒称生成或重复提交。
- [ ] 全帧遮挡检查覆盖实际折线、箭头尖端、绘制顺序和容器归属，并以注入穿字线的负对照验证检测器；弱化背景节点也没有透在局部图解的文字下。
- [ ] 末句图示在镜头离开前有足够阅读时间；如延后视觉交接，分别记录视觉起点和原有语音/字幕时点，再查移动中的Logo区与下一题答案时点。
- [ ] 字段别名、映射等制作理解确认已用于统一术语，没有机械变成学员背诵内容；执行规定仍完整讲清。
- [ ] 总览课程标题与角色标题留足间距，缩放后全部必要节点名称仍可读；Logo无空间时隐藏，实际显隐纳入检查。
- [ ] 最新片头片尾的版本、批准记录、原始规格及配乐一并核对；片头字幕没有突兀的正文底色矩形，实际编码透明底与字形对比已检查。
- [ ] 片头收束、首个可听字、首条字幕及正文切换在同一连续编码小样中检查，已记录实际间隔，没有机械延迟到固定秒数造成空等。
- [ ] 字幕白字黑描边、字号适合小屏，最长行安全；中英文/数字/标点使用同一兼容字体和字重，实际字体日志与混排词的字高、基线、风格均复查，明暗背景都清楚。
- [ ] 字幕没有机械截断句意：按完整句子/自然分句切换，课程名称、词语、中英文术语、数字单位、条件及否定词完整；没有拼上下一句的半截，全文重建、单行宽度、短句阅读时间及口播同步同时检查。
- [ ] 实际播放器播放/暂停、普通/全屏状态下，控制条及渐暗层没有遮挡或压暗字幕；必要时在预留安全带内上移，仍与主图分开。
- [ ] 总览充分利用横向空间，列宽与间距舒展，文字/图标不变形；推近/拉回时同一画布连续，标题及字幕避让仍成立。
- [ ] 点名多个角色/区域时，实测口播顺序与对应板块的短暂高亮一致，前后交接清楚，结束回稳，没有无关循环闪烁或同时争抢焦点。

- [ ] 讲解后半句、复核和回顾均有对应教学动作；不是只在首个关键词入场后长停。动作类型及时长有变化，落定文字稳定，必要读图停顿单列理由。
- [ ] 全部新增事件在真实图示区可见，未被后绘容器覆盖、未因原路径同色而消失；从源画布与最终MP4检查起步/过程，排除字幕变化。
- [ ] 动作分散度、无动作占比、构图变化分别查看原始测量；细描框通过不代替动态验收，同路线的旧/新交接物件没有重叠。

- [ ] 详细图展开前仍有可理解的已知父对象，未只剩空框/标题；父对象转入局部容器时旧图形及时退场，无单帧穿字。

- [ ] 局部镜头按条件定位、字段细读、成组比较和实际交接切换，移动后停稳，末句仍有完整读图时间；下一章继承上一章实际镜头位置，无机械归回造成的跳动。
- [ ] 审查页面已加载正文绘制器和真实教学对象，实际文字/对象数量合理；没有用空集合的“零遮挡/零短停留”当作通过。

- [ ] 镜头变化和主物件动作快慢分别核对；更新、展开、比较与交接有不同节奏。改入场时长后，原声同步、解释覆盖、空档、动作速度和阅读时间一并复测。

- [ ] 渲染缓存覆盖实际嵌套依赖；修改source/内画面代码后已强制重渲或按递归指纹清除受影响帧，成片过程帧与当前源码对照无旧缓存混入。

- [ ] 动作统计区分预定主图区域、固定字幕带与品牌头尾；若字幕替换造成光流干扰，保留完整报告，用同一算法/阈值对全正文预定区域复算并记录样本、指纹和限制，未挑有利片段或冒称原始整片全通过。

- [ ] 焦点作用于原元素，文字、图形与容器成组围绕实际中心轻微放大/变色/有限呼吸；无重复选择框、半框、扫描框或装饰勾号。基准、峰值、回稳和交接的连续编码画面已查，保留真实连线并确认缩放后不碰字、不裁切。
