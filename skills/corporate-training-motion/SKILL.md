# 酷果星创企业课程动画导演

版本 **3.4.0**，酷果星创内部分发版，唯一企业课程入口。仅用于酷果星创企业内部课程制作，保留企业名称、品牌、业务术语和案例。仓库公开用于同事安装，认证凭据和个人运行配置放在仓库外。主要职责是视觉、美观、动效、镜头与音效。内容结构、详略、练习和讲解深度在逐字稿阶段调整；发现问题回到稿件，不能靠增加问答、文字卡或延长旁白替代画面质量。当前用户要求优先，历史风格只作可选经验。代码视频导演和艺术动画的导演方法、绘画技法、渲染器及诊断工具已融合在本包，作为内部模块直接执行，不再加载或调用另外两个Skill。品牌头尾是已批准的资源模块。

安装与首次环境检查见[同事安装说明](INSTALL.md)。

## 统一制作流程与职责

所有课程沿一条制作链推进；正文形式与实现技术由内容决定，方法不会随引擎切换而改变。

| 阶段 | 本Skill负责的工作 | 实际产物 |
|---|---|---|
| 新课建档 | 默认运行scaffold，内置工作台、独立启动器、通用画布与可编辑草稿；建立稳定场景/对象/素材ID | workbench.json、native/、editor/ |
| 来源与讲稿 | 查看原文和原图，核对条件、例外、教学顺序与逐字稿 | 原件、规则台账、讲稿 |
| 导演设计 | 为内容选择场景、实物、截图、日历、比较、图表或局部关系图；锁定视觉语言与主动作 | 导演方案、分镜、视觉选择理由 |
| 旁白与时间轴 | 本地Aiden原速生成或复用原带，检查内容后量实际时长 | WAV、真实口播锚点 |
| 画面与动作 | 先构图和主动作，再加必要辅层、镜头和材质；选择通用画布或为内部网页/三维/插画接入统一桥接 | 关键帧、可编辑源码、真实工作台绑定 |
| 动态小样 | 看正常速度有声片段，检查动作、读图、字幕和接缝；新人物先验证设计及动作 | 有声小样、具体返工项 |
| 整课与混音 | 从当前已保存工作台数据沿同一渲染器导出，单行无标点字幕，事件音效与批准品牌包装 | MP4、SRT、编辑数据及源码哈希 |
| 工作台编辑 | 打开本地工作台，编辑字幕与时间、同步裁剪空白区间、句尾停留、登记画面参数和图片；保存历史并用同一渲染器导出 | workbench.json、MP4、SRT、可编辑ZIP |
| 验收与交付 | 检查内容、视觉、音频、布局及编码，分别记录技术结果和真实观看范围 | 当前成片、源码包、QA |

统一默认：字幕单行无标点，画面标题按内容保留；画面按内容选择，不强制大地图或全课唯一相机；新配音为Aiden原速。只改视觉时复用冻结原带。用户明确另选优先。具体确认点沿用已有授权与[确认记录](references/09-review-protocol.md)，不因融合新增审批。

内部职责及调用见[模块结构](references/08-integrated-modules.md)、[视觉与动作方法](references/24-visual-and-motion.md)、[内置工具](references/25-internal-tools.md)、[实现路线](references/26-rendering-routes.md)。目录、模板和最终交付规则始终由本入口管理。

## 内置内容编辑工作台

**每门新课程默认可在工作台继续编辑，这是制作与交付的一部分，不等待用户另行提出。** 开工先运行`scripts/scaffold.py COURSE`；自动生成可直接打开的`project/workbench.json`、通用画布及包内独立启动器。初始草稿尚无配音时可以打开，不能把占位画布导出为已完成课程。

导演方案确定后登记稳定的场景、对象、文字与图片ID，按实际Aiden原速音轨量时，填写课程构图数据并用`workbench.py configure COURSE --spec SPEC.json`接入。通用`scene-graph-v1`按内容自由组合独立场景、截图、图形、日历、比较、流程或泳道，不依赖国补WORLD或固定版式；使用其他网页、插画或三维实现时，由本Skill制作`seek-bridge-v1`桥接，应用登记文字/图片及实际时间轴后再绘制。不能为更换引擎省略工作台，不能把正文文字全部烘焙成不可编辑视频再声称完成接入。

制作中默认启动并展示工作台实际本地URL，字幕、时间轴、登记文字与图片进入真实画面；最终视频从当前保存版本由同一个渲染器导出。交付必须包含可编辑数据、实际画布源码、配音/素材、独立启动器和可恢复ZIP。`check_workbench.py --runtime`验证每个场景可绘制及正反向seek；阶段检查和发布检查会阻止缺失、陈旧或与成片不匹配的工作台工程。编辑后重新导出与复核，不沿用旧版本验证。

具体命令、通用数据与自定义桥接接口见[工作台操作与工程契约](references/27-content-workbench.md)。这是同一Skill的内置工具，不另调另一个Skill、不上传素材、不自动安装环境。旧冻结工程保持原样；需要旧课编辑时再迁移到独立副本，`national-world-v1`只负责历史国补课兼容，不再作为新课前提。字幕改文案不会自动重配音，需要更新口播时继续使用Aiden原速并重新对齐。

## 从素材到视觉决定

先读当前工程、原始资料、现稿、音轨和用户反馈。拿到视频要实际抽看开端、主要内容、转折和结尾，并检查音频/字幕；拿到文档要查看原页和有信息的图片。区分事实、用户有效解释与设计示意，标出未检查范围。制度口径见[来源](references/01-evidence.md)，稿件任务才读[编稿](references/02-teaching.md)。不擅自增加人数配比、工时算法、审批顺序或例外。复杂内容用分步演示、比较和具体情境降低理解难度；扩充解释和案例仍受原规则约束，示例假设不能成为政策。来源、页码和整理过程只留内部台账，不进入学员画面或口播。开场短而自然，说明本课要解决的问题；固定品牌问候与头尾按项目配置保留。

根据观众要看懂的对象选表现：时间范围可用时间轴，排班组合用周历与角色，协作交接用物件流转，操作用真实截图/原型，条件变化用前后状态，概念可用场景隐喻。流程、多角色协作和泳道等内容优先考虑流程图、业务地图或泳道图，但这些及总览—局部—返回均为可选方案；不用一张大地图、固定坐标、一条整课相机轨迹约束所有课程。采用地图才读[地图与原图](references/18-relationship-maps-and-source-images.md)。

制作前给出简短导演方案：内容与受众判断、选择的视觉语言、看得见的配色/材质/字体、核心动作、镜头路线、旁白和音效来源、目标时长。已有授权范围内直接制作。优先复用既有可运行引擎、已确认素材及声音，不安装无关工具，不上传公司素材。

## 画面、动作、镜头与声音

视觉开工统一执行[导演执行](references/12-director-teaching.md)与[视觉动作方法](references/24-visual-and-motion.md)。需要具体渲染或诊断时直接运行[内置工具](references/25-internal-tools.md)，不再查找外部Skill。按内容决定阅读停留、动作密度和景别，不采用模型分档、固定镜头数、强制震屏、强制AI画人物或全课运动率配额。

画面先有构图与焦点：主物件足够大，色彩和明暗有层次，留白有目的，品牌自然融入。避免常驻大黑页眉/底块、无意义编号和制作标签。不是删掉所有容器：日历格、表格、真实系统界面等有业务意义的结构应保留。不得全课沿用一个标题加内容板版式。同类对象在同页共用尺度进行比较，避免逐页记忆后才能比对。删去无用小字和装饰，保留条件、单位及真正帮助理解的标注。

章节名按实际课程目录锁定，以正式、概括的名词短语命名，通常四至六字，必要时更长；同章节跨镜头不换成一句口语结论。旁白保持自然，标题变更不触发重配音。见[章节命名](references/03-visual.md#章节标题与原课程目录)。

人物与其名称作为统一布局组，按真实变换后的完整边界分配行高、内边距和组间距；表格分隔线不得穿过人物列。使用统一、可调的设计间距，不靠缩小人物或文字掩盖拥挤。对全时间轴、移动路径和镜头缩放检查，手与钥匙等接触须有具体对象、时间窗、区域白名单，头部和名称不豁免。执行及验收见[人物组合避让](references/14-semantic-layout-qa.md#人物与名称组合及全时段避让)。

动作表达可见变化：人员进入时段、两人同步锁门、带教与新员工同班、休息冲突被分开、职责移交、范围与上限的区别。只有标题滑入、卡片淡入、描框呼吸或翻页不算主动作。先做主动作，确认起点、过程、结果，再加镜头和细节，最后加声音；返工只改责任层。

镜头为定位、比较、细节或交接而动；总览、推近、跟随、返回按内容使用，移动后停稳读图，保持有意义对象的连续性。不能整段缓推，也不为凑变化频率任意切景。动作速度按物体与事件区分，不统一套一个缓动时长。

声音是实际产物。旁白优先复用已有录音并按完整句/静音边界剪辑，不变速掩盖节奏问题。音效少量绑定动作接触或状态完成，峰值对准事件，不每字一响；可复用合法资产或本地合成。BGM按片段需要选择，不强行铺乐，不与旁白争抢。最终核对响度、峰值、接缝、字幕和关键词同步。

本项目用户于2026-10-19确认后续新配音默认使用本地 **Qwen3-TTS 1.7B CustomVoice / Aiden｜清亮中音，美式英语男声**，原版自然语速1.0，不加慢读指令或变速。中英文沿用同一音色，无需再次选声。参数与调用见[本地Aiden](references/23-local-qwen3-voice.md)；本次明确另选、已有录音和冻结课程优先。通用能力仍支持其他供应商，偏好不等于云调用许可。新文本发给外部供应商须在本次授权范围内，不能从旧课程授权推断新课许可。按需读[Azure](references/10-azure-voice.md)、[发音](references/13-pronunciation.md)或用户指定的[MiniMax](references/17-minimax-voice.md)。凭据不进工程、日志或Skill。

用户要求新人物或主播时，先按真实服装/品牌参考出设计稿，取得当前稿的明确确认，再做代表短动画，确认后才扩展整课。跳过、否定、未回答、只选风格均不自动批准具体人物；批准绑定实际文件哈希。采用A-roll/B-roll时，主播有自己的讲解景别和动作，业务对比画面占据合适篇幅，不当常驻角落贴纸。自然角色动作按[角色与动作验证](references/19-character-performance.md)执行：保持头颈肩肘腕连续及同一人物轮廓，不把插画切碎后分别旋转或拉长；半身与全身共用同一角色和动作时间轴。动作不得超出样片验证范围。旁白驱动口型，记录实际方法；能量/频谱驱动不等于逐音素同步，静音闭嘴、眨眼与头型稳定需动态复查。

## 先判观感，再判技术

先看关键帧的真实设计，再看连续有声片段的运动、节奏与声音。记录最差的可观察问题和时间点，修完再看。视觉方案评价：是否有设计感、主次清楚、动作表达对象变化、景别服务内容、声音收敛且可听。不能以字段齐全、无报错、帧率或哈希通过声称美观合格。

布局采集覆盖所有可见文字、线段/箭头和细长填色装饰；文字—文字、文字—线条/装饰、人物—名称及移动路径分别检查。帧数只说明采样频率，不证明关系类别完整；保留实际失败画面作负例，几何与视觉审查分开。再做[布局与遮挡](references/14-semantic-layout-qa.md)、[媒体QA](references/06-qa.md)：检查转场全过程、角色/图形/连线/字幕区，核对数字、范围、强制与建议、例外。字幕无标点且始终单行：长句按语义切为连续字幕，合理分配时段，保留数字、时间和范围含义。不缩小字号硬塞，不自动折行或滚动保留上一行。用[单行字幕工具与验收](references/20-single-line-subtitles.md)同时检查文本、实际字形宽度、时间和最终编码画面。样式继承已确认项目，白字黑描边可作新项目候选。正常尺寸与小屏缩图都查看；缩图不能冒称实体手机测试。

抽帧、顺序帧、自动转写和媒体测量各有边界；未全程听看不得写成已人工全片通听，用户视觉与学习效果验收不代填。音效/镜头数据与旁白共享实际时间轴。

## 工程、验证与交付

默认中文1080p/30fps，已有规格和用户选择优先。确定性绝对时间绘制，资源加载后才ready；同一时刻正反向seek一致。同一输出只有一个写入者，成功编码及解码后再提交。冻结原音/来源/用户改动；修改Skill先备份并记录实际应用位置、版本和变更文件；发布安装方式见仓库README，安装器保护已有用户配置。内部素材卡只提供局部技法与API，不能覆盖本入口的课程规则。

只要样段就交一个讲完整的小节、有声MP4、SRT和简明工程说明；需要整课再覆盖整课。样段不自动拼接完整课固定结束语或长品牌头尾。[品牌](references/11-brand-bookends.md)按当前项目配置使用；仅酷果项目加载[酷果配置](references/16-kgxc-profile.md)，其中的KG、M1、蓝店员/店长及MyCoach不是通用角色。Logo使用实际资产且保比例。

完整课继承包内KGXC R5/R8品牌资产；使用`scripts/bookends.py --title 课程名 --out 新目录`生成当课换字片段，无需开发机的course-bookends目录。Blender用于编辑随包三维工程。“开场简短”不能被解释为取消已确认固定头尾。最终导出必须核对批准资产清单、实际时长及成片首尾对应画面/声音；有Logo或欢迎语不等于固定片头已接入。详细要求见[品牌头尾](references/11-brand-bookends.md)。

目录遵循[工作区](references/15-workspace.md)，渲染见[实施](references/05-render-pipeline.md)。原课程和旧成片保留；用户要求桌面文件时复制并核对哈希，不用云链接替代本机视频。清理仅按已授权的精确范围执行。

现有脚本按任务使用：`scripts/scaffold.py`建立工程；`validate.py`、`check_visual_plan.py`、`check_course_completeness.py`检查计划和文件绑定；`workspace_check.py`检查交付目录。它们不证明审美、动效或声音合格。地图检查仅适用于选用地图/关系图的分镜，实物演示不为过检查虚构连线；新工程模板不预设唯一地图风格。历史冻结工程不自动迁移或重渲。发布前运行`check_skill_package.py`核对包资源，`release_checks.py`核对单行字幕、资产哈希、媒体和真实人工检查范围。负样例及本次已知限制见[回归与边界](references/21-regressions-and-limits.md)。公开仓库供同事安装，课程与品牌素材用于酷果星创内部培训；第三方素材沿用原许可。

包内运行依赖、内部使用范围和发布计划格式见[打包使用](references/22-package-use.md)。
