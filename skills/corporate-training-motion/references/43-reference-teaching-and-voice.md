# 从参考片吸收讲解、表演和声音

用户提供培训视频并要求学习其表现时使用。先按时间码观察真实片段，分别记录已看静帧、连续动作、声音样段和未审范围；字幕转写或一张截图不能证明整片听看。参考片中的业务要求不自动成为当前课程制度。

学习可迁移的组织方法，用当前课程的已确认美术与角色实现。保留私有参考原片、裁段、转写和克隆参考在本地课程工程；公共Skill只包含方法和工具，不夹带参考片、截图、声音或克隆身份。

## 可按名字调用的四种导演方法

这些是内容导演配方，使用现有工作台对象、镜头和人物通道；不是四种互斥美术风格，也不宣称一条命令能复制参考片表演。

### 讲师引题 → 情境演示 → 回到要点

适合把抽象规则落到操作或服务。讲师先说明要解决的问题，切到同一任务的门店实例，让对象发生必要变化；结果停稳后回到讲师或关键对象，只总结本次差别。观众不需要同时读整章要点。

调用时写清当前口播、引出的问题、示范动作、结果和返回后的一句总结。镜头交接沿同一个对象或问题，不在旁白未落点时随意切到另一事件。扫码可比较同一Mac入库与出库，服务可示范一次邀请与顾客回应；这些只是用法，不是所有课的固定分镜。

### 对话中的“说 → 听 → 回应”

适合异议处理、反馈、管理沟通。角色先有明确意图；说话者看向对方或当前对象，听者闭口倾听，表情在听到对应信息后变化，再开口或做动作。动作与人物自己的对白绑定，不能让旁白中所有人都周期张嘴、同步点头或无目的摆手。

用 `course_tools.py stage-performance COURSE --identity S01|C01 --out ...` 暂存各自原图标定，合入现有 `sceneGraph.materials`。用 `data.performance.keys/targets/blinks` 安排实际词句上的视线、眉眼、点头与已验证手势；用当前景别检查脸和手是否在画内。能力边界沿[人物演出](41-direction-and-performance.md)，不把正面二维通道描述为自然走动或逐音素口型。

### 演示暂停 → 焦点讲解 → 返回现场

适合指出刚才为什么有效或哪里有误。保留同一场景的上下文，降低次要对象的视觉竞争，将讲师或被解释对象突出；只出现当前的一个短要点。解释结束后恢复现场并继续结果，不能把背景模糊当作主体动作。

有可用模糊或镜头通道时按当前渲染路线调用；没有实际实现时用减弱对比、局部取景或清楚的硬切，不声称已实现景深。不能给每个名词都套模糊转场。

### 逐项建立 → 对照差别 → 一句收束

适合流程、条件、指标和多项任务。当前项目随口播出现，已解释项目降为参照；比较时保持对应位置，让学员看见差别。最后集中展示必要的完整关系，保留读图时间。数字应在对应分母和统计对象就位后出现，不能先抛结论再让学员猜对象。

所有配方都先绑定本课口播锚点、对象、起态和结果，再经过当前正常速度预览与编码复核；不复用参考片的时间码、紫色制服、角色身份、蓝底或产品型号。沿用仍有效的白底等美术确认，不自动增加一次美术选型。

## 章节页与讲解衔接

章节页出现时，应有对应的章节编号、名称或等价的任务引导口播。已有一句能明确告诉学员“现在进入什么、要学会什么”，就沿用并对齐；缺失时补一句自然衔接，不能只加静默标题卡。目录顺序、章节页、实际口播和进度条共用章节映射。标题不能抢在上一段话未结束时切走，也不把同一章名连读两次。

## 专业感与情感不是固定高低音

声音的专业感来自清楚的逻辑、标准发音、稳定声线、适度重音和自然收束。提问、邀请、说明、提醒、总结可以有不同的语调，情绪服从句意。亲切不等于撒娇，坚定不等于喊话；“平实”也不等于从头到尾没有起伏。

用户要求保留原男声音色时，先沿用已确认参考生成同课样段，改善文字的交流感、标点、语义分句和节奏。Base克隆依靠参考，不支持用VoiceDesign指令精确改变情绪；不能把不支持的参数写成已生效。重新VoiceDesign的候选可能改变音色，要明确区分并实际试听，不能保证“仍是完全同一人”。

先用同一段实际课程文字对比音色、语调和速度，再冻结选定参考生成少量完整语义段。不要以升调、响度或拉长空白替代情感；不要只按短样本文字速度推算整片。增加课程时长，优先展开条件、动作、结果、对照例子与章节引导；用实际录音和阅读需要对齐时轴。用户指定约12分钟是当前课的目标，不是所有课程的标准。

## 本地参考声音配置

可用 `scripts/voice_library.py` 保存与复用本地参考。它复制参考WAV和对应文本、绑定哈希，已存在的ID不覆盖；生成前重新核验，注册不更改默认声音，也不会将本地库装进发布包。

```sh
python3 SKILL_DIR/scripts/voice_library.py register --id teaching-female --audio REFERENCE.wav --text REFERENCE.txt --label "教学参考女声" --origin "用户提供参考片，已记录片段时间码"
python3 SKILL_DIR/scripts/voice_library.py list
python3 SKILL_DIR/scripts/voice_library.py generate --id teaching-female --text-file SAMPLE.txt --out SAMPLE.wav --dry-run
python3 SKILL_DIR/scripts/voice_library.py generate --id teaching-female --text-file SAMPLE.txt --out SAMPLE.wav
```

默认保存在Skill外的配置目录 `voices/`。参考文本须逐句对应裁段，记录源文件与首尾；ASR可定位，仍核对字幕或实际声音，避免把下一句首音裁进参考。参考含背景音乐时不声称已完成分离，先选择较干净的人声区间并试听实际克隆。注册成功只证明配置可调用，音色相似度、发音与最终用户认可仍待实际试听。

用户明确命名并指定默认男女声后，用 `voice_library.py set-defaults --male 男声ID --female 女声ID --evidence 实际选择原话` 保存。此命令备份原voice.json与默认配置，保留本地运行时路径；未指定性别时使用选定的主声音。`qwen3_tts.py --gender male|female`调用相应默认，`--voice 名称`直接调用命名声音。公共安装包含本次明确授权的didi/pipi推荐参考；干净安装推荐男声didi、女声pipi，默认讲述为didi。其他私有参考不入包，已有本地默认随升级保留。

声音ID支持1至64个英文字母、中文汉字、数字、下划线或连字符，例如 `teaching-male` 或 `示例讲师`；不接受路径。注册后可直接运行 `qwen3_tts.py --voice 示例讲师 --dry-run` 核对所选参考。一次指定不改变默认。升级保留用户配置；换机器须另行迁移用户授权的私有参考库，公共包仅提供已授权的didi/pipi推荐参考，不提供其他私有声音。
