# 扫读层级与教学动作

用于教学视频分镜、画面实现与验收；独立课件只用扫读层级，不强制动画。F 型是内容扫读的观察，不是要模仿的版式或经过验证的课程眼动路线。迪士尼原则用于把动作演清楚，不模仿角色、美术或品牌。

## 第一次看也能抓住重点

- **规则、步骤、知识说明**：标题或已经成立的短结论置于画面上方优先看到的区域，讲到当前步骤时把动作词或对象放到容易扫到的行首。把会改变操作的条件、例外和停止信号放在动作附近，不能放到右下角小字或只靠口播补救。揭示应跟随讲解，不能以“结论前置”为由提前显示未成立的答案。
- **并列对比、图表、流程图**：比较项共享相同尺度和字段标签并靠近放置；流程可以沿关系移动焦点，不必左对齐。首次举例时保留本步骤要用的必要条件；不相关旧内容退场。短标签、分组、留白、字重比让整块文字同时闪现更有效；颜色不承担唯一的状态区别。
- **情境演练、设备操作、空间画面**：主角、手、对象或操作位置带领视线。把标注贴近真实对象，保留必要场景关系；不为凑 F 形挤到左上，不把字幕、进度或花字当正文。仍沿用[阅读与信息节奏](45-reading-and-information-pacing.md)的稳定阅读和回看规则。

## 把动画原则转成课程动作

| 做法 | 对课程的具体要求 |
| --- | --- |
| 调度（staging）与吸引力 | 同一时刻只有一个主教学焦点；先用构图、姿态、视线或层级突出对象，再考虑动效。吸引力来自清楚、可信和一致的形态，不是再加一个会动的元素。 |
| 预备动作（anticipation） | 先让学员看见动作会发生在哪，例如视线先转向票据或手移到按钮边。仅提前建立对象或位置；新结论、数值及结果等真实语义触发。 |
| 关键姿态与连续动作 | 技能演示先锁起态、关键接触和结果，再补中间过程；头发、衣角等连续辅助运动可逐帧处理，但不是教学主线。 |
| 时间、节奏与缓入缓出 | 用实际口播锚点安排动作开始、过程和反馈，速度服从物件重量、操作特点及观看任务。入场停稳不等于读完；解释可继续，正文保留到读完或对照结束。无需给点击、警示或计量变化强加弹跳、减速或统一时长。 |
| 弧线、跟随与重叠动作 | 手臂转向、拿起和递交符合关节与运动轨迹；交接能看清谁拿、谁接、在哪里放。接触后，次要部件可自然收势，不模糊对象归属或盖过结果。界面操作保持真实的直线、点击或定位。 |
| 次要动作、适度夸张、立体感与挤压拉伸 | 只在确能补足信息时用，例如接收者视线、手势、非数值信号的轻微强调。真实设备、UI 热区、证件、文字、数字、关系节点不变形；保持角色比例、物件空间和前后镜头连续。无教学作用就省略。 |

**分镜写法**：在既有 `opening / action / result / focus / reading_design` 里写清“先看什么 → 口播在哪触发 → 哪个业务对象怎样变 → 最后能回看什么”。先画出结果关键帧，再定动作。纯解释段可以用同屏对照、因果连线或焦点转移；不要以硬加动作或每条都套十二项来代替清楚的讲解。

**门店示范：别先抹掉旧机。** 画面保留旧机与新机关系；当讲到“不要先抹掉”时，让伸向确认键的手停下，保持旧机未抹除。讲到“在新机确认记录能打开”时，把焦点移到新机上的验证动作；只在条件满足后展示后续处理，不把操作演示读成无条件授权。可以有轻微反馈，但停手、核对和可见结果是主动作。

## 在现有复核中检查

1. **缩略图或静音扫读**：针对规则页，快扫能否指出本页话题、当步行动和限制？针对演示页，能否指出当前对象和下一眼要看的位置？同时查小字体、字幕遮挡、必要对比及颜色以外的区分。
2. **当前成片动作检查**：看触发前、开始、关键接触/转折、停稳，以及结果的稳定阅读末端。回放关键段，核对真实口播含义与触发，不提前亮出答案；检查辅助动效退让、视线连续和结果是否留够，不用抽帧宣称连续听看。
3. 把不通过处记在已有问题清单并只复核受影响段。设计原则不是新审批、额外盲审、重抽小样或追溯改旧课的触发条件。
