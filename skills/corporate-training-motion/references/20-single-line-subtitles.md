# 单行字幕：处理与真实渲染检查

字幕无标点、每时刻一条一行；画面标题、字段名和业务标注按内容保留，字幕规范不禁止画面标题。保留原文字、数字、时间、范围、条件和否定含义，不把长句缩成摘要。先在自然停顿/完整语块处拆分，再分配连续时段；词语、课程名、数字单位及系统代号不截断。源录音时间与成片偏移单独保存。

本地处理：

```sh
python3 scripts/single_line_subtitles.py captions.json --phrases semantic-phrases.json --out captions-single.json --srt captions-single.srt
```

输入为caption数组或`{captions:[...]}`，每条含id/start/end/text。可选phrases为`{"cue-id":["第一完整语块","第二完整语块"]}`，各语块只能重建原文字。脚本用句读/显式语块拆分，不机械截字。max-em仅预筛宽度，不冒充字体测量。默认字号不变；过长且没有明确语义边界时失败，补充语块而不是缩字。

脚本先转换承载意义的数字标点：`10:00—22:00`→`10点至22点`、`40–44小时`→`40至44小时`、`3.5`→`3点5`、`5%`→`百分之5`。歧义分数/日期斜杠拒绝静默删除，先明确含义。中文数字原样保留；对最终连续字幕与规范化原稿做逐字重建。

原句时间窗不变，内部按语块字数比例分配并对齐帧，是**待听校估计**。可从真实停顿/有授权的对齐结果改边界；看波形不等于听懂停顿。短于0.5秒的拆分直接失败，0.5秒以上仍不保证可读，需看实际语速和句长。不能为字幕改变原声速度，也不能提前显示问答结论。

Canvas引擎可复制`assets/templates/single-line-caption.js`，传入真实安装字体、42px等已确认样式、位置和安全区。适配器只调用一次strokeText/fillText，不使用maxWidth压缩、自动折行或保留上行。它返回实际字形加描边的bounds与line_count；任何越区直接失败。DOM引擎使用nowrap并量实际行框与scrollWidth，libass须从实际编码画面查自动折行，不能只检查SRT没有换行。

调用`validate(cues, metrics, safe)`必须覆盖全部cue ID和匹配文本，逐条检查实际一行与边界。不把预测字符数、空metrics或旧渲染器结果当通过。字幕时间轴独立于人物动作/口型事件，拆字幕不能改变原人物动作或声音。

最后从**本次MP4**提取每条字幕中点及所有新切分边界前后帧，核对残留双行、缺字、叠字和底色；最长行、品牌明暗背景、角色伸手和章节接缝须看完整画面。正常速度有声观看另记范围。技术通过、抽帧看清、用户认可和人工全片听校分别报告。
