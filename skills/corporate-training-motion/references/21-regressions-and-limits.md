# 回归负例与验证边界

保留原缺陷快照、实际失败帧/片段、责任层、源码及视频哈希；这些证据在课程私有QA中，不打包原课程资料。通用包用合成负例验证检测器，不能声称它等同复现每个真实失败像素。

| 已观察缺陷 | 回归检查与修复方向 |
|---|---|
| 换嘴形时整个头轮廓改变 | 固定姿态对闭嘴/开嘴/眨眼头部alpha；再检查点头连续片段，不整头换图 |
| 切碎插画后前臂、掌形变长或脱节 | 肩肘腕与掌形长度、网格翻折、极限姿态及连续播放；用完整协调动作修复 |
| 主播过小、手尖裁切、字幕碰人物 | 半身取景共用原角色；真实变换后的完整边界及最大伸展，先重排或改镜头 |
| 文字与后绘横线/细色条交叠 | 全部实际可见glyph对文字/line/thin-fill检查；注入中途穿字负例，不能排除先画线 |
| 缺少固定头尾但有Logo就报品牌通过 | 哈希清单、实际首尾画面/声音、时长及连续衔接分别核对 |
| 单条字幕无换行却被渲染器自动折行 | 实际行数、glyph含描边边界和编码帧；越宽就按语义拆分 |
| 删除数字标点破坏时间/范围 | 先转换承载含义的符号，再逐字重建；数字负例测试 |
| 零采集对象、旧视频或静帧冒充动态检查 | 非空检查、完整时间范围、源→视频哈希绑定及连续播放证据 |
| 时间输入使用近似1/30秒步长，合法整课时长被浏览器拒绝 | 秒数输入step=any，提交时量化整数帧；验证693.733333秒可提交 |
| 独立渲染并发加载时原课脚本丢失 | 本地服务连接队列128，启动失败最多完整重载三次；资源错误保留日志 |
| JPEG输入将H.264误标为全范围色彩，格式门禁失败 | 编码前显式转换limited并标记tv，核对最终yuv420p与实际画面 |
| UI改了数据但原引擎保留旧对象索引 | 保留原场景对象身份，真实画布应用文字和图片；比较历史原版与编辑版像素 |
| 只导出MP4，ZIP解压后无法继续编辑 | 从包内启动器在新目录开课，再改字幕/停留、保存和导出 |
| 新课上传目录未建立，或上传/保存请求期间继续编辑丢失修改 | 上传前创建media目录；保存等待上传完成并按编辑序号续存；用延迟请求实测上传即保存、保存中改字幕及重开后导出 |
| 裁了配音但画面/字幕仍按原时轴播放 | 整数帧删除区间共用同一映射；验证重复裁剪、跨停留裁剪、PCM样本、正反向定位和重开导出 |

V8沉淀的边界：M1当前有限正面讲解/眨眼/嘴形动作通过了各自几何和抽样动态检查；不代表已支持所有自然全身动作。音量/频谱口型不保证逐音素精度。全帧几何不覆盖所有透明纹理、遮罩及主观自然度。全量解码和静音自动播放不证明听校完成，107条字幕抽帧不等于全片人工听审。导演通用运动指标有剩余提示时保留原报告，按内容判断，不能换统计区域后宣称原整片全部通过。

单行字幕修订保持原声时，内部拆分估计仍需听校；实际设备、播放器控制条覆盖和字体回退未检查时如实列出。打包资产仅限用户内部使用，不证明拥有对外转授权，也不分发系统字体、凭证、原始业务文档或渲染帧缓存。

工作台3.3默认新课使用通用scene-graph-v1或seek-bridge-v1；WORLD国补适配器只负责历史导入。图片替换作用全部同ID引用，字段仅限登记对象，支持画面配音字幕同步裁剪，不提供任意关键帧/片段重排或自动重配音。浏览器端撤销仅保留当前会话，磁盘保存历史留在编辑副本，导出ZIP只带当前版本。详见[工作台契约](27-content-workbench.md)。
