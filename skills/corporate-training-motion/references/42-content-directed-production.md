# 按本课内容导演，复用方法而非成片模板

新课和已授权视觉返修都执行本方法；沿用有效的内容、声音和美术确认。此文不规定某一课的角色组合、颜色、版式、数字例子、总时长、动作数量或镜头速度。共用库提供可编辑的素材和动作能力，制作端仍须依据当前内容作导演判断。

## 一段内容，一条可见的信息变化

从已确认逐字稿问：学员此刻要理解哪件事，最容易误解什么，画面能比文字多解释哪一层关系？确定本段的对象身份、起态、关键过程、结果和例外，再选择表现。新流程每个完整教学片段给出至少三种有实质差异的可行表现与推荐理由，用户可逐段选择或明确采用推荐组合；见[全课分镜与三段抽样](44-storyboard-and-sampling.md)。

可按关系考虑方法，不按关键词自动选模板：

| 当前要看懂的关系 | 可考虑的画面信息 | 应验证的结果 |
|---|---|---|
| 操作与条件 | 接触位置、朝向、允许路径、条件分支、错误停止 | 物件真的改变状态，适用范围和例外仍清楚 |
| 人物交流 | 当前意图、疑虑、看向对象、倾听、回应后的反应 | 先听再答，另一人有反应，必要表情在画面中足够大 |
| 数量与范围 | 同一组对象如何划分，时间窗、集合边界和分母 | 图形中的总量、子集与算式对应，不能用数值跳动替代口径 |
| 资料或任务流转 | 同一个对象的来源、身份、去向、接收状态 | 重排和换镜头后仍能认出同一对象，反馈回到原问题 |
| 查阅与比较 | 当前行、列、字段、前后差异与结果 | 观众能读清、定位；不要求每一刻运动 |

这些是可组合的思考方向，不是固定章节或必须全用的构图清单。同一张表连续解释字段可以保持位置；人物特写、全景或固定镜头都取决于需要看清的信息。不得为增加种类破坏上下文。

## 把观看焦点、人物与镜头排成连续过程

粗图阶段就用实际旁白排动态分镜，先确认关系与切换，再精修美术。每次安排当前焦点、观众从哪里看向哪里、何时获得结果。镜头服务定位、细节、比较或交接；固定镜头也可以是明确的选择。静音查看画面是否传递了额外信息，再在正常速度检查时机。

人物按[人物演出](41-direction-and-performance.md)设计意图、情绪与视线目标。主次轮换，预备、动作、反应与回稳不能都同一速度；点头、手势和情绪峰值须实际在镜头内发生。讲师在叙述时不强行让角色持续张嘴。角色自己没有标定的动作先验证，不把正面二维演出宣称为侧转、自然行走或手部接物。

镜头变化后重新检查文字、标注和主体的生命周期：某个区域标签只在总览有用，就在推进前退场；需要在细节里保留的说明应重新构图。不能留下半截字、把关键表情裁掉，或让连线端点和标签分离。取景变化、局部重排和转场要检查所有复用位置，不只改当前截图。

## 旁白窗口、动作、读图停留各自安排

用真实词句和源帧触发动作。一次交接或转向按自然时长完成，后续解释已完成结果可以停稳。预备让观众知道将发生什么，关键动作给信息，反应或停留让观众消化；节奏由信息难度和注意力转移决定。

不要把整段旁白时长传给局部动作，也不要统一套相同的入场秒数、循环摆动或固定频率切镜。工具中的异常时长提示用于发现拖长，不能代替导演判断；长的真实操作和稳定阅读各有理由。已有原音不可变时，在其实际时轴内设计画面，不暗中变速或重新配音。

## 让通用工具检查实际实现

`resume` 的 `production_handoff.direction` 自动提供本方法入口、当前工程的场景和关键采样数量。需要逐段检查时运行：

```sh
python3 SKILL_DIR/scripts/course_tools.py direction-check --spec COURSE/project/workbench.json --out NEW_REVIEW_PLAN.json
```

它读取当前保存的逐句口播、对象、动作与前后状态，按实际关键帧产生检查计划：动作过程、人物表演关键姿态、变换和显隐边界、停稳以及下一场开始；保留源帧与编辑后显示帧映射，剔除已裁掉的源帧。也会返回重复构图线索。它不按课名或关键词选模板，不修改工程，不把计划标为验收通过。

实际动画可能在缓动过冲、遮挡或手部最大外延处出现问题。工具列出的帧是候选，不保证穷尽峰值；制作端继续在 `scene.reviewFrames` 或动作beat的 `reviewFrames` 补充实际发现的源帧。检查全幅与缩略图，必要时查看相邻连续帧。自定义原生路线的额外关键时刻同样明确登记。

## 验收分层，问题回到责任层修正

| 层次 | 必须有的证据 | 不能据此推断的结论 |
|---|---|---|
| 内容与动作对应 | 本句对象、用途、状态和结果，真实词句锚点；难点的表现选择理由 | 动画数量多就讲清了 |
| 真实实现 | 本地对象前/中/后状态、运行回执、最终编码目标隔离像素；预览与导出同源 | 全画面变化就是主体在动作 |
| 镜头与画面 | 实际编码的动作峰值、视线/手势、标签边界、文字避让、接触、残留与下一场 | 固定场景中点或外框比例能覆盖所有视觉问题 |
| 节奏与工艺 | 正常速度观察的实际范围、具体时刻和问题；构图、字体、材质、留白与听感依据分项记录 | 自动播放到结尾、ASR、哈希或自评分等于全程人工听看 |
| 可继续制作 | 包内实际编辑器重开，改字/移动/换图有画面变化，并实际导出 | ZIP可解压就证明可编辑 |
| 用户认可 | 用户对当前版本的真实反馈 | 制作检查通过就已获最终认可 |

灰色描边、细线或弱变化应从编码后的目标区域验证可见性；不要写死通用颜色或为了过检查放慢动作。局部修补先证明只改变声明范围，再对当前最终视频重做受影响证据与版本绑定。

完整规则沿用[整课动效](32-full-course-motion.md)、[课程工艺](36-course-craft.md)、[封面交付](37-cover-and-delivery-finish.md)和[逐场视觉检查](39-visual-hygiene.md)。一次有效检查绑定当前文件即可；发现新问题或修改后再复查，不能虚构观察，也不增加额外用户审批。

## 后续课程的迁移检查

新课使用当前自己的逐字稿、原始资料、对象、风格和真实时间轴，不导入旧课分镜生成器。确认全课分镜后分层随机抽三个完整片段，保存候选池与种子再测试，不能挑好看或容易的片段代替；结果应表现出当前任务的关系，而不是只改旧例标题。验证一段操作能动，不代表对话、统计或阅读都适用同一做法。工具的合成回归只证明入口、采样和编码契约，不承诺新课自动达到审美或学习效果。
