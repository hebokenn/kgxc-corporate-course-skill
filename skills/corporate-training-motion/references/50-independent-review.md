# 独立学员盲审与执行监督

用户要求保留原文、ID与依据，并显式登记适用阶段和职责。内容要求由制作端核验；隔离、职责、通道、预算和执行顺序由独立监督核对。后续阶段义务仍保留为待执行，不能要求逐字稿证明未来成片已经完成。监督依据当前已验证结果和拟执行动作，区分内容待修、合法停留与越过阻断；有未解决内容问题不等于执行违规，强行放行或虚称成功必须阻塞。制作端使用可回查的逐字正文及来源引文，概述与省略号拼接不能作为原句证据。

适用于继续或新制作的课程。四个正式节点是逐字稿、全课分镜、实际有声小样、当前完整成片。制作端先完成自己的来源核验与制作预检，再提交当前阶段的成品；各阶段唯一一次盲审新建独立 agent，禁止继承制作上下文。只审当前已选方案；未选备选与未来阶段不纳入验收。技术预检、盲审、用户确认与正式交付分别保存。


用户明确授权以效果优先、临时取消本课调用与返修次数门槛时，记录真实答复来源并启用仅本课可恢复的临时不限模式；保留旧上限及全部累计，不改变新课默认、质量检查、隔离或模型通道。恢复有限模式后继续按保留的累计与原上限判断。已有独立token预算不会因此取消。

## 一次盲审与固定清单验收

每阶段当前选定方案只盲审一次，不按新文件哈希、返修次数、刷新、升级或“次数不限”重置。修复改变字节意味着新证据需要验收，不意味着独立学员必须重学全课。旧阶段已有有效盲审时，保留原始报告并从既有清单继续；不能升级后为同一方案补开一轮。

流程为：制作端完成输入质量与来源预检 → 一次独立盲审 → 总导演汇总固定问题清单 → 一次集中自动修复 → 一次定向验收 → 沿用真实用户确认。没有问题时无需制造返修。未闭环则保留成果和卡点，等待针对未解决项的明确后续动作；不能自动循环执行整个评价。用户明确改选实质新方案或明确另审时才可记录新周期授权，不能由制作端自称方案改变。

### 问题标准与停止条件

每项包含稳定 ID、阶段、具体位置/时间码、原文或同字节媒体证据、学习影响、严重程度及可观察的验收条件。验收条件描述应达到的行为，不写替换稿或补丁。缺少证据的猜测与个人喜好不得升级成阻断项；正常作品可无问题。

| 等级 | 判定依据 | 处理 |
| --- | --- | --- |
| 阻断/严重 | 事实或关键条件错误、核心步骤不可执行、学习结论误导、关键内容无法读懂/听清、缺失已选方案必需对象或实际能力无法验证关键项 | 修复并给当前证据；未解决保持卡点 |
| 一般 | 可定位地增加理解负担，例子/过渡/信息组织存在具体缺口，局部重复妨碍理解 | 在同一批次集中处理，记录验收结果 |
| 建议 | 不影响正确理解和使用的风格偏好、额外媒介或扩展内容 | 不阻断、不强迫换方案、不自动增轮 |

总导演合并同源问题并说明取舍，不能悄悄删去严重问题。制作端逐项记录修复位置、当前证据、已解决/未解决/有依据的不适用；不能只写“已改好”。定向验收只看固定清单、既有用户要求及修改直接引入的回归，新增回归须指出改动与症状的关系。不重新做全课开放评价、不要求未选备选达到成片标准、不以风格偏好扩大范围。独立监督只核对真实执行和权限，不触发第二轮学员评课。

### 逐字稿质量前移

先准备来源—任务—情境/例子—动作与依据—结果/反馈的简明对应，再写可直接口播的稿件。每段应新增事实、解释、示范、判断依据或练习反馈；必要导入/转场/总结只承担一次清楚作用。制作端先读稿自检自然度与重复，确定性程序检查品牌问候、占位和明显重复；程序不冒称已判断语义质量。不新增一个“质量预审模型”替代被取消的审阅循环。酷果正文开头保留已确认的酷果星创问候，原件和品牌约束由制作端核对，盲审者不接收私有答案。

## 三种角色的实际边界

| 角色 | 可以拿到 | 职责和输出 | 禁止 |
| --- | --- | --- | --- |
| 制作 agent | 原件、用户要求、确认、工程和审阅发现 | 核验业务事实、教学取舍、导演与制作；修改后生成新成品和版本证据 | 自己冒充独立盲审，替用户确认 |
| 学员盲审 agent | 当前阶段成品及其中本就存在的信息；同一视频字节的衍生证据 | 从成品复述内容与所得，报告可定位的问题和无法验证项 | 原件、目标答案、制作历史、其他阶段稿件、旧评语；写文件、改稿、输出替换文案或补丁、批准阶段 |
| 监督侦探 agent | 当前用户要求、角色与访问范围、实际执行事件、版本/调用/导出记录 | 核对指令传递、真实执行、角色隔离、当前证据和未解决问题 | 修改课程、代替盲审、编造成功、替用户确认 |

用宿主真实 agent 服务建立独立身份。审阅者从空白会话启动，工作目录为中性的隔离目录；不加载项目指令、全局历史、原件或制作会话。仅开放绑定当前成品的只读工具，禁止全局文件、终端、搜索、网络与子 agent 工具。工具授权与上下文都须强制隔离，单写一句“不要看原件”不算完成。宿主缺少可验证的隔离能力时停止审阅并记录缺项，不能退回让制作模型自己审。

监督者从开始、进展、失败到结束独立跟踪实际生产事件，登记自身 agent/session 身份；只写监督报告。它不把预期结论透露给学员盲审者。总导演接收两类报告后安排制作端处理。

执行证据区分工具请求声明、已提交工具返回与宿主独立文件检测。写入目标来自实际工具参数，保留来源与可解析范围；受支持的基线匹配、版本、备份数量和输出目录须保留实际值，不能只给类型。正文与任意参数不直接转给监督，不能解析的路径、补丁或返回继续标为无法验证；补齐证据后重新核验，不追认此前的失败或暂停。

## 每个节点交什么、查什么

| 节点 | 唯一成品输入 | 必查内容 |
| --- | --- | --- |
| 逐字稿 | 当前逐字稿文字 | 口语是否自然、表达是否具体且有新增信息，是否有同义反复、空泛口号和无作用过渡；首次阅读能否理解主题、术语、前因后果、步骤、条件、示范、练习与反馈；能学到什么、实际能做什么；依赖未提供附件或空泛要求的位置。只能评价文字和表达可行性，不能声称看过实际画面。 |
| 全课分镜 | 当前完整分镜成品；内嵌旁白、示意图及导航标题/目录的安全可见帧窗与已有显示状态均属于成品，不因过滤制作上下文而遗漏 | 讲解推进是否带来主体对象、信息或焦点变化；每段起态、过程、结果及节拍是否清楚；长静止页面、机械套版、已选方案中的机械重复、演示缺失、阅读被打断和无目的装饰。分镜检查的是计划，不能声称看过实际动画。 |
| 实际有声小样 | 当前小样视频；同一视频解码产生的帧、音轨、识别文字可作衍生证据 | 片段讲什么、学到什么；视觉风格、构图、文字、人物演出、音画节奏与技术异常。只评价实际片段，不要求它证明未给出的全课。 |
| 当前完整成片 | 当前全片视频及其本身的衍生证据 | 全课主题与可迁移的学习所得，章节/因果/练习反馈衔接；逐场视觉、表演、视听节奏及完整结尾；是否存在只靠口播推进而画面长期停滞。 |

每个 agent 先用自己的话回答：**这是什么内容；讲了哪些东西；我学到了什么、现在能怎么做；哪些地方仍不明白。** 再报告具体问题、严重程度、影响、定位和证据。正常作品可以没有发现问题，不为凑数编造。发现问题只说明哪里与为什么；不写改后全文、替换句、patch 或精确编辑命令。制作端自行设计修复办法。

## 总导演的视觉与节奏检查

- 教学：实际任务、例子、条件和错误反馈是否连贯；图解或演出是否解释当前句意。
- 画面：构图与留白、层级焦点、字体大小与对比、字幕安全区、色彩和插画一致性、封面识别与标题导航。
- 人物：完整形体、不同外貌、同人跨场连续、双方同场可见、正确朝向、听完回应、支撑接触与前后遮挡。
- 变化：把每个讲解要点映射到对象起态、动作过程和可见结果；信息逐步加入、比较、聚焦、反馈都可以构成有效变化。同一场景可有多个节拍，不机械按秒切镜；字幕、进度条和装饰移动不能代替主体演示。
- 节奏：动作完成后能停稳读懂；旁白转入新要点时画面有对应变化；排查长时间不变、空等、慢放、突然替换、频繁切换和过度强调。
- 视听：声音自然、完整尾字、字幕和口型对应、音效落点与强弱、转场衔接、画面空白/闪烁/裁切及编码异常。

导航自身的问题用 `method: storyboard_read`、`locator: input.storyboard.navigation.<实际字段或数组索引>` 和当前安全可见值的精确 `quote` 定位；不混入 segment_id、option_id、beat、time、sha256 或其他字段。错误路径、敏感/缺失值和不匹配引文继续阻断，不能用哈希或估算时间代替证据。

分镜投影仅白名单保留导航的已有结构化可见信息，未知或未设计的覆盖/退场状态不能补造。原件、资源路径、教学目标、目标答案、制作要求/历史与选择回执继续隔离，自由制作说明不能整段穿入盲审。审阅边界实现改变后遵循原有绑定重新核验；相同正文的真实内容确认仍按实际成品哈希保留，不追认旧报告。

静态分镜不能证明动作已实现；关键帧不能证明整个过程自然；ASR不能证明结尾没有残音。当前通道若只支持文字与图片，就记录实际看过的帧、对应时间与识别范围，不能伪造 full_av 或声称完成连续播放。

## 当前课的用户听审分工

默认仍由可验证的完整视听能力检查相应关键项；能力不足保持无法验证。用户可明确选择本课采用 `visual_ai_user_audio`：AI审文字与画面，用户听音轨。保存真实选择、身份及来源，仅改变职责分配，不改变模型或计费来源，也不代表用户已听过。缺省课程不自动启用，制作端不能替用户选择或代记听审。

- AI审阅者仍为空白独立身份，只收到当前成品、同字节衍生证据和公开职责范围；不收到用户原话、原件、教学目标答案、历史和旧评语。文字、静帧、帧序列与技术检查的范围如实记录，未实际连续播放不能称连续看片。
- 声音自然、语句完整、残音和完整结尾、音效听感及声音与画面配合交用户实际播放检查。技术解码、时长、音轨存在和峰值等仍须实际验证，不能因分工而跳过；画面长期停滞、表演和阅读等视觉关键问题也不得转记为听审事项而放行。
- 小样须覆盖当前登记的全部小样，全片须覆盖当前完整视频。用户声明绑定每个文件当前SHA和从头至尾的实际范围；缺一段、部分试听、旧版本或媒体变化后均不沿用。安排选择不构成声明，推荐、预选、关闭、沉默、超时、全程委托和制作代理报告均不构成实际听审。
- 复用原有小样/全片确认同一次动作，让用户明确声明“已完整播放当前全部小样/全片，声音与音画配合无问题”，或记录真实聊天中的同等明确答复与来源。普通确认没有相应声明不能继续。报告问题时保存反馈，留在待修状态，不自动批准。
- 切换职责前核对实际执行状态。failure可能只是可恢复错误，不能独自当成任务终止；当前暂停且已有明确、匹配原制作身份和操作的原生终态回证时，才按原接口保留历史并恢复设置。未知或仍活动的任务继续阻断。
- AI职责范围通过、用户实际听审与原内容确认、桌面正式交付分别保留。旧原始报告和无法验证项不改写为通过；升级、切换分工和重开不清零累计，也不追认旧版本。


## 版本、返修与恢复

已核实原生 `turn/end` 因 Codex app-server 错误而结束时，保留 `failed/error` 原种类、错误和未知用量，通过正常事件追加同一制作身份、操作、step/turn、seq、时间与来源观察回证。在暂停且全部调用已结算后可继续原授权设置。工具错误、缺少终态、错误身份或序列、后续仍有进展的任务继续阻止；失败本身不表示已经结束。

制作核验总等待默认10分钟；如需调整，只能在本课暂停且正式审阅和生产监督都无未结算调用时显式设置并保留旧值、依据和身份。次数不限不自动延长等待，适配器idle、RPC等待与核验总等待分别核对。新核对包和监督摘要记录实际设置，旧包和既有报告不重写；取消与暂停始终有效。无事件超时不自动证明额度、鉴权或模型根因，也不能造心跳掩盖静默。

制作端核验沿用实际绑定的制作agent，仅本次出站投影为完整当前核对包与原生系统指令；保留持久会话、原生身份、原模型通道和配置，实际发送记录不得把排除的历史当作已发送。分镜阶段可去掉不能编辑的工程副本和重复旧报告，完整必要原件、讲稿、方案、要求及当轮发现不能截断；旧包和新尝试按各自路径与哈希保留。已接受盲审之后发生的制作调用失败，只有最新失败轮、完整输入与协议绑定仍一致、无已提交制作报告/实际返修/在途预约时才能显式同轮恢复。旧失败与未知用量保留，新调用继续累计，随后进入实际制作核验和监督；不能用恢复动作跳过任何质量门槛。成果改变后沿用已冻结的问题清单，以新版本证据做定向验收，不重新启动盲审。

**宿主核对实际请求，再绑定审阅报告。** 适合独立审阅或生产监督已经读完当前成品、却因手抄长版本编号错误而被拒绝的情况。宿主先核对本次注册调用、冻结输入、实际原生输入与零工具边界；只有报告确实未提供绑定字段时，才附上已核实的本次绑定。模型已提供的空值或错误绑定继续拒绝，真实成果变化仍由后端阻止。原模型正文与宿主封装分别留档，历史无效报告不追认。该检查是原生应用调用边界的证据，不声称捕获供应商最终 HTTP 请求。

报告绑定阶段、成品字节哈希、盲审协议、实际 agent/session 身份、允许工具、访问记录和模型通道。原件一致性保存在制作端私有核验中，不送入盲审包。旧有知情审阅保留为历史，不能重新贴上独立盲审标签；相同内容的真实用户确认仍保留原话与来源，不冒充新点击。

制作端收到一次汇总的问题后，在原有授权与累计限制内集中修改，保留前版与差异，重新导出受影响视频；随后仅核验冻结问题与本次修改的直接回归，逐项绑定新成品证据。不再次创建独立盲审者，也不将制作验收改称盲审。次数、耗时、用量和失败不因重新打开、升级协议或继续审阅而清零；达到预算或无法验证关键项时保留成果与卡点。模型与计费来源沿用用户设置，无自动切换。

默认不新增无限审批；各阶段沿用用户已经明确的内容选择与委托。用户确认、AI检查结论和桌面正式交付始终分别记录。用户要求先改规则并暂停时，先停止真实生产，保存暂停证据，完成规则与隔离执行验证后再恢复。

## 当前课免人工配音审批

用户明确要求配音无需本人审核时，记录真实来源并选择 `visual_ai_producer_audio`，只改变本课音频审批责任。制作端按当前媒体字节完成自动技术检测，独立学员按实际文字、帧和帧序列能力审阅。工作台显示免人工审批及未执行连续听审，不再索取逐句试听或用户音轨声明，不生成虚假通过。主观自然度、残音与连续音画配合不由ASR、波形或解码结果冒认，关键未知继续阻断正式放行；候选制作可继续，原有内容/视觉确认要求、版本绑定、隔离、预算历史和通道不变。
# 发送前实际能力与完整白名单

先执行[共用执行合同](55-execution-contract-and-release.md)的能力预检。`plugin/review-preflight.mjs`用当前`llm.prepareCall`核对合成通道，并实际尝试最小PNG附件入口，回执保存在本课`qa/review-capabilities`；这不是课程盲审，也不是模型已收到/看过图片的证明。正式调用前关键能力缺失返回`REVIEW_CAPABILITY_MISSING`，不换供应商。制作可以保留候选，不能把缺失能力填写为通过。

`review_preflight.require_clean`与插件发送边界扫描完整白名单，包括本就允许的分镜action等文字内部，拦截隐藏的UV/PILOT返修历史及私人路径，返回`REVIEW_INPUT_CONTAMINATED`。当前解码抽帧保存实际主流帧号，不用输入寻址时间冒充帧。发送前停止与已发生/不明的调用分别记账；已经消耗的同方案盲审不能借修包、改哈希或升级重置。
