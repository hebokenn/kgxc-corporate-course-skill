# 融合视觉、艺术与动作方法

此页与12号导演执行共同构成本Skill的制作方法，不再转交其他Skill。先明确观众要理解的对象、关系和变化，再选择构图、动作、镜头与材质。画面标题按内容保留；口播字幕始终单行无标点。

## 内容怎样变成画面

| 内容 | 优先考虑 | 可替代的表现 |
|---|---|---|
| 流程、条件、退回重提 | 局部流程图或业务地图 | 真实操作、物件状态变化、场景演示 |
| 多角色协作、泳道、责任交接 | 泳道图或关系地图 | 同场景角色与材料交接、系统联动演示 |
| 时间与排班 | 时间轴、周历、角色进入时段 | 门店场景与时段变化 |
| 操作、票据与证据 | 来源截图、实物全貌与字段近景 | 可核对的原型演示 |
| 对比、范围与限制 | 同尺度并列、区间、前后状态 | 实物对照、图表 |
| 概念与机制 | 具体例子、物体动作、白板推导 | 图解、插画场景 |

地图是可选方法；流程、多角色协作和泳道内容优先考虑地图/泳道图，最终仍按教学效果选择。地图可服务一个段落或业务单元，不默认覆盖整课，不要求唯一世界或相机。选用地图后保持该段的节点身份、关系语义和空间连续。

## 统一的画面与动作制作

1. **锁定视觉语言**：按题材和品牌确定配色、字体、材质、光和构图。内置绘画材料含35种风格及财经图表、白板、机制推导、调查桌、叙事、发布会、动态排版、科普等动画语法；按本课重新设计，不照搬示范内容。
2. **先有具体对象**：有真实截图、表单、商品或照片时优先利用其教学信息；代码承担标注、局部揭示和动作。概念用可观察的物件变化表达，不堆满抽象字卡。
3. **主动作先成立**：移动、重排、交接、核对、提交、退回、限制落定各有起点、过程与结果。原地漂浮、描框呼吸或标题淡入不能代替业务动作。
4. **再补必要辅层**：道具跟随、接触反馈、材质细节和背景层次服务主焦点。快动作与稳定读图交替；动作在被讲到的词句触发，按物体和实际事件完成；不要从段落总长反推移动或描线速度。动作后的阅读、解释与顾客反馈分别安排。不能用慢动作覆盖率、全片镜头数、每秒事件数或运动率配额代替关联。
5. **镜头有目的**：定位、比较、细节、交接才移动，移动后留读图时间。推近后可以拉开、横移或换景；不每句话都推镜，也不整段不停缓推。稳定读图的画面仍需有清晰焦点和内容推进。
6. **人物保持身份与动作连续**：复用已确认角色；矢量、插画、已有录影或生成帧按任务选择，不统一强制AI生帧。新角色按本课程的确认流程，既有批准角色不重新做三方向选型。

## 时间与声音

旁白先于精确分镜时间轴：本地B2已选速度或已确认录音 → 内容检查 → 真实起止与锚点 → 动作和字幕。音乐仅在内容需要时使用；有音乐再测节拍，动作结果与接触音对齐。音效在画面动作成立之后制作，最后混音。不要通过变速旁白或固定句间空白来适配画面。

## 静帧、动态与返工

先查关键帧的设计、真实字形、信息层级与对象避让，再看正常速度有声小样的动作、镜头和阅读。内部QA提供确定性、运动、效率、框景等线索；不把像素运动量直接当成审美批准。返工写明时间点、可观察问题、责任层和修正，保护已确认内容、原带和品牌资产；只重做受影响部分，再检查最终编码片段。
