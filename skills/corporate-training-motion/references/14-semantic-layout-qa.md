# 14 · 动作含义、人物工服与图形遮挡

## 先验证动作是否表达了事实

用“动作前 → 变化过程 → 可观察结果”描述每个事件，并查看真实三态画面。

- 更换工服：同一人物的衣服实际变化，脸、发型与身份保持。颜色、袖型、胸标按用户资料；不能用一件大衣服遮住头部，或把衣服平移到人物前方当作穿上。
- 人员参加会议：人物走到会议位置，保持正常大小和间距。人物不是交接物件，不随通用道具容器缩小、递到另一个人手里。
- 核对金额：POS与单据形成对应关系，等号或核对标记位于图解区；说明位于单独阅读区，不能跨桌沿。
- 库存点数：画面数量若为类别示意，应与来源类别对应，不暗示真实库存件数；箱体用箱盖、封条等结构，不反复画成有横线的文件。
- 抽查：放大镜有镜片、镜框和连接的手柄，并落在被检查的表格上；孤立圆圈无法独立证明“检查”。

一个事实只设一个主要图内标签。底部已有完整说明时，删除重复的红色概括，或合并为一处；不要用重复标签填空白或增加动效。

## 人物身份、衣服与强调色分开

人物模型分别设置 `identity / role / outfit / pose`。不要用红绿强调色推断人物岗位，也不要换衣色就自动换脸、头发、性别或眼镜。可爱人物维持统一比例和表情语言，以姿势、发型和身份特征区分，避免靠重复人物填满画面。

酷果星创当前用户确认的工服（2026-10-16）：

- 店员：蓝色短袖；所给实物照片为偏浅蓝灰，胸前浅色KG标识。采用原KG图形，按工服参考使用浅色版本；角标与门头仍用原企业Logo，不把工服配色扩散到所有商标。
- 店长：黑色衣服，胸前白色KG logo；与MyCoach的胸标分开，不混用。
- MyCoach：黑色翻领短袖，胸前浅色 `MyCoach` 字样。角色需要被识别时，另有清楚的岗位标签。
- 照片用于本课程的形制、配色和标识位置参考；取样色是插画近似值，不称为官方色号。人物保持本课已选卡通风格，不自动换成照片中的人物。

私有参考照片留在获授权的项目资产中；可复用Skill保存规范与引用方式，不打包用户个人照片。其他企业和新项目重新读取品牌资料，不套用酷果工服。

## 检查完整的图形层次

文字框不交叠只是其中一项。另检查：文字与表格线/桌沿/箭头/印章、衣服与人脸、人物与人物、道具与标签，以及转场遮罩中的旧/新内容。

1. 先划分标题/导航、操作图解、解释文字、字幕区域。给文字真实字形高度、描边与圆角留出余量；1080p画布可从24px间距起步，最终以真实画面为准。
2. 日历和单据的装饰横线只放在空白数据区，避开标题与状态标签。把线放在文字后面仍可能形成划线，不能算修好。
3. 桌沿是一条图形边界，说明文字应完整位于边界下方；物件和核对符号完整位于上方。不能把说明挪入字幕或播放器遮罩区域。
4. 记录关键图形的世界坐标包围盒或描边线段，应用与绘制一致的缩放/平移/裁切；对有意义的文字与人物头部作碰撞复查。设计中的容器背景承载文字属于允许关系，须与穿过字形的前景描边区分。
5. 不要在入场阶段隐藏所有检查框来掩盖真实遮挡。正常阅读状态与转场状态分别检测，并保留过程帧供实看。
6. 单独检查后来绘制的实色横幅、卡片和遮罩是否盖住先前文字。按绘制顺序记录可见字形与填充区域；进入动画中被辅助函数移出文字审计列表的文字仍须检查。横幅可以承载自身文字，但不能覆盖单据原标题。为横幅和单据标题预留独立区域，并以原缺陷作负向对照，证明检查确实能发现这类错误。

## 修订回归与证据

用户截图对应的时间点逐一建回归项：旧问题、修改位置、动作前/中/后三帧、实际MP4抽帧与复核结果。高风险的换装、交接、收拢和缩放窗口按最终帧率采样，整课继续查章节边界、文字与人头。

可自动比较同一人物换装前后的脸部像素一致（可允许逐通道1级抗锯齿舍入误差并记录最大差值）、衣服区域像素改变；同时检查真实场景中没有额外衣服覆盖脸。单独组件测试不能代替合成帧。图标完整性需检查关键结构及指向对象，不能仅看脚本里出现了“放大镜”名称。

用户只改视觉且要求保留声音时，直接复用冻结音轨；修订前后核对原音、母带、SSML、时间轴与字幕哈希，避免无必要的重配音。最终MP4重新解码、检查音画时长、实际编码画面和播放；报告绑定本次视频与源码哈希。旧版完整动态扫描不能冒充本版全部复测，局部复核写清覆盖范围。

## 整课复检：覆盖从首帧到尾帧

用户要求整课主动排查时，不只回看其截图或列举几张关键帧。建立覆盖所有章节和全部入场、退出、缩放、交接、转场的检查：

- 从实际 `fillText` 绘制调用记录字形内外的对比采样，完成全部后续图层后再比较，检测实色块、线条、图片和道具造成的字形损失。避免依赖会被入场辅助函数删除的文字框。记录检查的字号、透明度、采样和损失阈值；可见像素采样不是所有像素的绝对保证。
- 人物面部与身体均比较后续图层前后；配合人物相互间距、文字边界与描边检查。正常握手等有意义接触可记录为设计关系，不能概括豁免所有人物遮挡。
- 检查画布边缘，不让半截班次、期限或条件名称先从画外伸出来。保持整张卡片在安全区内入场；数字和时间完整出现，避免遮罩把“13:00”变成不完整数字。
- 为主卡展示区、星期标题行、周表小卡行分别留出区域。大卡不能在缩小归档时穿过星期或其他小卡；可在展示区退出后，让小卡在对应日期格内出现。
- 查背景图形之间的覆盖：如预排班输入卡进入时，不应从日历标题或其他活动图标上方横穿。放大镜检查数据区，避开单据标题；异常提示等旧图解缩到安全区域后再入场。
- 至少保留一套连续的整课缩略图供人工逐章查看，并将机器候选展开看真实大图。处理有意退场时，优先不再绘制已经退出的内容，不用先画全文再用大背景遮盖的方式制造虚假的持续遮挡。
- 完成修改后冻结代码，再做最终完整帧率的整课复测和实际MP4抽帧验证。记录视频、画面代码哈希；原先报告只作为问题证据，不能贴上新哈希当作新测量。最终报告区分逐帧像素采样、人工静帧查看、浏览器播放和听音验收。

## 店长角色补充

店长穿黑色衣服，胸前白色KG logo；MyCoach黑色工服印MyCoach，员工为蓝色KG。身份、职责、衣服颜色与胸标分别建模并检查，不能因两者同穿黑色就混用人物。新增规范写入角色表；对已冻结课程是否重制以当前用户范围为准，本次工程整理不擅自改变成片。

## 系统状态图的具体回归

如果概览图的节点在局部展开时被新容器替代，要同时停用原节点的光圈、图标、标题和穿过该区域的背景连线，不能只藏图标留下空圆，再把不相关文字堆在圆上。有效时间、系统延迟和门店提醒各使用语义对应的图标与容器，图标/文字行居中对齐，交接只保留一条清楚的连接关系。灰色背景箭头和前景高亮箭头不得重复叠头，线段不得穿过文字、时钟或卡片。字段核对高亮在文字下层绘制；不能用文字框互不重叠宣称图形或箭头遮挡已通过。检查动作开始、中段、落定及转场的真实编码帧，逐项记录对象与线的关系。

## 已验证的连续地图回归方法

固定在屏幕层的课程标题、角色栏名、Logo和字幕也必须纳入检查。只给正文文字函数打点、另用原生fillText画固定标题，会把标题排版漏出审计范围；零发现结果因此不能证明无重叠。总览增加“必要节点名称全部可见”和标题/角色间距检查，Logo按实际显隐与可见边界判断，不用一块永久预留区反过来裁掉角色文字。降低地图缩放后检查字号阈值，不能为了留白把节点名称悄悄隐藏。

文字框互不重叠仍可能有折线穿字、箭头重头、后绘形状盖字或图标挤出容器。当前画布引擎可在每帧记录文字框、实际折线路径、后绘填充、箭头尖端、绘制顺序和对象归属；只有后来绘制且完全覆盖文字区的实心底板才能遮蔽背景线。把图标内部几何与正文容器分开，避免把信封、显示器的内部形状误判成文字容器。

扫描完整实际帧率时间轴，并注入一条穿过可见文字的测试线，确认检查器能检出后再信任零发现结果。共同路由只保留一个箭头；垂直流程的入/出端口分离，正文连接线停在完整图标和标题之外。局部替换旧节点时同时清除旧光圈与旧边，不能仅把新容器盖上去。

最后一句旁白结束不意味着最后一条图示已经读完。可延后下一段视觉交接，保持原音轨和字幕时点，并记录实际视觉起点；镜头推移期间新标题可能经过Logo区，须重新扫描交接过程，必要时等镜头落定再展示标题。上述方法在商品价格调整课程的正文全帧几何扫描通过；这仍不代替最终编码动态图、图标语义及声音接缝听审。

描边字幕的边界与实底框检测分别处理。较厚描边会提高总墨迹密度，不能仅因总填充率变高就误判成不透明底板；读取实际样式的BorderStyle/背景设置，用纯字形填充蒙版检查实底框，再以含完整描边的蒙版量安全区。字体、字号或描边改变后，对每条字幕重新测量，并从实际MP4抽取全部字幕中点复查。字体与几何通过后，还须在真实播放器检查控制条及渐暗层，不能用原生抽帧替代这一层。


## 连续地图与字幕带的边界回归

出片前主动检查整课，不等用户提供截图。推近、平移、拉回的运动过程与停稳读图都属于检查范围；当前内容以及仍可见、承担前后关系、阶段或角色交接说明的相邻已讲节点，都必须避开字幕条。

本次漏检的原因：镜头移到推荐汇总表后，“新注册企业／历史银行流水”仍在邻近区域；普通图解补充标签未归入标题/正文类型，检查又只关注当前焦点，因此下行进入字幕实底带却没有报警。裁切后的文字框已丢失被挡部分，也不能证明原说明完整。

1. **记录真实遮罩。** 区分字幕实底带、含描边的字幕字形、后绘实色层和播放器控制条/渐暗层；按项目实际分辨率与显隐状态确定屏幕遮挡区，不把本课的固定坐标复制成所有课程标准。
2. **先采集完整文字，再裁切绘制。** 所有业务标签、图内补充说明与成组多行文字都记录对象ID、所属节点、揭示状态、字形/描边边界及相机变换。保留变换后、裁切前的完整屏幕边界；即使某行已完全落到裁切区外，也不能从审计集合直接丢弃。检查文字与对象数量，空集合不能产生“零遮挡通过”。
3. **以最终帧率扫描完整时间轴。** 检查当前内容和仍应读到的相邻说明，不随焦点切换将邻点移出检查。逐帧覆盖推近、平移、拉回、章节衔接及停稳状态；不能只测开始/中点/结束或停稳帧。记录已知的刻意退场与远处地图边缘，不能用这类例外豁免仍须阅读的半截说明。
4. **先修布局，再回归。** 成组说明整体上移，或调整原图、人物间距及相机取景；保留前后关系、所属阶段与角色交接。正常阅读状态下，完整字形和描边须位于实际字幕遮挡区之外；1080p可从24px间距起步，以实际字形与最终画面为准。不删有效信息、不缩到不可读，也不靠裁切隐藏问题。修改后复查与图片、人物、箭头的碰撞及连续镜头衔接。
5. **用原缺陷验证检测器。** 恢复已知有问题的布局或注入等效遮挡，检查器须能检出对应对象与时间点；再扫描修复版，不能只写一个未经实际验证的通过标志。本课将两行说明整体上移70个世界单位，实际编码抽帧与播放器复核确认完整显示；这一位移是本课结果，不能当作通用修复参数。
6. **核对最终成片。** 以最新源码和MP4哈希绑定报告，复看覆盖“局部读图→平移/拉回→下一节点”的连续编码片段及问题附近过程帧；在真实播放器检查播放/暂停、普通/全屏及控制条显示时的遮挡。修复后重跑受影响及下游检查；记录整课扫描范围、最终帧率、遮罩、对象ID、时间点、阈值、负向对照、修复与未查项。未闭环的字幕遮挡阻断出片，几张静帧或旧版报告不能替代本版复核。

## 人物与名称组合及全时段避让

人物、名称和必要的身份标签使用稳定组ID，共用位移与缩放。组边界取人物实际绘制图元、完整发型/脸/肢体/脚部及真实字体字形边界的并集；不是只测文字框，也不是凭身高估一个固定行高。先测组合高度，再分配行内边距与组间距，表格数据区从人物列之外起画。分隔线即使在人物后面也要留出人物列，不能把穿头改成在头后面。

统一设计单位可从1080p的12px起步：人名与人物12px、组合间24px、列内边距12px；紧凑图标可显式采用更小的等比例规格。实际根据字号、造型、信息密度调整并复测，不机械拉远全部元素、不缩成小字。相机变换后按同一设计尺度换算屏幕间距，保留裁切前的完整边界。

执行步骤：
1. 记录每个实际可见对象的稳定ID、所属组、绘制顺序、变换后边界、人物头部/脚部、字形和线段含描边；记录组数量，空集合不能通过。
2. 最终帧率扫描完整时间轴，涵盖入场、移动路径、放大、收手、退场和章节交接；检查人物组合相互间距、外部文字与人物、分隔线/后绘线与人物/名称、图片与头部。斜线用实际线段求交，不只拿其外接矩形。
3. 刻意接触只白名单精确对象对、理由、时间窗与受限接触区，如手持钥匙的手掌及接近通道；头部与名称始终不能用该接触豁免。角色内部面部/服装构成与外部遮挡分开，不能忽略所有同组或所有重叠。
4. 用用户原缺陷或等效恢复布局作负向对照，必须检出人物名称与另一头部、分隔线穿头；另测“握持允许，但钥匙移到头/名称仍拒绝”，防止白名单失控。
5. 修后重扫并绑定源码/导出数据/MP4哈希，核对问题时刻及动作前中后最终编码帧。保留允许接触清单、候选处理和未检范围；几何零候选不冒称像素级无任何遮挡或人工全程视听。

可执行检查：`python3 scripts/check_actor_clearance.py --self-test`；引擎按脚本首部说明导出每帧JSONL后，运行 `python3 scripts/check_actor_clearance.py GEOMETRY.jsonl --out REPORT.json`。导出必须使用实际绘制调用的图元/字形和相机矩阵，不得另填一套不会碰撞的预想框。该工具是保守几何检查器，仍需查看实际编码画面。

## 文字与线条、填色装饰的关系覆盖（v2.8）

采集stroke线段、箭头各段和细长填色矩形/小装饰，不只采人物内部图元。所有可见字形都与线/装饰检查，不能只对带owner的人名检查。`scripts/check_layout_clearance.py`兼容人物检查快照，并补文字—文字、文字—线、文字—细填色及组件安全区检查；顺序/缩放/转场过程都要采集。描边和填色条是不同渲染入口，必须在采集侧同时支持。

默认几何候选不因先画线、后画字就忽略；若有真实遮罩消除了候选，保留实际编码证据和该对象/时间范围的解释，不能全局关掉类别。当前几何不解析全部透明度与遮罩，不替代实际画面复看。保留用户真实错误的源快照与成片帧、源码/视频哈希，使旧检测漏项能复现、新检测能报出，再检查修订画面。

人物—名称组、章节区、字幕安全区、同屏对比网格使用共享组件，字号、实际字形边界、内外间距集中定义。先重排、减少无意义装饰与调整镜头，不用小字或缩小人物掩盖拥挤。只有代表布局采用组件时，不能称整课已迁移。
