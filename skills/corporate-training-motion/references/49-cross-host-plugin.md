# DSH 课程工作台

当前本地适配版 0.8.1，课程核心 6.7.1；公共发布仍为0.6.0/6.5.0。本版仅开发、安装和验证 DSH；其他宿主暂缓。使用 DSH 原生会话、当前模型和附件能力，每个会话独立关联课程，不从全局最近课程自动载入。

## 工程与实际状态

新课优先 `kgxc_course_create`，恢复优先 `kgxc_course_resume`。DSH 自动传入当前会话工作区；工程放在其中的 `courses/`，不默认写全局数据目录。已有外置工程通过工作台校验迁入，保持课程ID、原件、人工稿和有效确认。未完成工程只认真实课程文件，不从审计目录恢复已清理工程。

用 `kgxc_course_status(full=true)` 和 `kgxc_course_editor(action=read)` 读取当前内容与人工稿。工作台 URL 是本机服务；不使用互联网网页获取工具读取它，不为制课扩大整个电脑的权限。已核对的资料、环境与有效选择沿用，无变化不重复检查。

## 六阶段及保存约定

资料 → 大纲 → 逐字稿 → 分镜 → 有声小样 → 整课交付，各阶段显示实际内容、状态和缺项。AI 完成本次目标阶段并保存成果，逐字稿、分镜、小样和全片分别进入独立盲审，实际边界见[独立学员盲审与执行监督](50-independent-review.md)。分镜检查旁白与画面变化，沿用已有选择与委托，不新增一次强制人工审批。保存不构成确认，不代用户批准后续阶段。

- 大纲：`kgxc_course_update(stage=design,data=完整方案)`。保留稳定 `units.id`；章节有 `content_points` 数组、`activity`、`objective_ids`、`source_refs`（source_id/locator）、`duration_minutes`（分钟）。原件逐页素材去向与取舍理由一并保存。
- 逐字稿：`kgxc_course_update(stage=script,data={sections:[{unit_id,body}]})`，使用现有章节ID；不得按标题或数字编号猜配。用户手改先保留，AI 更新保存差异建议，用户采用后才替换。段落稳定ID在 `plan.script_mapping.paragraphs` 中。
- 分镜：完整逐字稿的每个教学片段至少三种实质不同的表现，保留稳定段落引用。实际关键帧标为静态示意；动态预览须有真实画面。
- 小样：按已保存的抽样计划制作三个完整有声片段，使用正式生产画布和声音，保存实际视频、分镜与时间线绑定。合并视频的三个样段各自定位到准确区间；反馈绑定视频字节、片段及视频内时间。
- 整课：当前小样确认后制作。只有真实任务才展示进度；真实视频的章节导航使用其导出时冻结的时间线，不能套用后来编辑的时轴。

工作台的确认、方案选择和版本检查复用核心记录。自动保存和撤销保护人工输入；结构变化移动同一章节的讲稿与段落身份，标出受影响分镜、过渡及音视频。

## 人与 AI 的入口

右侧原生对话保持可用，支持选择文件夹、上传文件、发送与停止。阶段按钮在对话中只展示简短可理解的请求，路径、稳定ID和制作契约作为内部上下文交给 AI。

需要时长、受众或事实缺口选择时，先保存待选事项，再调用 DSH `ask_user_question` 主动展示。前题点选后进入下一题；最后单选真实点选后直接发送整组。默认推荐、重开、关闭与超时都不代表回答或批准，多选保留完整提交。工作台在全部相关阶段展示待选事项；模型空闲后若问题已保存却未弹出，会主动请求原生问答补开一次，已有原生待选不重复打开，已回答和已委托项不重问。

## 桌面交付与过程文件选择

完成制作端校验并登记后，使用“保存成品到桌面（保留过程文件）”。核对字节，复制当前视频、字幕和封面到桌面 `ai 制课/<课程名称>/`。逐字稿、分镜、小样、配音、原件、缓存和工程默认保留，保存成品本身不授权删除。

交付后弹窗供选择保留、稍后提醒或查看清理范围。关闭、预选和超时不删除，也不算确认。“不用中途确认／全程授权”这样的制作委托不包含删除授权；用户明确要求保留时，保存 `project/retention-policy.json` 的 `mode=keep`、实际原话 `evidence` 和 `actor=user`，不重复弹清理问题阻塞制作。

只有用户核对当前本课文件数量、大小、分类后，明确点击“确认清理所列过程文件”才执行。后端核对当前桌面文件、课程版本和短时有效的文件清单，拒绝缺少或过期确认；先保护独立原始业务资料，再清理授权范围。保留工程可继续编辑；经确认清理后仍通过小型交付记录播放、定位和下载，不从审计目录重建旧工程。技术验证与业务用户验收继续区分。

## 顾客、花字与音效的制作偏好

分镜前在一个窗口明确三项：使用 V01/V02/V03 同风格可动顾客、设计新顾客或不出镜；适量重点花字、少量关键条件或关闭；使用已经确定的原库提示音或关闭。已有顾客显示同一运行器生成的实际预览，新增支持描述和上传参考图，在同一套多部件人物中设计不同发型与服装，先给设计、采用后再制作。整张静态PNG人物从当前使用和默认选项中移除，历史原图保留。选择逐项点击即保存，第一次为开始制作补齐选择时，最后一项完成后继续原阶段，不需要再按提交。关闭不作默认选择，重开沿用已保存答案。

偏好在 `project/production-preferences.json` 保存：`choices.customer=V01|V02|V03|new|none`、`choices.flower_text=key-points|minimal|off`、`choices.sound_effects=native|off`。工作台保存真实选择的 actor、依据和时间。用户委托制作时由制作端填写同一结构并记录 `actor=user-delegated-production` 与实际授权，不冒充用户点选。新增顾客的 `new_customer` 保存 brief、已上传参考，完成实际设计并被采用后保存本课 `profile_path` 与 `design_approval={status:confirmed,actor,evidence}`，不因文件存在就声称被采用。新增设计的实际profile字节也进入选择基准，修改形象会要求更新相关分镜与视频。

对已完成的6.2–6.4旧课程，可显式记录已验证成片的实际选择供界面回看：`recorded_existing_production` 绑定已登记final路径、视频SHA、记录人和实际依据。它只作历史事实回读，不改变旧小样批准；第一次更换偏好即转入当前完整契约。新课程不能通过这个字段跳过检查，不根据不存在的记录猜填答案。

修改偏好保留原稿，并使相关分镜、小样及整课需要更新。通过 `save_storyboard` 保存实际新分镜后，工作台在独立衔接记录中绑定当前选择和分镜，不靠章节标题匹配，也不为了界面选项重写稳定段落。已有冻结工程在只读打开时不自动迁移或重新询问；用户请求继续制作或主动打开“制作偏好”才进入选择。

制作端在实际查看当前视频后分别保存 `qa/production-preferences-pilot-review.json` 和 `qa/production-preferences-final-review.json`：

```json
{
  "choices_sha256": "当前production_handoff返回的选择摘要哈希",
  "video_sha256": "本次实际视频字节哈希",
  "observations": {
    "customer": "实际观察顾客形象、站位及连续性",
    "flower_text": "实际观察重点文字、条件保留与避让",
    "sound_effects": "实际核对原库、落点和混音，不伪称真人听审"
  },
  "implemented": {
    "customer_ids": ["V01"],
    "customer_nodes": ["当前导出里的真实顾客节点ID"],
    "flower_count": 2,
    "flower_nodes": ["当前导出里的真实花字文字节点ID"],
    "sfx_count": 1,
    "sfx_palette": "teaching-native-v1"
  }
}
```

数量仅为字段示例，必须填写实际结果，不是每课模板。小样未覆盖的启用特征可用 `deferred_features` 记录具体原因，整课必须落实。新增顾客还要登记 `implemented.new_customer_profile` 的实际本课路径。确认时核对选择哈希、视频哈希、当前导出文档的真实节点，以及音效混音回执、绑定音频和非静音分轨；启用但未接入、关闭但仍绑定提示音、使用旧选择或旧视频的报告，均不能通过。技术实物核对、正常速度听看和用户业务验收仍分别记录。

## 当前任务与历史失败

整课页首先显示当前整课任务，历史任务默认折叠，错误堆栈再折叠到每次尝试内。后续同类导出成功时，旧失败标为“后续版本导出已通过，本条保留为历史诊断”；旧状态和文件不删除、不改写。最新任务失败时仍显示本次未通过，即使已经编码了全部帧也不显示成功。当前成果因修改失效时继续提示更新，不把旧成品或旧小样当成新的整课完成。

## 安装与验证

`python3 scripts/install_plugin.py --host dsh` 或双击“安装制课插件.command”，重新打开 DSH。保留现有账号、模型、权限、媒体配置与其他插件。当前仅验证 macOS Apple 芯片环境，新机器仍需原有媒体与本地声音依赖。

随包 `docs/PLUGIN.md` 与验证报告分别记录界面、真实模型调用、媒体导出及用户验收范围；安装和单元检查不冒称完整课程成功。

### 保存位置与保留选择

保存成功后显示当前交付记录中的真实目录，DSH成品页与文件处理窗口提供“打开保存文件夹”。只打开已核对本课视频、字幕、封面的记录位置，不让模型猜路径。保留全部或稍后提醒无需先取得清理范围；只有用户要求查看清理时才列出具体范围。课程根目录的versions为流程历史快照，保留并正常识别；其他未知文件只阻止清理，不阻止保存或保留。关闭窗口不删除，已保存结果与清理资格分别呈现。
