# 本地默认声音与可选配音

优先使用用户后来明确选择的本地默认声音。没有个人选择时，随包推荐男声 **didi**、女声 **pipi**，未指定性别时用didi；`qwen3_tts.py --gender male|female`选择相应默认，`--voice didi|pipi`单次指定。两套参考WAV、准确文本与配置位于 `assets/voice/recommended/`，完整安装准备同一Qwen3-TTS Base模型后可直接使用。它们是推荐起点，支持后续调试、换声和个人参考克隆。原始生成与推荐交付倍率均为1.0；既有用户与冻结课程保持原声音。B2 VoiceDesign及其1.1倍方案继续作为可选项保留。

这是默认选项，不是唯一选项。本次明确另选、个人已保存的声音和既有批准录音优先。脚本支持 CustomVoice 的九个预设、VoiceDesign 文字改声，以及 Base 参考音频克隆。不得把所有模式硬编码成 Aiden 或同一模型；默认配置在 Skill 外，权重不入工程/发布包。

## 所有供应商都须遵守的配音要求

1. **语气自然**：普通、正常的培训声音，像向同事说明工作。不过度煽情、不夸张表演，不把每个词都重读，句尾自然收住。提问、邀请、提醒和总结有符合句意的起伏与适度重音，不能把平实理解为从头到尾没有情感。
2. **语言标准**：标准普通话；专业名词、数字、单位、外语或缩写按实际语境核对，保证完整、清楚。
3. **节奏干脆**：干脆利落，速度不要太慢。短停顿用于分句与理解，不拖长音，不以长空白拉长课程；以用户确认的实际小样确定速度，不统一套用固定倍率。
4. **前后连贯**：同一讲师的声线、语气、响度和句尾前后一致。整课优先固定已确认参考或 speaker，以完整语义段连续生成；不能每个小段重新独立设计声音。相同描述和 seed 不等于声音身份稳定。

保留已确认声音。新的描述只用于新生成或用户授权修改的声音，不自动重配冻结录音。进一步执行[课程工艺](36-course-craft.md)的实际听看与证据要求。

## 英文名称与缩写的实际读法

先列出本课发音表：画面与字幕的标准写法、语境下应读整词还是逐字母、TTS输入别名、实际配音片段及核对结果。例如 Mac 是产品名称，应按英文整词处理；SN、RFID等按实际业务语境核对缩写读法，不能把所有英文一律拆字母或一律改成中文。

逐字稿和字幕保留标准拼写；必要的大小写、发音别名、语言模式只用于有记录的配音输入副本。同一个词在不同模型、语言模式和上下文中可能有不同结果，先用当前声音测试整句，再选择有效参数。某次 auto 语言配合小写词输入的修复，不自动成为所有英文、所有课程的固定设置，也不修改个人默认声音。

出现拆字母、吞音或接音不自然时，优先在同一已确认speaker或参考录音下，重生成包含该词的完整混合语言句子或语义段。不要只生成孤立英文词后按粗略时间戳替换；切口可能保留旧音节，或把新词连成另一个词。确需拼接时，检查词首、词尾、左右衔接和整句听感；保护上下文裁切也要核对实际尾字，不能夹带下一句的首音。

复核所有重复出现的位置，不以第一处修好代表全课通过。检查最终混音及编码MP4中的完整句子；ASR能辅助查漏、定位和提示拆字母，不能证明英文发音、音色或衔接已被人工听审。用户确认绑定实际有声版本；保留原声、修复输入、参数及被否决的候选，不自动重配其他冻结课程。

```sh
python3 SKILL_DIR/scripts/qwen3_tts.py --list-voices
python3 SKILL_DIR/scripts/qwen3_tts.py --profile B2 --dry-run
python3 SKILL_DIR/scripts/qwen3_tts.py --text-file APPROVED.txt --out VOICE.wav
python3 SKILL_DIR/scripts/qwen3_tts.py --voice Aiden --text-file APPROVED.txt --out OTHER.wav
python3 SKILL_DIR/scripts/qwen3_tts.py --profile B2-clone --ref-audio REFERENCE.wav --ref-text-file REFERENCE.txt --text-file APPROVED.txt --out CLONE.wav
```

一次另选只作用于该次；明确“以后默认”才使用 `--set-default`，自动备份配置。文字设计音色用支持指令模式的 `--instruct-file`，didi/pipi的Base克隆不接受该参数；交付语速用 `--delivery-rate`；本地模型路径用 `--model`。克隆参考和逐字文本必须对应。完整安装可用 `--voice-profile` 准备对应模型；离线生成时不下载或换供应商。

输出不存在才生成，真实参数和原声/交付哈希写入 WAV 旁 JSON。长文用少量完整语义段，保持相同配置并实听衔接；首尾、数字、百分比和练习全文覆盖必须核对，尤其检查每段最后一句是否完整。缺尾可在同一声线条件下增加后续上下文作保护，实际核对后裁去保护语句；不得插值补字幕来掩盖缺失口播。token 上限和 ASR 不能替代听校。相同 seed 不证明声音身份稳定。改变声音方案先出本课实际有声小样，沿用仍有效的确认，不改已有冻结录音。

完整切换、模型安装、克隆、改声及速度示例随发布仓库 `docs/VOICE.md` 提供；本技能内的实际参数源是 `assets/voice/profiles.json` 和 `scripts/qwen3_tts.py`。

后期提速或升调按[最终声音与时间线检查](37-cover-and-delivery-finish.md)执行，明确相对输入版本，避免重复加速；旁白升调不改变音乐音高，字幕与画面共用映射。

用户给出参考片或要求添加可复用的本地克隆声音时，见[参考片学习与本地声音库](43-reference-teaching-and-voice.md)。Base克隆和VoiceDesign的控制边界分别说明，注册候选不更改默认声音。
