# 并行制作与局部返工

## 并行制作

- 已确认逐字稿并选择视频后，锁定讲稿字节、课程ID、现有确认及音色选择。默认让一端生成已授权的配音，另一端做逐段分镜备选、素材、构图及导出预检。分工使用独立工作文件，每个正式文件只有一个写入者；等待真实录音期间不要按估计秒数锁定字幕、表演、导航或音效时间。
- 有可复用的已确认录音先用；按完整语义段生成候选时，检查断句、称谓、尾句、声音一致性及接缝。未获授权的联网生成、预算扩张或新音色不得因“并行”自动执行。确认现有音色且本地能力足够时，不额外等待小样确认才生成同版干声；未知或高风险新发音先做对应短句、选定后继续其他段。不要一条线故障就重启另一条线。
- 实际音轨产生后，依据实际录音对齐，才锁定各句、镜头、字幕和后期事件。分镜照既有选择与独立审查执行。照既有抽样规则制作三段有声小样，同时用本课真实片头、正文与片尾检查两处短接缝及最终编码、字幕与音轨链路，见[渲染与声音时间轴](05-render-pipeline.md)。接缝诊断不充当三段小样，也不增加人工审批。
- 人工问答仍确认讲稿、三段有声小样、成片；其它既有有效选择沿用，不人为制造审批。小样确认后才扩展整课并正式导出，先完成主体（画面、字幕与实际配音时轴），再单独做花字层与音效分轨，最后合成并核对。各阶段对选定方案的一次盲审、正式放行和完整连续看听要求不变。
- 每段工作记录实际开始/结束、并行等待、复用/重做范围、证据及当前阻塞；不要把并行分支耗时直接相加当作交付用时，也不要把导出进度当作质量通过。

## 局部返工

按变更实际影响挑最小责任层，不把“先重渲一遍看看”当默认。保存已验证基线及当前输入字节的依赖，核对实际产物，而不是只比较版本名或时间戳。

| 改动 | 优先保留 | 重做及复核 |
| --- | --- | --- |
| 单处音效素材、落点或增益 | 逐字稿、配音干声、未变的画面和字幕 | 该事件与共享分组、受影响混音、当前编码及声画同步 |
| 花字样式或位置 | 干声、与该花字独立的镜头 | 花字所在时间窗及触发、稳定阅读、进出场；同时核对相关音效及遮挡 |
| 字幕排版或文字 | 未改旁白、独立画面素材 | 对应字幕/烧录画面；检查相邻字幕，文本事实变化须回到讲稿批准边界 |
| 局部画面或一句旁白 | 依赖未变的章节、原件、已验证素材和录音 | 变更段、两侧接缝、下游口播对齐及全局时轴；必要时延伸到共享人物、模板和素材的全部使用点 |
| 帧率、分辨率、共同渲染器、固定包装或全局导航 | 证明不受影响的源素材或干声 | 受该共同依赖影响的画面及成片。全局时钟或进度条变化可能使后续全部画面失效 |

已分轨、分镜可独立重做的路线使用下面的依赖快照；工作台现有整课导出仍走同一完整生产渲染与验收，不能把另一个渲染器拼接的旧段当作当前证明。没有完整的依赖、绑定、独立生成能力或短接缝结果，就只复用已确认的上游素材，不猜测复用旧帧。单次渲染器的相同画面优化与进程内审查缓存不是跨任务片段缓存。源素材清单不替代所有脚本、字体、时间轴、色彩与导出规格的版本绑定。

### 可执行复用计划

对可独立复用的阶段，将实际工作输入（原文片段、字体/素材、镜头时轴与规格、声音配置、代码及工具版本收据等）和对应候选产物列入依赖图。包内或外部依赖需落入本课实际、可校验的锁定收据；该收据随实际版本更新。各片段持有独立 ID 和产物。声明生成上游用 `dependsOn`，普通源输入用 `inputs`，路径一律相对本课 `project/`，不跨课。

例如，返修工作区内已有配音干声和已编码正文，音效改动只应牵连混音，最后重组当前视频：

```json
{"schema":"kgxc-incremental-production/1","nodes":{
  "narration":{"layer":"narration","inputs":["source/transcript.md","work/voice-config.lock"],"output":"audio/narration.wav"},
  "body":{"layer":"body","dependsOn":["narration"],"inputs":["native/lesson.js","work/render-inputs.lock"],"output":"work/body.mp4"},
  "mix":{"layer":"mix","dependsOn":["narration"],"inputs":["work/sfx-inputs.lock"],"output":"work/mix.wav"},
  "mux":{"layer":"package","dependsOn":["body","mix"],"inputs":["work/export-inputs.lock"],"output":"work/candidate.mp4"}
}}
```

在**基线实际生成、相应质检通过后且输入未变**时保存一次快照；待复用时使用同一清单结构采集当前快照，任何新增、移除或改变的依赖都须更新清单。快照仅保存实际文件哈希，不证明声明完整；不能修改输入后再捕获基线，或让历史报告伪造当前生成来源。生成前比对期间不得有同课写入；各步仍执行自己的输入冻结检查。

```sh
python3 SKILL_DIR/scripts/incremental_production.py snapshot COURSE --spec COURSE/project/work/production-plan.json
python3 SKILL_DIR/scripts/incremental_production.py compare COURSE --previous PRIOR_SNAPSHOT --current CURRENT_SNAPSHOT
```

先将 snapshot 的成功输出保存为独立新文件，再用于 compare；失败不能覆盖旧基线。只有 `action=reuse` 的实际产物可复用，`rebuild` 及其下游按图重做。比较会重读当前输入与产物并拒绝过期快照；路径/依赖不全、产物丢失、文件或上游改变时，不能返回可复用。修改范围按真实传播扩展，重新核验当前版本的接缝、声画同步、关键帧和完整解码。检查只证明明确范围，不替代人审与正式交付。逐帧源图精确比对留给确有异常或必须保留无损一致性的范围；不要把全量解码与逐帧像素相等混为一谈。
