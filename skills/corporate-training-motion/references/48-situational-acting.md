# 情境怎样演得自然：编排、人物与可复用实现

用于顾客接待、带教、管理沟通、正反案例等需要人物演出的片段。后续此类片段默认采用本方法：先有意图与站位变化，再用简化的连续形体把动作做清楚。概念、数字、流程仍按内容选择图解。沿用已确认内容、人物特征和美术；需要简化时保留脸型、发型、服装与身份标识，在现有分镜/小样中审阅，不另加固定审批。

## 先把一段戏排出来

先为每人写一句当前意图，如“走近询问”“听出顾虑”“指给对方看”“让开位置”。用起始站位、关键动作、结果站位串成完整片段。先排全身粗演，再修五官和细节。一次选择一个主要动作，动作改变人物关系或让观众看到工作步骤。

一个可改写的接待节拍：

| 节拍 | 人物怎样做 | 配合对白与观看焦点 |
| --- | --- | --- |
| 进场 | 顾客看向店员，全身朝行进方向走近；店员注意到来人，轻转身体 | 先让观众认清谁来了、找谁 |
| 停步 | 最后两步收小，脚落稳后收臂，轻转向对方 | 问候接在对视建立之后 |
| 提问与倾听 | 说话者用一个短手势说明需求；听者看向对方，稍停后回应 | 自己的对白驱动自己的嘴，听者保持可读反应 |
| 示范或解释 | 先看目标，再抬手/拿取/记录，结果停稳给对方看 | 让视线、手和解说指向同一个重点 |
| 结束或离开 | 收回手，重心落到支撑脚，小步转向；头、胸、胯、鞋跟随，再起步 | 转身完整完成，离开有明确方向 |

不需要每场走一遍；坐下交流、同侧观看、让位和递交记录可按任务变化。改变人物间距、朝向、主次或视线应有原因。剪接在观众已看懂结果后发生，不靠所有人反复摇摆制造活动。

## 速度怎样安排才利落

先给动作自己的时间，再把它放到语义锚点。走路根据距离、人物比例和步频安排；抬手是抬起—表达—收回，转身是重心转移—调整步—全身朝向稳定。预备短，关键动作明确，临近结果收住。手腕和肘稍有先后，避免所有关节同时直线插值，也避免每个动作都夸张弹跳。

一句话比动作长时，让人物自然进入看、听、等回应或展示结果。动作已经完成，就保留姿势和有目的的小反应；不要把行走、转头和抬手拉满整段配音。语速另按对白意图调整，不用慢对白迁就画面。修改声音需沿用原字幕文字并按同一时间线重对齐。

## 人物怎样画才方便动

推荐头部稍大、肩线圆滑、四肢轮廓清楚的简化二维人物。肩点位于颈根两侧，袖子连到上臂；放松时上臂自然垂下、肘微弯、手落在髋部附近。先看正面、左右侧面与抬手剪影，再加领口、胸标和表情。不要用悬空肩球或硬凸肩片连接胳膊；上臂、前臂、手掌都保留明确的旋转关系。

可复用实现位于 `workbench/motion/acting.js`，公开为 `CourseActors`，与普通场景节点共用预览、编辑、定位和导出：

- **行走**：交替支撑与摆动，支撑脚锁在地面；摆动脚提起、摆到前方、脚跟着地、再落平。髋部随步伐轻起伏，最后两步落到终点。腿用两段骨骼求解，走动由根位移和脚底共同决定。
- **转向**：以 `facing` 控制头、胸、胯的连续朝向，鞋跟随方向；`turns` 安排两脚先后调整与重心移动。左右转经过正面，避免只翻鞋或正面人物侧滑。走路期间全身侧向行进方向；停下后可转为面对对方的三分之二侧面。
- **摆臂**：左右与步态反向，以上臂小幅连续弧线为主，前臂和手腕稍滞后；持物、记录或示范时相应手臂减去自动摆动，保持任务姿态。肩部保持放松。
- **手臂遮挡**：先画远侧臂，再画衣服和躯干，最后画近侧或承担任务的臂。同一条胳膊实心绘制一次，袖口—肘—腕连续。深屈肘用圆接头和两段封口轮廓合成，避免单个偏移多边形折出尖刺；前后交接不靠透明淡入。
- **头和脸**：一个连续头部轮廓，眼鼻口和眼镜裁在同一脸形内；颈部先画在头后。转向改变五官投影与可见性，保持一套五官，避免两张脸交叉渐变造成穿模。
- **对白与视线**：`speech` 使用本人对白的逐帧能量控制开合，不声称逐音素同步；`targets` 指向真实人物或物件。讲师分析时人物可以看、听、思考，嘴不跟讲师动。
- **服装标识**：店长黑衣 KG、店员蓝衣 KG、Coach 黑衣 MyCoach。胸标使用原图，随胸面投影压窄、被侧面遮住，不镜像文字或重画近似标。

当前实现是正面到左右侧面的二维人物，可走近/离开、转向、说听回应、手势及部分手部任务。它不是原批准 PNG 的万能骨架，也不支持背面、自由三维、复杂手指或任意接物。原纹理 C01/S01 的正面演出继续走[原图通道](41-direction-and-performance.md)；该路线边界不因新代码变化。新绘简化身份不能冒称原图已完成自然走路绑定。

## 直接开始：本课人物与动作

1. 按当前人物参考编辑 [`assets/templates/acting-design.json`](../assets/templates/acting-design.json)，填本课ID、场景、地面、外观、站位及 `travel`。模板是自造技术示例，没有课程对白。
2. 用下面命令输出 `node` 和原标 `assets`，合并到本课顶层 `sceneGraph.nodes` 与 `assets`。`x` 是最初脚下中心，`floorY` 是脚底地面，`height` 控制正向等比缩放。人物位移由 `walks` 控制，转向由 `facing/turns` 控制。
3. 按本课语义给 `keys`、`targets` 和 `speech` 加时刻；配合对方的观察与回应，先做完整粗演，再细修。

```sh
python3 SKILL_DIR/scripts/course_tools.py stage-acting COURSE --design DESIGN.json --out COURSE/project/source/actor-stage.json
python3 SKILL_DIR/scripts/course_tools.py route --spec SPEC.json
python3 SKILL_DIR/scripts/course_tools.py acting-check --spec SPEC.json --out COURSE/project/qa/acting-plan.json
```

`stage-acting` 为 `travel` 计算步数、自然时长和转向轨道；不读取旁白长度来慢放。`travel[].startFrame/fromX/toX` 是实际源时轴与舞台位置；`stepRate` 可选，只是粗演起点，按人物性格和实际效果调。`restYaw` 为停下后的朝向，0正面、正值向右、负值向左，范围为±π/2；离场可保持±π/2。两段移动之间留出停步和转身，命令提示不足时重新排动作起点，不将转身压成瞬间。现有绝对帧轨道可直接编辑 `vectorActor.walks/facing/turns`。

可组合的稀疏关键值为 `gesture/concern/relief/nod/head/turn/write/reach/tryEar/shrug/yield/scribble/gazeDown`；`head/turn` 为-1至1，其余0至1，各通道各自连续采样。每个动作显式写出起、落值，`yield` 等也需本课实际画面验证，不能用通道名推定业务动作完成。`blinks` 为开始、闭合、回开三帧；`targets:[{frame,id}]` 绑定实际对象；`speech:[{startFrame,envelope:[...]}]` 为自己对白的每帧能量。不要把示例的帧号、人物组合、步数、幅度或音色照抄成课程标准。

`route=auto` 检出 `vectorActor` 后接入 `situational-acting` 和实际运行器；已有自定义原生工程保留源码，用同一个 `CourseActors.prepare/paint/motionState/bounds/runtimeCalls` 接入。不要覆盖旧实现或用空声明冒充支持。`objectReceipt()[人物ID].actor` 返回实际朝向、脚底、关节与绘制层级，`isolate([人物ID])` 隐藏同一对象，供已有对象证据检查使用。

## 怎样复看、定位并修好

先正常速度看完整片段，判断意图、动作轻重和节拍；再用 `acting-check` 生成的连续帧范围定位细节。这个命令检查输入和给出取证计划，不自动认证演出好看。

优先看起步前后、停步前后、整段转身、深屈肘、持物与收手。连续帧比只看起终点更容易发现一帧的透明胳膊、重复鼻子、腕部跳点与突然换层。实际原生画面通过后，从最终MP4解码相同帧复查；静态证据、技术通过、正常速度看听和用户认可分别记录。

| 看到的问题 | 从哪里改、怎样试 |
| --- | --- |
| 人像纸片横移，鞋向右人却朝前 | 同时检查根位移、头胸胯 `facing` 与双脚朝向；把行进区间稳定在对应侧面，再安排停下后的转向 |
| 转身像瞬间拧过去 | 先锁支撑脚，另一脚抬起调整，再换支撑；头先带一点，胸胯跟上，鞋完成调整后才起步 |
| 手臂灰透、重影或穿过衣服 | 检查同一逻辑臂是否重复画、局部透明度是否变化；改为实心的前后层级，重新看换层前后连续帧 |
| 肩膀像铠甲或胳膊垂得太低 | 回到正面/侧面静止剪影，调颈根、肩点、袖口和肘腕比例；先画顺肩袖连接，再检查动态，不用整体上移胳膊掩盖连接问题 |
| 摆臂像钟摆或机械甩动 | 减小肩摆，以步态相位带动肘腕，稍错开收放时刻；持物那只手减摆，慢看连续轨迹再正常速度复看 |
| 脚打滑、伸长或离地 | 核对支撑脚世界坐标、骨长误差和步距；缩短步距/增加合适步数或调整站位，避免只改根移动曲线 |
| 动作拖沓 | 先删与意图无关的摆动，给主动作自然时长，完成后进入倾听/展示；再对齐对白，保留原来需要读懂的结果 |

对本次成功方法可保留本地参考片和源码哈希，记录用户认可的准确范围。公共 Skill 只携带通用实现与自造示例，私人案例、声音和画面留在课程工程。后续仍按实际人物和场景调整，目标是清楚、自然、有交流感。
