# 花字、参考音源与动作选音

新视频在全课分镜时执行；既有样片只在用户要求补花字、换音效或相应返修的范围执行。已有有效画面、稿件、声音与确认沿用。花字和声音进入同一分镜、时间线及有声小样，不增加一轮单独审批。单次样片的配色、数量、秒数与音效密度不成为整课模板。

DSH 在分镜前合并展示顾客、花字、音效制作偏好，保存后不反复问。默认推荐适量重点花字和已确定的原库提示音；用户可减少或关闭。用户已委托制作时记录 `user-delegated-production` 的决定和依据，不因没有弹窗操作而静默省略。启用后必须检查当前编码画面、原库文件、实际音效分轨与最终混音；没有接入就保持未完成，不以“规则已写”或勾选项代替。选择或参数改变只使相关分镜、小样及整课需要更新，不改动无关讲稿。

## 先确定这句话需要学员注意什么

从已确认逐字稿提炼当前的行动、条件、依据、边界、选项或总结；普通叙述可以没有花字。先写“为什么此处需要强调”，再选择弹出短词、重点标记、移动定位、描线、条件便签、平等选项或总结链。不要每个名词都跳字，也不把整句字幕放大复制。

每个花字事件记录 `id`、对应 `cueId`/原句、强调文案、教学用途、视觉种类、目标对象、源时间轴起止帧、动画起止/落位帧、稳定阅读窗口、所属信息组，以及声音或静音理由。字段保存在本课的花字计划，可与分镜关联；实际音效转换为31号参考的 `sfx-events.json`。时间来自当前配音，不能照搬演示的时间码或伪称已有逐字对齐。

短文案保留改变判断的否定、条件与权限，例如“顾客愿意”“先核实”“不能私自加价”；不能把“符合条件才适用”缩成“有优惠”。并列选项保持同等大小、停留与声音权重，不用奖励音暗示学员必须选择成交。花字避让字幕、脸部、操作位置和进度；划线绑定实际文字或对象，动作后留可读状态。依45号阅读规则检查曝光，不自动加静音凑时间。花字是注意提示，不能代替演示对象的真实动作。

讲检测时让学员看到检查对象和结果，讲报价时按实际口播逐项呈现依据、金额及条件，人物对提问有相应回应。先解释原价或需补金额，再讲符合条件的权益时，画面不能提前跳到最终结果；费用与附条件优惠分列，不用花字合并成错误承诺。新增文字和步骤说明也要检查与手机、人物、字幕及导航的实际避让。

## 新音效默认用已经确定的两款原库声音

`assets/sfx/teaching-native-v1/` 随安装包提供原始MP3、48kHz立体声PCM16渲染副本、来源/哈希、固定角色映射与离线试听。安装后即可调用，不要求使用者重新搜索或购买素材才能开始试听。来源名称与资产ID见 `source.json`，来源权利说明保留；不把第三方来源标为CC0。不要用同名搜索结果、抽取版或合成正弦/噪声替换冻结音源。

| 视觉或教学用途 | 默认做法 |
| --- | --- |
| 花字弹出、条件便签、轻提醒 | 嘟咚；只在需要辨认这次出现时给一次 |
| 依据或关键词标记、结论落定 | 叮；不把它当作所有词语的统一入场音 |
| 对象移动或镜头推进 | 通常保留静音；确需提示交接时，在启动或落位给一次嘟咚，不拉长短音铺满运动 |
| 连续划线或步骤链 | 按信息组在起点提示，必要时在全组完成给叮；不每条线、每个字都响 |
| 平等选项 | 同一嘟咚与相同增益，或整组静音；用 `groupId` 让旁白避让也采用共同的较低增益 |
| 相邻否定边界、连续提问、阅读与思考 | 可只提示组首，其余静音；不叠加警报、奖励或多层音色 |

默认库只有两款独立音源。15个动作角色是对这两款声音的别名映射，不宣称15种音色，也不要求15类动作全发声。旧 `natural-ui-v1` 的45个CC0素材与 `soft-tactile-v1` 保留供明确选用或恢复旧计划，不能因默认更新自动重混已有课程。用户明确另选音源时，按其选择登记新的本地库版本，不覆盖冻结文件。

## 同一时间线落地

```sh
python3 SKILL_DIR/scripts/course_tools.py sfx-catalog
python3 SKILL_DIR/scripts/course_tools.py sfx-plan COURSE --events COURSE/project/source/sfx-events.json
python3 SKILL_DIR/scripts/course_tools.py sfx-mix COURSE --plan COURSE/project/audio/sfx-plan.json --narration audio/narration.wav --out audio/course-mix.wav
```

例如下面三项是在本课实际动作峰值处发声；数字只演示整数帧格式，需要按本课录音和动画替换：

```json
{"palette":"teaching-native-v1","events":[
  {"id":"option-a","frame":120,"role":"appear","assetId":"appear-native","groupId":"equal-options","gainDb":0},
  {"id":"option-b","frame":180,"role":"appear","assetId":"appear-native","groupId":"equal-options","gainDb":0},
  {"id":"line-group-finished","frame":255,"role":"confirm","assetId":"confirm-native","gainDb":-2},
  {"id":"question-hold","frame":300,"role":"none"}
]}
```

事件 `gainDb` 是相对于库内推荐基准的调整；计划保存实际合成增益。原始MP3可能带起始空白，按解码副本的 `peakSample` 和实际可闻起音定位；不能把文件开头直接当作敲击时刻，也不能固定套一个偏移量。移动用启动/接触/完成中真正需要提示的点，划线完成音对应最后一笔，均核对当前整数帧。

现有混音器保留立体声，兼容旧单声道库。旁白保持原增益与时轴，局部避让只降低音效；相同 `groupId` 采用共同增益并记录 `appliedGains`。含旧音效的成品必须回到干净旁白/分轨重混，再替换音轨；不叠加新声音假装移除了旧声音。输出独立音效分轨、混音与来源回执。其他渲染器同样接入这些实际文件和事件，不另外合成近似音。

## 参考片找同款与实际复核

用户给出参考片时，先定位具体事件，保留时间码和原混音；有分离版时并列试听，分离残留不能称为干净原版。候选来自原素材库时保留标题、作者、资产ID、来源页与文件哈希；同名不足以证明同款，可用对齐波形/相关性辅助排除，最后以实际试听和用户答复为准。相同声音出现在多个时间码时，登记同一源资产，不复制成多个虚假音源。不要把未经用户选择的候选升级为全局默认。

正常速度检查原库单音、课程混音及最终编码：清脆程度、尾音、是否抢词、密度、可闻起音与动作落点、同组选项是否等权。源哈希、格式、削波、波形相关、ASR和抽帧各自只证明技术项目；不能虚构已完整听看或代填用户认可。出现“音源不好听”时，回到参考音源选择，不继续用EQ、升调或加混响掩盖选源问题。

公开演示《回收价格异议处理》采用22处花字、15次声音、两款原库音源，末尾三问和阅读留白保持安静；这是一段具体演示的选择。公开入口见仓库主页的“花字与原库音效样片”，完整教学任务仍按本课内容安排。

## 可执行花字与当前编码声音证据

`requirements.emphasis.events`仍是唯一花字清单，新增执行字段：`requirement_id,quote,purpose,emphasis_text,visual_treatment,target_node_ids,text_node_ids,marker_node_ids,semantic_anchor,animation_start,animation_end,landing_frame,reading_window,sound_or_silence_reason`。需要保留的否定、条件、权限登记 `protected_tokens`。实际字组、标记及目标关系必须存在；字体名、普通正文换ID、字幕、单纯透明度入场不能单独算专门花字。`emphasis_checks.inspect()`沿实际祖先、阅读组与运行曝光核对，事件空表、语义改变、缺图或读不完分别保持稳定错误。逐图观察不能复制同一句“已看清”。

编码图证据使用当前视频的出现前/触发/中点/落位/阅读结束帧，记录 `encoded_frame,actualPTS,path,sha256,observation`及当前doc/videoSHA。程序会从当前主视频实际解码比对像素。图像核对与真实片段观看、主体/人物遮挡观察各自记录；此检查不自动授予审美或学员接受结论。详见[执行合同](55-execution-contract-and-release.md)。

`sfx_evidence.mix_from_dry(project,dry_path,plan_path,assets,stem_path,mix_path,fps)`从已保存计划及实际干声生成48k单声道独立音效分轨和混音，返回源、增益、落点、计划/干声/分轨/混音哈希与样本数。不新增静音、不压缩或拉长配音、不静默削尾，不自动归一化以掩盖过载。需要多声道或额外音乐时仍沿现有混音流程，并交同等来源和时轴回执。

执行事件使用 `asset_id/source_sha256/visual_event_id/trigger_kind/peak_or_onset_frame/source_peak_sample或source_onset_sample/gain/group_id`，由实际源的空白、起音或峰值确定位置。`timing_contract`在混音前保存目标及容差依据；`receipt`绑定本次计划和未改变的干声时轴。不得把源文件开头直接当可闻起音。

`requirements.sfx.calibration.assets`为每个当前源记录 `source_sha256`及实际 `positive_controls/negative_controls`文件和哈希。正例含原声与压缩含声，负例含静音、旁白、压缩无声；正例保存真实 `expected_offset_sample`。匹配器实际解码到48k，从这些对照推导阈值与采样误差；不能用一个未经校准的相关系数放行。当前编码逐事件保存匹配值、落点及偏差，删声报 `SFX_NOT_IN_ENCODE`，无法分离报 `SFX_PRESENCE_UNCERTAIN`，超出预先约定的整数帧量化及实测误差报 `SFX_TIME_MISMATCH`，事后扩大误差报 `SFX_TIMING_CONTRACT_MISMATCH`。

`review.listening`单独记录实际正常速度听审能力、检查者、方法和每事件可闻性、抢词、尾音、密度、平等权重、音画落点及未解决项。信号检出、波形或ASR不填写这些听感结论；没有真实听审继续返回 `AUDIO_REVIEW_UNVERIFIED`。当前合成夹具验证了原库声音、AAC压缩、静音/旁白反例、删声和错两帧；它不证明任意混音可分离，更不替代真实课程听审。
