# 7.0.0 精简高效工作流、多集系列课、代码化动画与自查验收

本规范由用户于 2026-11-23 明确授权升级，面向本机当前宿主（Antigravity / CLI + 结构化提问 + 本地工作台，不依赖 DSH 专属插件），目标是：**降低用户人工把关负担、去掉形式主义冗余、释放代码化动画表现力、提高一次达标率，并支持灵活回改。**

## 1. 多集系列课统一批次模式（1 门课多支视频 + 配套文档）

当一门课程包含多支章节视频（及配套讲义精要、章节测验题库、可打印手写作业等）时，**整门课作为一个统一批次推进，不为每支视频重复跑全套重流程**：

1. **统一大纲与讲法**：一次性规划全部章节的视频、讲义、测验与课后闭环作业分工，用户一次确认。
2. **统一逐字稿**：按章节编号（如 01–06）组织完整口播稿与原件要点覆盖对照，制作端自查修精后一次交付用户确认。
3. **内容母版三选一 + 全课精简分镜**：不再要求每个教学片段都写 3 套备选方案。改为按本课内容类型提炼核心视觉母版（例如认知模型类、七环节对照类、管理带练类、数据热力图类、短案例暂停互动类、专项服务情景类），**每类母版提供 3 套实质不同方案**供用户定调；定调后全课逐段直接输出 **1 套最优导演分镜**（写入 `storyboard.json` 的 `template_masters` + `segments[].template_id`）。
4. **全课抽 3 段代表性有声小样**：跨章节分层抽取 3 段覆盖不同母版与高风险实现的完整有声小样（带真实片头/正文/片尾接缝及多角色配音），经用户确认后锁定共用视觉、声音、字幕与包装规范。
5. **共享母版、分集独立导出**：共享同一套配色、字体、进度条、音色与片头片尾，按章节分别导出独立 `01_xxx.mp4`…`06_xxx.mp4`（各自配独立 `.srt` 字幕与课程封面），并与配套《讲义精要》、测验题库、A4 可打印手写作业一并交付至 `桌面 `ai 制课/<课程名称>/``。

## 2. 代码化自由动画表现（不调生图、不用静态贴图）

- **底线要求**：坚持**代码驱动的动态呈现**，**不调用外部 AI 生图，不用整张静态 PNG 人物贴图**，产品范围仍限定 Apple 及明确适配 Apple 的无他牌配件。
- **释放表现力**：不再把人物与场景局限在僵硬的简单 2D 矢量站桩图形。在纯代码范围内（Canvas / SVG 骨骼与路径形变 / 程序化手绘描边风 / 镜头推拉与分屏 / 动态微表情与眼神嘴型情绪通道 / 焦虑度与进度可视化仪表 / 必要时的代码化 Blender 3D 道具渲染），按教学情境选用最有感染力和精良度的动态表达。
- **角色与构图底线保留**：黑衣 KG 店长、蓝衣店员、黑衣 MyCoach、便装无标顾客；人物通过发型与穿搭清晰区分；同场对白朝向受话人、柜台前后遮挡合理、脚底与物件有真实支撑、文字与字幕不重叠遮挡。

## 3. 精选明亮通透浅色画布色板

- 新课默认随机抽取色板，但**随机池严格限定在 `workbench/course-palettes.json` 中 `random_eligible: true` 的 16 套精选明亮、通透、高对比（WCAG ≥ 4.5）、无绿色的浅色系色板**（涵盖晴雪银红、温瓷靛蓝、冰川海蓝、亚麻深咖、樱雾青灰、云影琥珀、象牙赤陶、霜雪鸢尾等 16 种差异化明亮气质）。
- 压抑/深色画布（如午夜蓝、炭灰）标记为 `random_eligible: false`，仅在用户主动明确要求深色风时才启用；同一门课视频画布与配套讲义/作业保持视觉和谐。

## 4. 取消强制独立盲审与形式化监督，整合为“产出前实质自查验收（Self-Check Gate）”

为避免多轮子 Agent 盲审与繁复回执链消耗额度和时间、增加用户负担，**取消强制的独立盲审子 Agent 与形式化监督侦探**，整合为制作端在交付用户前必须自己扎扎实实做完的**实质质量自查清单**（把能自己发现和修好的问题全部修完，达到高精良度再交用户看）：

- **大纲 / 逐字稿交用户前自查**：
  1. 逐项核对用户全部显性要求与禁忌词（如去敏、匿名店名、无自报内部部门、保留酷果星创开场问候语、完整收尾）。
  2. 原件关键业务要点、条件与例外有清晰去处与取舍台账，不漏核心事实、不编造未确认的指标/金额。
  3. 逐句通读：像真人在跟受众面对面讲工作，短句自然、无“资料提到/原件显示”等旁观口吻、无同义车轱辘话、无依赖未发原件的悬空指代；**不把用户的制作限制或避坑叮嘱当成口播写进正文**（如“大家对七步法很熟，这节不讲基础步骤 / 隐去店名 / 不讲后台按键”等过度纠错元说明，制作端心里执行即可，不念给学员听）。
- **分镜 / 三段有声小样交用户前自查**：
  1. 多集/多段视觉骨架有节奏变化，不连续套同一张卡片；每句口播有对应的信息或动作推进。
  2. 多角色对话启用本地清晰分声（如旁白男声 + 顾客/员工/店长男女分声），先实测短句自然度，再对齐真实音轨锁字幕、动作、编号顺序（1/2/3 与口播严格同步）及花字/原库音效（`teaching-native-v1`）。
  3. 实际查看渲染关键帧与编码结果：查人物朝向与支撑、柜台遮挡、文字安全区与避让、片头尽快入题、封面仅首帧、末句完整无残音。
- **完整成片交付前自查**：
  1. 按每支成片核对 MP4/SRT/封面三件套完整、音画时长与非静音、片头片尾接缝、字幕错别字与换行、实际抽帧画面精良度。
  2. 视频、讲义精要、测验题与打印作业口径一致、互相呼应；过程文件默认保留在工程目录，绝不自动删除。

## 5. 支持灵活回改、只重做最小影响范围

用户在小样或成片完成后回头修改某段逐字稿、某页讲义或大纲微调，属于正常打磨，**绝不因此强制把大纲、逐字稿、分镜、小样全部重审重走一遍**：

- 仅修改局部台词/画面/花字/音效时，锁定受影响章节与片段，只重配受影响句子、重渲染对应片段与衔接、更新对应字幕与受影响讲义条目。
- 未变更章节的配音、画面与已确认视觉/声音规范全部复用，做完局部自查验收即可直接交付更新版。
