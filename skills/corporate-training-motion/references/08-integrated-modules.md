# 融合后的内部结构与唯一调用关系

本包已经融合原代码视频导演与艺术动画的制作能力。它们没有独立Skill入口、独立审批链或交付规则；课程从头到尾由corporate-training-motion负责。

| 内部部分 | 职责 | 所在位置 |
|---|---|---|
| 课程内容 | 来源、规则、逐字稿、条件与例外 | references/01、02；课程台账 |
| 导演与动画 | 视觉选择、构图、主辅动作、镜头、风格与真实素材 | references/12、24 |
| 网页制作工具 | seek(t)逐帧渲染、节拍分析、视频运动诊断 | libraries/web/ |
| 插画制作工具 | scene、参数化动画语法、材质、绘画库、字体和确定性检查 | libraries/illustration/ |
| 配音与字幕 | Aiden原速、真实时间轴、单行无标点字幕 | scripts/qwen3_tts.py、single_line_subtitles.py |
| 内容工作台 | 时间轴、波形、字幕、登记画面参数与图片、撤销及历史、统一预览导出 | workbench/；scripts/workbench.py；references/27 |
| 品牌包装 | 已确认的R5/R8资源、课程标题和音轨衔接 | references/11、16；kgxc profile |
| 最终验收 | 原图、规则覆盖、布局、实际编码、声音与观看记录 | scripts/release_checks.py及课程QA |

实际调用：本入口 → 导演方案与分镜 → 本地Aiden及真实时间轴 → 内部渲染工具 → 统一字幕和混音 → 课程验收。引擎是实现选择，不切换制作方法或重新询问音色。

新课默认与后续编辑调用：本入口 → 打开本包工作台 → workbench.json编辑数据 → 同一个CourseRenderer预览和逐帧导出 → 编码解码与字幕安全区检查 → 课程重新复核。工作台直接读写当前课程的独立副本及历史，不由另外两个Skill中转。

导入材料中的风格配方、示范场景和参数片段是可编辑技术材料，不是整课模板。画风、故事与构图按本课重做，不把示范角色、口播或章结构原样复制。旧供应商配置器、模型能力分档、三方向硬门、逐句配音和艺术片运动率门禁没有导入主流程。

第三方实现及许可证清单见libraries/provenance.json。原始Skill完整快照在本次迁移备份中；历史来源不参与当前制作规则。历史脚本路径可保留兼容别名，但别名不包含SKILL.md，不构成另一个Skill。

新课建档即生成scene-graph-v1工程及随课工作台，其他引擎使用seek-bridge-v1；national-world-v1只处理国补旧课。check_workbench.py与阶段/发布检查一起验证可编辑交付，缺失或陈旧记录会阻断新课通过。
