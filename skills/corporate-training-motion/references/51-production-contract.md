# 制作合同与实际放行

视频派工、恢复、小样扩展整课以及正式登记前读取本参考。合同把已经存在的要求交给实际制作端执行，不新增教学内容、用户确认或独立盲审。新课在视频制作前建立；旧冻结工程保留原约定，只在用户授权的相关返修范围纳入。个人选择、当前课程有效确认优先于通用默认；其他企业使用其自己的品牌，不自动套用酷果标识与话术。

## 一份合同贯穿派工与登记

`project/production-contract.json` 使用 `course-production-contract/1`，保存配置依据、制作偏好快照，以及 `requirements` 下的 `sfx`、`emphasis`、`direction`、`logo`、`chapters`、`bookends`。它必须能区分“本课要求什么”“实际接在哪里”“当前成品验证了什么”。只写启用开关、素材存在或计划完成，仍不是当前成片证据。

```sh
python3 SKILL_DIR/scripts/course_tools.py production-contract COURSE
python3 SKILL_DIR/scripts/course_tools.py production-contract COURSE --read
python3 SKILL_DIR/scripts/course_tools.py production-contract COURSE --activate
python3 SKILL_DIR/scripts/course_tools.py production-check COURSE --document WORKBENCH.json --video CURRENT.mp4 --purpose final
```

首条为当前制作建立或补齐合同；已冻结旧课只有在用户明确授权相关修订后才用 `--activate` 启用。底层入口为 `ensure(project, profile=None, activate=False)`；状态、摘要、交接和 `--read`／`--dry-run` 均只读，不因恢复自动迁移或写合同。检查使用当前工作台文档与实际视频。`production-check` 返回 `required`、`ready`、逐项 `checks`、具体 `errors` 和 `next_steps`；要求生效而未就绪时以非零状态退出。错误应说明缺的是实现、来源、帧范围还是当前证据，不能只写“质量不足”。`production_handoff.production_contract` 同时提供合同位置、适用配置、选择、六项要求、实现字段和下一步。

总导演派工时把相关要求、当前原句、对象及待补证据交给负责者；业务图示同时交代节点和关系代表什么、需要哪些正文标签。负责者交回实际路径、对象ID、时间范围和验证结果。只派“做动画”“加花字”而不传已选音源、品牌、导航等义务，会继续造成漏项。独立学员盲审仍只拿本阶段当前成品，不把这份制作台账、原件或标准答案附给审阅者。

## 六项怎样落到实际媒体

| 合同项 | 实现与核对 |
| --- | --- |
| `sfx` 原库音效 | 未另选时使用 `teaching-native-v1` 的叮、嘟咚，核对实际资产路径与SHA、事件、分轨、混音和最终编码音轨；旧音效从干净旁白或分轨中移除后重混，不能叠加叮声掩盖旧声。恢复已有冻结选择不自动换库。 |
| `emphasis` 重点强调 | 每次强调对应讲稿原句、教学用途、目标对象、起止帧与稳定阅读窗。弹词、marker、focus、underline、条件便签都可使用；不以某一种 `text.effect` 字段作为唯一判据。查看当前帧及连续片段，确认重点可读、条件否定保留且没有抢走操作焦点。 |
| `direction` 语义动作 | 逐段记录原句或口播锚点、对象起态、变化过程与结果，绑定实际对象和时间。讲核对要能看到被核对的信息及结果，讲回应要有受话人与回应。真实信息揭示、对比揭示或焦点转移可按 `change_kind` 登记，当前片段的观察须按 `scene_id` 给出变化前后证据；有目的读图可用 `purposeful-reading`，写明具体理由、`reading_window` 与当前片段实查，不机械要求每场移动。opacity次数、字幕更新、装饰运动或进度变化不能证明主体完成了演示，不能靠加切镜或循环动作凑数。 |
| `logo` 正文原标 | 酷果正文默认固定右上角的原版Logo，按可见边界布局并避让标题、人物、字幕；不能因画面密集自行隐藏或移到左侧。只有本课用户明确选择才改变位置或显隐。核对实际资产SHA、正文对象及编码帧；品牌头尾和独立封面沿用各自构图。 |
| `chapters` 分节导航 | 多节课程的进度应分辨已学、当前、未学，使用稳定章节ID、真实章节边界和源／显示时间映射；不能只画一条全局填充线。目录、独立小节标题页和正文导航共用章节表，正文区间外按导航规则隐藏；以当前编码逐节边界和正常播放核对。 |
| `bookends` 品牌头尾 | 酷果整课接入批准R5/R8的本课标题适配片段及原配乐，记录清单、拼接范围、资产和当前成片证据；出现Logo不等于已经使用头尾。口播优先当前已确认稿中的问候与末句，只说一次，不因旧固定示例自动重录、重复追加或裁断。 |

动画、阅读与强调的具体设计分别沿用[整课动作](32-full-course-motion.md)、[阅读节奏](45-reading-and-information-pacing.md)、[花字与音效](46-flower-text-and-native-sfx.md)；导航与Logo见[视觉规范](03-visual.md)，酷果头尾见[品牌细则](16-kgxc-bookends.md)。合同引用这些依据，不另建一套相互冲突的默认值。

正常改选分镜时，仅在原制作偏好绑定仍有效的前提下续接新的已选方案；原绑定已过期则继续阻断，不通过改选绕过核对。

编码和解码成功但合同未就绪时，技术任务可记为 `complete`，登记状态为 `registration_status=held`，明确“制作候选已生成，待核验，未登记”，保留候选供作者核对当前六项。此时不归档旧成功导出、不改变正式引用、不登记阶段或桌面交付；合同就绪后沿既有流程登记。编码失败和其他执行错误仍是失败。状态区分不新增模型审阅轮次，也不把候选当正式通过。

## 业务图示与文字标签

图示承担业务解释时，先让学员能从当前画面辨认“是什么、对应谁、怎样关联”，再安排移动与强调。团队分工、资料流转、对比、判断分支等重要节点或关系，不能只画相似的纸页、对话框、圆点和连线；标签应说明本句实际对象、作用或去向，保留必要条件与否定。字幕、页眉和导航负责别的阅读任务，不能代替正文图示说明。装饰性图标或已有清楚文字的对象不强制逐一另贴标签，也不把某门课的节点数或措辞固定为模板。

作者在分镜与派工阶段给出需要解释的图示及标签，连同原句、出现时机和可读区间一并实现。可在 `requirements.direction.scenes[]` 内登记 `diagram_labels`，每项结构如下，ID和帧须来自当前实际文档：

```json
{
  "diagram_node_ids": ["task-source", "task-recipient"],
  "label_node_ids": ["source-label", "recipient-label"],
  "meaning": "标明任务从哪里交给谁，图示位置与文字一一对应",
  "start_frame": 120,
  "end_frame": 240
}
```

登记后检查图示与标签节点真实存在、标签是非空的正文 `text`、场景一致，节点和父容器的声明可见状态及起止范围覆盖整个登记帧窗。字幕、标题、页眉、页脚及导航节点和其子节点不能冒充正文标签。每项图示和标签列表均须非空；不能用已声明的空绑定冒充落实。整个字段可省略，不按图标或装饰数量自动推断缺字；无需标签时由制作端说明当前图示为何已经可辨认。旧合同没有此字段时继续按既有六项检查，旧冻结课程不自动迁移。

程序只验证绑定结构、声明状态和时间覆盖，不验证实际动态遮挡、opacity动画或读图效果。制作端仍须从当前编码确认标签是否贴近相应对象、关系方向是否清楚、文字是否读得清、运动时是否遮挡，以及图示是否让学员理解正在讲的含义；字段齐全或文字非空不能证明这些判断。该检查属于 `direction` 的作者自检与固定清单验收，不另设第七项合同，也不增加一次独立盲审。

## 当前证据与停止条件

六类 `review` 保存实际检查者、范围、观察与对应工作台文档及视频SHA；观察定位到真实帧。音效还需核对当前编码音轨。原句、文档、素材、混音或视频改变后，重新核对受影响项，历史保留；不能复制旧哈希、编造“已看听”或用程序生成主观通过。制作端验证记录不是模型代替用户确认。

机器只核对已实现的结构、引用、时间与证据绑定；`ready` 不证明动画有教学意义、画面美观、花字效果合适或声音自然。动作和强调需查看同一当前视频的正常速度连续片段，声音按既定听审分工核对实际音轨；抽帧、ASR、波形、字段齐全均不冒称完整看听。无法验证时保留具体项及范围。

小样只检查实际选中范围内的片段，不能要求未呈现的未来片段提前达标。延期仅限内部中段小样的R5/R8，或完整计划中全部音效／强调事件确实在本次样段范围外的 `sfx`／`emphasis`；在该项 `pilot_defer` 或 `deferred_features.<key>` 保存理由、执行者、依据、当前文档与视频SHA及 `source_range`，并与当前视频的真实选段元数据核对。Logo、导航和当前片段的语义演绎不能延期。延期不算通过，整课 `final` 不接受延期；缺少适用品牌、导航、Logo、已启用项或当前证据时只保存候选，正式复制、登记与完成均须停在具体缺项。

本合同属于作者自检、执行交接和已有固定清单验收。每阶段当前选定方案仍只盲审一次，问题一次汇总；集中修复后核对固定问题与直接回归，一次自动修复和一次定向验收后仍有问题就保留卡点，不再开放式找茬或自动重启盲审。升级、哈希变化与恢复都不重置累计用量和审阅周期。
