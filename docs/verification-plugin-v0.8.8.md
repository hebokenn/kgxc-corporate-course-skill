# 插件0.8.8 / 核心仍6.7.7 制作端只读核验

本地开发插件更新，公共下载仍0.6.0/6.5.0。本次沿用核心6.7.7及其既有安装包，不重新安装全局课程Skill。

实际原生技能插件在 pre-step middleware 的后段生成技能清单。原制作会话曾发布清单后转入零工具只读QA，会产生精确的空清单替换消息；它并非 required-context。旧快照把该程序消息当作新对话，因而在接受独立盲审后停止制作端核验。

本版在本轮原制作agent的实际生成位置，仅剔除与隐藏的skill工具、非claimed原输入、精确来源及固定原生正文相符的空技能清单更新。来源kind本身不是白名单，其他middleware结果保持。真实用户、伪造清单及未知消息继续停止旧QA并保留输入；普通制作在QA结束后恢复技能可用性。

原系统指令、完整当前核对包、制作身份、模型通道、持久历史和只读工具保护保持。后台任务完成通知修复、独立学员成品隔离及后台质量/CAS检查沿用既有实现；已接受的同轮盲审可以按原有严格绑定恢复制作核验，不重复审阅未改成果。
