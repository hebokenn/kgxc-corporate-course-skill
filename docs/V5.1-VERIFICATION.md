# 5.1.0 历史技术验证记录

**后续实际观看已否决该版服务七步骤样段的动效节奏与讲解关联。下列技术结果为当时记录，不构成课程质量通过；不可照搬其慢动作编排。修正见[5.1.1](V5.1.1-VERIFICATION.md)。**

## 已验证

- 95项Skill回归检查通过，包含短入场冒充长讲解、虚构对象、只有字幕变化、删策略绕过、未实现的原生调用、小样绑定、候选完成闸门、切段/停留后的时间轴和角色资产边界。
- 48种动作通过实际Canvas像素、运行调用和正反向定位验证；实际改字、移动和换图影响画面。移除全部动作的负例被拒绝。清单见[机器结果](verification-motion-v5.1.json)。
- 同一工作台导出48动作无旁白技术图库：1920×1080、30fps、7200帧、240秒，全片解码通过；48项编码动作和48项运行回执均通过。图库用于验证能力，不能代替有声课程。
- 17类教学构图经过实际编译、预览和多时间点定位；构图参数进入普通可编辑节点。[实际画面](media/motion-modules-17.png)。
- 服务七步骤连续样段：41场景、9466帧、315.533秒，保留原已确认B2录音；96项主体动作与96项运行回执通过，未发现未解释的8秒长静止段，全片解码通过。样段实际调用19类动作，未机械塞入全部48种；不以动效数量冒充审美。
- 三位顾客设计已由用户确认，独立透明全身PNG已生成并校验；全身/半身在实际渲染器中共用同一原图，改变crop会改变实际画面。文件变更或调用未验证自然动作会被拒绝。

- 安装器7项回归通过；Codex和WorkBuddy安装文件逐项哈希一致。可编辑工程包CRC及独立解压恢复检查通过。另以可丢弃实际视听样本验证候选不自动完成、证据修改使完成失效、动效引擎修改使小样批准失效，见[流程验证](verification-final-gates-v5.1.json)。

## 仍需区分的验收

编码与回归通过属于技术验证；实际帧复核不等于全程人工听看，内部导演复核不等于用户最终认可。当前样段用户最终认可待完成。检查用于定位和阻止已知失败，不作“以后绝不出问题”的承诺。

新顾客的自然关节、走路、接物与逐音素口型尚未验证；设计板中的表情/姿态不代表连续动画生产素材已完成。原有M1绑定不能直接套用新角色。macOS arm64为已验证平台；本版没有新增WorkBuddy原生应用验收。

原冻结整课未被安装或新样段覆盖。默认B2配音、可选声音和克隆方法沿用5.0.3，本版更新保留用户配置。更多结果见[技术摘要](verification-v5.1.json)。
