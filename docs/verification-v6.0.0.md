## 行为验证

`skills/corporate-training-motion/scripts/test_continuity_pacing.py` 的23项测试覆盖：

- 阅读窗口可与连续讲解重叠；阅读不足保持失败，不修改原文档或自动插静音。即使静帧使阅读曝光通过，没有实际任务的额外静音仍被拒绝。
- 任务停顿的用途、给学员的提示、实际源帧窗口、总预算与字幕句子边界；品牌交接可跨紧邻场景，但不能用整场标签或重叠窗口豁免普通讲解。
- 真实WAV的连续声音、旁白中断、持续背景声、静音导航、缺少干声及时间轴不一致。混音持续有声也不能掩盖独立旁白的中断。
- 真实剪切既可移除不必要空白，也可能把两个短静音合成长静音；自然尾静音与新增停顿按实际总间隔计算。
- 局部样段采用与整课相同的显示时钟，实际MP4音轨解码与视频哈希绑定；登记时拒绝旧文档、旧声音、旧视频或不同导出范围的回执。
- 旧课只读检查不自动迁移，显式启用保存原文档并可重复运行；工程要求新契约时，删除策略不能绕过检查。

## 检查边界

默认2.5秒/-42dB是异常静音诊断起点，可按实际录音在允许范围调整并保留依据，不是每句停顿时长或普遍教学标准。干声必须来自真实配音链；检测器不负责识别人声身份、全部漏字、语义断句、音乐遮蔽或自然听感。最终编码检查与正常速度连续听看各自保留范围；实际试听、学员理解与用户认可不可用声学扫描、抽帧或技术模拟代填。
