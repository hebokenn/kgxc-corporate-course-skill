# 6.1.0 验证范围

本版把花字设计并入现有分镜与小样流程，按用户进一步明确要求内置选定的两款原库音效作为新默认，并公开已授权样片。技术验证、实际听看和用户最终认可分别记录。

## 真实文件与行为

新增 `test_native_sfx.py` 的6项测试通过：

- 默认目录实际只有两款独立音源、15个角色别名；两份原始MP3的SHA-256与选定源文件一致。实际WAV为48kHz立体声PCM16，峰值以采样帧计，起始空白保留。
- 未指定库的新计划实际选择teaching-native-v1，静音事件不混入声音；实际混音有音效且旁白源文件哈希保持，输出时长及声道正确。
- 使用左右不同的真实PCM夹具验证立体声没有被折成单声道，峰值对齐没有因双声道偏移；保留采样级定位。
- 不同局部人声能量下，同组采用共同较低增益；未分组的对照会分别避让。计划与混音均拒绝同组不同素材/设置，拒绝路径越界库ID。
- 旧natural-ui-v1仍有45个独立文件，显式旧库计划和enter别名继续可用；查看新默认不改写已有旧计划。

原恢复与音效回归7项通过，覆盖真实文件哈希、旧库稳定轮换、草稿实际时轴、旁白保持、绑定历史及可编辑包恢复。安装器和README/打包入口回归21项通过。共34项针对本次变化与发布的回归通过；没有将上一版全量结果冒充本轮全量测试。

`fe7a3cde07b6d1427127a568f6164d99e3b342f5639baa19faed7347b0a635d3`

它与已交付的原库音效版v2字节一致，未重新改变画面或旁白；保留原编码画面流，完整解码通过。该样片有22处花字、15次音效，三个平等选项同素材同增益，末尾三问及最后阅读留白无新增音效。已有技术记录的编码音频无削波，估算真峰值约-1.71dBFS。文件、源资产ID与哈希见[演示清单](media/flower-native/manifest.json)。这些参数仅说明这一样片，不能推成普遍课程密度或学习效果标准。

本版执行README末章检查、Skill文件/引用/哈希检查、ZIP CRC及完整清单核对、隔离安装和重复安装；项目、Codex与WorkBuddy副本逐文件核对。正式Release提供版本ZIP、SHA256SUMS与样片MP4；对公共实际下载的完整字节再次核对SHA-256，发布凭据保存在维护端审阅目录。安装配置、私人声音选择与已有课程继续保留。
