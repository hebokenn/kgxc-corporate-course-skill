# 插件0.8.0 / 核心6.7.0 本机验证

2026-11-07，macOS Apple芯片，实际安装的DSH 0.2.2-rc.1。公共发布仍为0.6.0/6.5.0；本轮记录本地开发、隔离测试和安装，未替换公共附件。测试素材全部为合成内容，没有把私人课程原件、稿件或视频用于开发夹具。

## 规则与实现

- 四个节点：逐字稿、全课分镜、实际有声小样、当前完整成片。审阅者从独立新会话启动，只收到本阶段成品；原件、目标答案、制作历史和旧评语不进入盲审包。
- 学员报告先复述内容、所讲、所得和疑问，再报告可定位的问题。审阅者无写入或修改权；当前绑定制作agent接收问题并承担来源核验与版本比较后的修改，保留原文件和差异，再由新agent复审。
- 分镜检查旁白推进与对象/信息/焦点的起态、过程、结果和节拍，排查长静止页面、装饰代替演示和阅读问题。小样和全片同时检查视觉、表演与视听，静态计划不能冒称实际演出。
- 独立只读监督agent核对实际开始、进展、失败、结束及用户指令；阻塞发现会持久暂停制作、停止实际导出，保留过程文件。没有原生隔离能力时不退回制作模型自审。
- 原生完成/空闲、恢复绑定与真实导出结束触发自动检查；不依赖浏览器页面轮询。四节点依次执行、当前输入去重，保留旧知情报告、累计预算和真实原话确认。分镜独立检查不新增一次强制人工点击审批。

## 已完成的验证

使用已配置的媒体Python运行 `python -B -m unittest discover -s tests -v`：153项全部通过。包含24项独立盲审/泄漏/身份/四阶段/监督/分镜修复回归，已有24项闭环回归，以及真实Chromium中的审阅界面和直接挂载编辑器、交付文件保留、确认与版本保护。

`node --test tests/test_*.mjs`：最终57项全部通过。首次全量有1项旧标签查找失败（界面已由“分镜预检”改为“分镜”），测试已按当前四节点名称更新，对应11项客户端测试通过；失败记录保留。

`node --test tests/test_native_review_contract.mjs` 会启动本机安装的DSH Electron，使用真实Cordis、Agent、Loop、Session、Tools和Prompt服务，但模型流是合成实现，**网络/真实模型调用为0**。断言不同真实agent/session、空白独立上下文、全局工具执行器和上下文注入被隔离、直接工具schema泄漏在推理前阻止。真实idle事件签名与提交顺序同时核对；此项证明本机原生API契约，不能冒称实际课程审阅。

`tests/test_production_hold.py` 4项通过：真实父子进程、leader退出但子进程拒绝TERM、拒绝停止非自有进程组，以及实际Workspace导出调度线程中设置持久hold后停止受控worker、保留partial/ledger、无成品登记。另用本机Playwright在无网络data页面核验进程清理，没有观察到自有活跃进程遗留。受控worker测试不代表视频视觉或声音验收。

初次全Python回归有11项交付轻量接口兼容错误，已修为仍读取同一canonical course-state的enabled判断；最小接口仍不能绕过DSH模式检测，153项最终全量通过。服务复用测试有fixture子进程ResourceWarning，结束清理由fixture的SIGTERM处理；该提示未冒称媒体失败或正式课程成功。

## 能力边界与安装结果
