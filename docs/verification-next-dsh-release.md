# 下一版 DSH：功能合并与发布验收

以 GitHub 正式版 DSH 0.9.3（KGXC v6.9.2）为基线。不要把个人 Mac 上的临时版本视为正式版。以下项目必须在**同一份正式候选包**里验收；缺项不得发布，不能拿别的版本的测试结果补齐。

| 必须保留或交付 | 在候选包上的验收 |
| --- | --- |
| 右上角检查更新、插件详情页入口 | 不打开课程也能检查；没有新版时明确显示已是最新版；不在课程设置保留重复入口。 |
| macOS 顶栏空白可拖窗 | 非全屏下实际拖动窗口并确认位置变化；课程下拉、新建课程、检查更新和对话开关仍能点击。 |
| 应用内下载与校验 | 有新版时可在 DSH 直接下载并看到进度；验证 SHA-256 和包清单；校验失败不安装。发布页只作备用。 |
| 退出后安装并重开 | 实测从旧候选更新到新候选。按确认后正常退出 DSH，助手安装并重开；Codex 不退出。课程忙或有未保存内容时不启动安装；失败有明确提示。 |
| GitHub 查询限流 | 模拟限流验证官方备用查询；备用也失败时明确提示限流，不误报已是最新版。 |
| 课程隔离和制课流程优化 | 用独立测试课程 A/B 切换，验证原对话与产物目录不改绑。小样保留音视频和验收证据，不打整课工程包；同一字节技术结果可复用，但不跳过讲稿、小样和成片确认；主体完成后仍单独处理花字和音效。 |

| 制课提速 | 逐字稿批准后允许并行；有实际头尾时，短片用同一工作台编码器检查接缝；不兼容时先修再做长导出；有证据的可分段流程按依赖复用。无新增人工问答，已有成品仍须完整解码和适用验收。 |

正式发布前：对照上一个公开 tag 审查候选源码；检查正式 ZIP 确实包含实现与更新助手；保留同一候选包的 SHA-256、测试结果和 macOS 实测记录。发布后再验证 GitHub 的公开下载和旧版检查。云端定向测试覆盖真实 FFmpeg 编码、合成音轨与短接缝，但并非桌面端到端测试。当前候选的 macOS 拖窗和真实升级全链路尚未验收。
