# 插件 0.3.0 本机验证 · 2026-11-05

适配版 0.3.0，内含本机核心 6.3.2；没有公开推送或发布。

- DSH 0.2.1-rc.3 原生窗口右侧显示同一宿主 Conversation，含模型、发送、停止与文件入口。
- 原生文件选择器加入合成文本文件，发送后模型实际读取，5秒后正确返回文件中的唯一测试口令；没有因此改课程或生成媒体。
- 右侧对话可以收起和展开，并通过分隔线调整宽度。
- 文件夹选择使用 DSH Electron 原生桥；AI 完成后同步内容使用受当前父窗口来源检查的消息，不覆盖尚未保存的文字。
- 20项相关回归通过，包括不因打开对话而启动模型、避免重复注入上下文、消息身份、选段替换、冲突保护、渲染冻结版本与原生接口访问边界。

基础改稿与实际画布、9.03秒视频导出的验证范围沿用 [0.2.0 记录](verification-plugin-v0.2.0.md)。当前业务课的整套改稿后重配音、分镜再生成，以及角色音色、调速和视觉风格编辑未据此宣称验收。
