# 5.4.0 验证范围

本版增加独立课程工艺流程。新工程默认 qualityPolicy 与 craft-contract，构图相似度只提示内容判断；最终复核绑定当前视频和文档，要求六项不同的实际审美观察、自然语气/标准普通话/干脆节奏/声线连贯的依据与真实听看范围，以及正文早中晚段的编码画面。

本地79项行为回归通过：11项新增工艺检查、19项动效与防降级、22项分支与批准、7项声音配置、6项新建工程、7项恢复与声音、7项安装器。另有11项真实媒体与批准路径断言通过。新增检查实际编码64×36测试视频并核对抽帧像素，验证预览或伪造图片不能替代编码证据，缺观察、旧哈希、遗漏中段、未解决问题及无理由的重复构图会保持待复核。旧工程没有显式采用新契约时保留原边界。

新建工程测试验证策略与标记真实写入；删除质量策略被拒绝。重复表单通过填写具体内容理由可以保留构图，不机械强制变化。检查器不计算美观分数，不验证一段文字是否真由人听过，也不保证不同AI的审美一致。64×36夹具仅验证技术行为，不作为课程美术样片。

Skill格式、Git差异、包内文件清单、ZIP CRC、隔离安装/重复安装与个人配置保留随本次发布验证。公开Release实际下载后另对照SHA256SUMS复核；发布回执与课程工程分开保存。权重与私有课程资料不进入安装包。

这些证据证明规则和版本边界生效，不等于任何完整课程已获用户最终验收。本版没有增加原生WorkBuddy独立制作全课的实际验收，也不把ASR或电平检查写成实际听校。
