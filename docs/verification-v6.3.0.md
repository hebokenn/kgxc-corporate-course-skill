# 6.3.0 验证范围

本版将情境演绎整理为具体编排方法、可复用二维人物实现、可改写设计输入及实际检查入口。先排人物意图、站位、关键动作和说听回应，再修连续形体与自然节拍；限制用于定位问题，不代替可运行做法。

## 实际验证

相关56项测试通过：新演绎5项、渲染选路与编辑/便携导出11项、导演交接7项、布局和原版胸标11项、原纹理人物实际预览1项、安装器7项、主页/打包入口14项。两个Skill结构检查、JavaScript语法检查和差异格式检查通过。

新演绎使用自造人物、无业务事实或真实对白的330帧技术场景，经实际工作台配置和托管画布加载。检查两个人物共660个实际渲染帧的关节、脚底、朝向、本人嘴形与绘制回执，其中行走114帧；支撑脚最大连续漂移约0.000056像素，处于亚像素计算容差内。自由行走腕部相对肩部的轨迹呈反向变化。检查工作台位置编辑、任意反向定位、隐藏同一人物对象及画面变化。

从同一实际生产画布截取起步附近28个连续帧，编码H.264后逐帧解码，比较前臂内部实心肤色像素。编码后无原有局部透明混色；同时核对实际绘制的两条逻辑臂各一次、前后层级及同一脸形裁剪回执。静帧组用于查看进场、停步、手势、转身中和回转后的整体形体，不能扩写为全片正常速度看听或自动审美判断。

输入检查与负例覆盖移动距离/比例/步频独立计算、转身时间不足时要求重新编排、全身行进方向、实心原标复制、已编辑资产保留及连续帧范围。原批准C01/S01的正面演出实际预览、编辑与反向定位继续通过；自定义原生工程保护、旧时间线保留与独立编辑包重开也通过。

可重跑对应脚本：`test_situational_acting.py`、`test_render_routes.py`、`test_direction_review.py`、`test_layout_and_uniform.py` 和 `test_character_performance.ActualWorkbenchPerformanceTests`。使用已准备好Playwright的媒体Python环境，普通系统Python未必含渲染依赖。

## 分发与适用范围

联合包为 `corporate-training-motion 6.3.0` 和 `elearning-course-design 2.0.3`。按[发布流程](RELEASING.md)核对清单、ZIP CRC、隔离首次/重复安装、项目与安装副本，以及公共下载完整字节SHA-256；分发结果以实际发布回执为准。

当前实现支持正面至左右侧面的新绘简化人物和已列出的动作，不支持背面、自由三维、复杂手指或任意接物；口型为本人对白能量开合，不是逐音素同步。技术场景通过不能证明任意新外观、极端站位或复杂持物都已通过。后续按实际课程粗演、细修、连续帧复查和正常速度观看；用户确认绑定其看到的实际版本。

原批准PNG、人物身份、已确认内容/美术和冻结课程保持原实现，更新安装不自动迁移。用户采用的本地演绎参考及其认可范围保存在课程内，私人故事、原件、声音、成片、人物名和本机路径均不进入公共仓库或安装包。本轮未重新验收WorkBuddy原生宿主的完整制课能力。
