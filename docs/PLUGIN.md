# DSH 课程工作台 0.9.6 · 核心 6.9.5

本版先完成 DSH，使用其原生会话、模型与附件功能，在当前会话工作区内制作课程。Codex 的适配、安装和验证暂缓；已有安装保持原样。

DSH课程以插件为统一用户入口。本地HTTP服务供插件内部的预览、编辑和导出使用；恢复DSH课程不会自动打开外部浏览器，旧独立工作台首页不再为这类课程展示第二套操作界面。独立Skill工程仍保留原有工作方式。插件热重载后，连接令牌失效会重新取得当前令牌并只重试一次同一请求，不重复创建审阅任务。

DSH直接挂载共用Studio界面，使用原有编辑、审阅和制作逻辑，不再依赖外层iframe。文件与视频按当前会话和课程授权读取；切换课程后旧资源入口失效。接口修改保留版本检查和连接令牌保护。实际小样与成片在插件中播放，逐字稿阶段先提供文字预览，修改后的画面和声音在小样阶段核验。

## 稳定版更新提醒

打开课程工作台时，插件在后台检查本仓库的 GitHub 最新稳定 Release，成功结果缓存 15 分钟；工作台保持打开会继续检查，失败约 2 分钟后重试。可从工作台顶部右上角「检查更新」跳过缓存。只有稳定 Release 中已经上传完整插件安装包，且插件版本确实高于当前安装版本，顶部才显示非阻塞提醒与“查看更新与下载”入口。检查不调用 AI，不发送课程资料、账号凭据或模型设置；只读取公开版本元数据。断网、GitHub 限流或数据异常不影响课程制作。

提醒不自动下载、执行安装或切换模型，也不关闭 DSH。“稍后”关闭当前版本提醒；之后出现更高版本可再次提醒。更新由用户自行决定：先保存当前工作、完整退出 DSH 及依赖插件的后端，再使用正式安装包更新并重启。缓存无法保存时本次应用运行仍采用内存缓存。

**已有旧版本需先手动升级一次**，之后才具备这项提醒能力。发布 GitHub 源码不会远程修改旧安装。默认仅检查稳定频道，预览版不会被主动推荐；当前安装若为 `0.9.0-rc.3`，旧稳定版 `0.8.x` 不会触发降级提醒，升级到 `0.9.1` 后，已经打开的工作台会继续检查；旧安装不获得新的检查频率或“检查更新”按钮。提醒本身不代表安装已完成。

在本版工作台，初次进入可选「上传资料，开始做课」或「描述课程，开始做课」。准备好的草稿需自己发送，AI 先产出可编辑大纲。左侧看当前作品、素材证据和确认记录；只有当前版本的原生问答实际打开时，才在右侧确认讲稿、小样和成片。已核实的素材位置可跳到当前视频；没有证据不会显示已出镜。「画面与配音」「后期与成片」分别浏览，不新增确认。

工作台顶部新增手动检查入口；继续支持稳定频道更新提醒，不自动安装；桌面更新路径、整课端到端验证和真实课程验收仍分别记录。[此前更新提醒验证](verification-release-v6.9.1.md)

## 从资料到交付

逐字稿确认后，配音可和分镜、素材准备并行；真实配音就绪后再对齐。小样先检查实际导出的包装接缝。正式制作先锁主体，再做花字与音效；复用经核对的录音与其他上游产物；工作台仍做必要的整课最终合成与检查。逐字稿、三段有声小样和成片仍只在右侧原生问答确认。

顶部固定显示 **资料 → 大纲 → 逐字稿 → 分镜 → 有声小样 → 整课交付**，每个阶段均可打开查看实际内容、确认状态和缺项。保存与确认分开，未生成的成果明确显示尚未生成；没有真实视频就不出现可播放成片。

正式 AI 审阅在逐字稿、全课分镜、实际有声小样和当前完整成片完成后分别运行。每阶段当前选定方案首次盲审创建新的DSH原生 agent，仅提供当前成品和绑定的只读访问；不继承制作会话，也不给原件、目标答案、其他阶段稿件或旧评语。审阅者先复述内容与所学，再报告有定位的问题和无法验证项，只挑毛病，不改稿、不提供替换或补丁。制作端另行核对原件和用户要求，收到问题后负责修改、保留差异、重新生成成品并按固定问题清单做定向验收，不再自动新开盲审。

**宿主核对实际请求，再绑定审阅报告。** 适合独立审阅或生产监督已经读完当前成品、却因手抄长版本编号错误而被拒绝的情况。宿主先核对本次注册调用、冻结输入、实际原生输入与零工具边界；只有报告确实未提供绑定字段时，才附上已核实的本次绑定。模型已提供的空值或错误绑定继续拒绝，真实成果变化仍由后端阻止。原模型正文与宿主封装分别留档，历史无效报告不追认。该检查是原生应用调用边界的证据，不声称捕获供应商最终 HTTP 请求。

分镜成品中已有的导航标题、目录帧窗和安全结构化显示状态会一起进入盲审，用于核对遮挡及阅读区间；原件、教学目标、资源路径、历史和自由制作说明仍被过滤，缺失状态不凭空补造。

分镜独立审阅重点检查旁白推进与画面起态、过程、结果及信息/焦点节拍的对应，识别长静止页面、字幕或装饰代替主体演示的问题。小样和全片检查教学理解、构图层级、文字可读性、人物表演与对白遮挡、风格、动作转场、花字和音画节奏。分镜只证明方案，小样只证明实际片段；抽帧和ASR不能冒充全片连续看听，关键项无法验证不放行。

当前模型只有文字与图片能力时，可由用户明确为本课选择“AI审文字与画面、用户听音轨”，记录原话与来源，保持原模型和计费来源。AI不声称听到声音或连续播放全片；按实际文字、帧与帧序列及编码证据检查，视觉和技术关键项无法验证继续阻断。工作台将AI范围内通过与待用户听审分别显示。用户实际完整播放当前全部小样/全片后，可在原有确认同一次动作中明确声明声音与音画配合无问题；声明精确绑定当前全部视频SHA和完整时段。选择分工本身不记听审通过，部分试听、旧SHA、关闭、沉默或制作代理自报均不通过。用户报告问题时保留反馈，由制作端修改后重验。

另开只读监督侦探 agent 记录实际生产开始、进展、失败与结束，核对用户要求传递、角色隔离、调用和版本证据；监督者不改课、不代替盲审、不批准阶段。报告绑定真实身份、工具权限和当前成品哈希，旧知情报告保留为历史。用户原有内容选择和制作委托保留真实原话，分镜新增AI检查不新增一次强制人工审批。原有逐字稿/小样/成片的用户确认、AI结论和桌面交付分别记录。

已核实原生 `turn/end` 因 Codex app-server 错误而结束时，保留 `failed/error` 原种类、错误和未知用量，通过正常事件追加同一制作身份、操作、step/turn、seq、时间与来源观察回证。在暂停且全部调用已结算后可继续原授权设置。工具错误、缺少终态、错误身份或序列、后续仍有进展的任务继续阻止；失败本身不表示已经结束。

普通过程事件逐条保存、每32条合批监督；原生请求头继续硬性核路由，普通shell job登记和结束不单独启动模型。起止、失败、用户插话及明确导出生命周期保持即时；原生update/export/write/edit/apply_patch工具在调用前、结果后同步等待监督。调用关联表只留有界name/kind元数据，已完成项删除，不能把表容量当本课调用次数限制。

原生重复工具提醒经真实post-execute生成点、原代理/调用、实际提醒策略与完整入队时序验证后作为程序上下文保留；尚未领取的历史提醒也由原生机制正常claim。不能只凭kind或文字前缀放行，不清除输入或改写日志。无法证明的并发历史、已消费重插、伪造和外来提醒，以及真人新指令继续停止旧任务。

制作进度按可信原生派发的课程、阶段与操作绑定刷新，普通用户伪造标头不能切换当前任务。旧失败折叠保留，仅在实际成功、较新版本、同一候选与目标正文均匹配时标记替代修订；新任务开始不等于旧错误已修。当前真实失败仍显示在当前任务，未知关联不会被删除。

执行监督的工具事件提供有界读取路径、工具请求声明的写入目标、可安全解析的简单脚本参数和真实结构化返回，包括已支持断言的实际布尔值、版本、备份数量、输出目录与文件哈希。桌面投影和核心清洗保持同一证据契约；只有类型而没有值时，不能推断核对已成立。复杂命令、正文和自由输出仅留哈希及结构元数据，未知证据不补造；请求路径和工具回证不等于宿主独立文件检测，也不证明全局没有其他写入。监督因缺少证据暂停后，应补齐证据并重新执行实际核验，不能仅清除暂停或追认旧报告。

用户要求可按既有ID补充适用阶段及content/execution职责，保留原文、证据和历史。制作端核验本阶段内容并提供逐字引用；监督保留完整要求、当前及后续义务，依据实际执行、已验证核验结果和拟执行动作检查。尚未发生的未来阶段与合法待修状态不能被误判成当前执行违规；真实越过阻断、证据不足或伪造完成继续阻塞。

用户可明确授权临时取消当前课的调用次数与返修轮数门槛，记录真实答复来源并保留旧上限及累计记录，恢复时继续按旧上限判断。该授权不改变新课默认值、独立来源核验、盲审隔离、质量门槛、原模型通道或另设的token预算。

制作核验保留原制作agent及持久历史，本次实际出站只发送完整当前核对包和原生系统指令，不重复回放旧核对包、工具返回或已失效报告；记录出站内容、绑定及排除历史的哈希和数量，保留原通道与取消信号。分镜包去掉该阶段不能编辑的工程副本及重复旧报告，完整必要原件、讲稿、方案、要求和本轮盲审发现继续保留，原包归档不覆盖。独立审阅已接受但制作调用失败时，仅最新失败轮、完整版本与身份绑定一致、无已提交制作报告/返修/在途调用才允许同轮恢复；使用新调用key，旧失败未知用量继续保留，之后仍须实际制作核验和监督。成果改动后按固定问题清单和直接回归做定向验收，不自动新开盲审。

每阶段当前选定方案只盲审一次，随后一次集中自动修复和一次定向验收；剩余问题保留卡点等待明确后续动作。原累计预算继续约束：每节点默认累计最多三轮返修、十二次模型调用，已有更紧预算继续约束；关闭、刷新、重开和规则升级不清零。制作端核对实际版本再改，保留旧稿与差异，不覆盖新的人工作业；无法完成的原声重制等保留具体卡点。当前模型与计费来源不变，不因失败切换供应商。每轮结束汇总已修复、未解决、无法验证、下一步与累计用量；关闭或稍后不批准。[详细规则](../skills/corporate-training-motion/references/50-independent-review.md) · [验证范围](verification-plugin-v0.8.3.md)

- **资料**：上传 PDF、Office 文档、文字或图片，逐页查看 PDF 原件、摘要、缺口、来源位置和各章内容取舍；单文件最大 25 MB。文件进入本课 inputs，不自动发送整盘资料。
- **大纲**：按章节卡片编辑标题、内容、推荐讲法与预计时长，可拖动或上下移动、增删、拆分及合并。章节和段落使用稳定身份；已有绑定稿件随章节移动，下游分镜按章节排序并标记过渡和时轴影响。未绑定旧稿保留并提示先绑定，避免按标题猜配。
- **逐字稿**：按章节手改，选句或选段让 DSH 模型给建议，比较后采用。自动保存人工稿，字数和估时随修改更新；插件即时预览文字，配音与实际画面在对应制作阶段处理。
- **分镜**：左侧教学片段、中间对应讲稿、至少三种画面方案和静态关键帧；右侧继续同一 DSH AI 对话。可采用本段或全部推荐方案，也能针对片段要求调整。静态示意不冒充动态小样。
- **有声小样**：显示本轮抽样、每段来源和方案、抽样原因、未覆盖类型；实际文件可播放，反馈定位到片段和播放时间。音色、语速以实际制作记录为准；未记录则明确提示核对。确认当前小样后才制作整课。
- **整课交付**：查看真实任务状态、进度、视频、基于各视频导出时冻结时轴的章节跳转、问题定位及当前文件。改一句话优先处理关联片段；改变受众或整体结构则标明更大的影响范围。

制作进度栏随页面保留：显示当前实际步骤、持续时间、最近执行结果和失败原因；等待模型回复时单独计时。配音等后台任务以真实结束记录为准，视频合成使用实际任务百分比。即使命令工具返回“非错误”，非零退出码也会显示失败；同一构建连续失败会累计提示，后续读取文件成功不会掩盖它，只有对应步骤通过后才清除。重启后从 DSH 原生事件恢复记录。只读取轻量状态，不反复刷新编辑区；后台隐藏时停止轮询。

当前画面、配音及分镜绑定已经就绪时，合成由程序直接执行，复用原有确认和全部后端检查，不增加一轮模型推理。未完成内容、人工草稿或针对性修改仍交给 AI。小样页可以重新合成当前版本；实际任务完成后更新结果，先前独立检查的问题保留在步骤明细，不覆盖新的成功状态。整课已完成登记后，切换到资料等其他页面也不会重新显示早先的检查失败；晚于本次交付的新失败仍会展示。

AI 对已经人工修改的讲稿或已选择的分镜提交差异建议，用户采用后写回；每次操作核对当前版本。撤销保留单调递增的编辑版本，遇到后续其他更新时拒绝直接覆盖。

后台命令完成通知属于本轮制作的工具上下文时，按原生工具调用、任务ID、原制作agent所有权和真实终态核实后继续取回结果。仅凭通知来源标签或文字前缀不能放行；其他agent、旧任务或伪造通知仍停止，真实用户新指令仍会打断并保留输入。该修复不替代当前成果的独立盲审或任何用户确认。

制作端只读核验转入零工具状态时，原生技能插件可能生成空清单替换通知。核验按实际生成seam、原制作身份、隐藏的skill工具及精确原生内容判断该程序更新，剔除该更新而不把整类source放行。真实用户和未核实来源仍停止并保留输入；结束后普通制作的技能可用性恢复。本版源码核心为6.8.2；历史审阅与同稿内容确认分别按实际绑定判断。

用户明确要求不审核配音时，可以记录本课的“制作端自动核查配音”分工。停止逐句试听和人工音轨审批，程序核对当前MP4字节的音轨、解码、时长及非静音；AI继续按实际能力审文字与画面。工作台明确区分免审批、自动检测和未执行连续听审，不写入用户听审通过。声音主观自然度与完整音画连续体验未获验证时如实保留，关键未知继续阻断正式放行，制作候选与原有内容/视觉确认分别保存。

分镜盲审按严格类型保留阅读窗口的帧坐标、入场与稳定范围，使审阅者能核对同轴规划；不向学员透露原件、目标答案或旧评语。边界变化不追认旧报告为当前通过，也不自动增加盲审轮次；保留历史并核对当前证据。

## 原始资料与讲稿对照

“原件对照”显示原始要点和出处、讲稿对应位置、取舍及理由，以及写稿新增内容、理由与依据。覆盖率以全部已登记独立业务要点为分母，舍弃仍计入；关键规则、条件和例外单列。未完整读取、未知或无法核验时不报告满覆盖；统计不证明AI已经完整拆出原件的全部信息，人工需核对拆点和语义覆盖。

“请AI生成／更新当前对照”只读取当前课来源及讲稿、保存对照报告，不改稿、方案或出片，不自动盲审。模型工具只有读取和保存能力，不能提交人工确认。用户可在原逐字稿确认动作中勾选明确声明，一次提交；关闭和预选不算。原件、稿件或报告变化后重新核对当前报告，历史回执保留。有来源却缺少当前人工对照确认时阻止逐字稿确认和下游制作；不改写历史内容确认。无原件时显示不适用，不填100%。

## 高质量输入与一次盲审

先把资料对应到岗位任务、情境、动作、判断依据和结果反馈，再写可直接口播的自然讲解。每段新增有效信息，去掉无作用同义复述；制作端在唯一一次盲审之前完成自检。酷果课程保留正文开场已确认的酷果星创问候语，程序检查问候遗漏、占位和明显重复，不用关键词冒称语义质量通过。

逐字稿、当前已选全课分镜、实际小样和全片各进行一次独立盲审。报告一次收齐可定位问题，合并为稳定清单；制作端集中修复，按当前版本证据定向验收。未选方案、未来阶段与个人风格偏好不扩大当前范围。修复、新哈希、重开或升级不自动创建另一盲审；未解决关键项继续保留卡点。已有盲审的历史阶段从原问题清单继续，累计预算与真实用户确认保留。明确改选新方案须单列真实用户授权。

## 会话、工程和资料

点击左侧已有课程会话，会恢复其课程工作台；普通对话顶部也有入口。点击“新建课程”进入独立空白会话，旧课程与旧稿保留。右侧可收起、调宽、选择资料文件夹和上传文件。

新工程默认建立在 **当前 DSH 会话工作区的 courses 子目录**。已有外置工程可以校验迁入；保留课程ID、原件、草稿与确认，旧路径只作定位别名，不复制或恢复已经清理的旧工程。活动导出时拒绝迁移。正常制课无需通过扩大整个电脑的权限来写工程。

## 主动选择

时长、受众或缺口需要用户决定时，AI 保存本轮待选事项并主动调用 DSH 原生 `ask_user_question`，居中显示选项。前题点选后进入下一题；最后一道单选题真实点选后直接发送本组答案。默认推荐、重开或恢复草稿不会发送，多选不采用末题单点发送。可填写自定义答案，收起后稍后处理；关闭或超时不代表批准。资料、大纲、逐字稿、分镜及小样等阶段都会检查属于当前阶段的未回答事项；若模型只保存问题未弹出，工作台会在模型空闲后主动补开一次，已有原生问题不重复打开，已回答或已委托决定的事项不再询问。

## 人物与制作偏好

分镜前主动展示“制作偏好”，可选择按本课设计新顾客、复用同风格可动顾客或无顾客出镜，并选花字密度和提示音。单项点击即保存，无需再次提交；关闭不代选，重开不丢答案。新增可写描述和上传参考图，先采用设计再用于制作。三种预设仅作起点，不是每门课的固定班底；按情境设计发型、衣服和配色，同课同人保持连续。

对白逐句核对双方在场与头部方向，转头在下一句开始前完成。柜台、手持物与人物按真实前后关系复核，不以装饰线穿过人物代替交接动作。真实转向、手势和走位直接参与动作验证。空闲工作台恢复时保持原端口，保留同源编辑恢复记录；点击当前阶段也可刷新外部完成的成果。

成片统一使用多部件可动人物，整张静态PNG人物不作为当前默认。预览缩略图由同一运行器生成。启用花字和原库音效时，校验当前导出中的真实文字/人物对象、音轨哈希、原库混音回执和非静音分轨；保存开关或数量声明不能替代实际接入。改偏好后提示更新关联分镜和音视频，不用旧视频的完成状态冒充新成果。

整课页只展开当前任务，历史尝试折叠保留；旧失败标明后续通过的版本，诊断可继续查看。新失败不会被旧成功遮盖，失败即使已完成全部帧也不显示为成功100%。

## 制作合同与图示文字

新视频及已授权的相关返修共用 `production-contract.json`，把原库音效、重点强调、语义动作、正文原Logo、分节导航、R5/R8头尾及待补证据交给实际制作端。恢复读取当前合同，正式登记和桌面复制前检查当前文档、原资产、实际混音和编码视频；计划、启用开关或旧版本通过均不能代替当前成片。酷果正文默认固定右上原版Logo，问候和末句优先本课已确认稿，保持完整且一次；沿用已有自然语速，不靠慢放或加静默凑时长。

团队、流程、比较等图解中的重要业务对象与关系要有能辨认的正文标签，按旁白解释节点及去向，不能只显示空白凭证、对话框和连线。制作端在设计与派工时为需要解释的图示登记图示节点、文字节点、含义和共同可见窗，再从当前编码核对文字与指向是否清楚。装饰图标不强制逐一加字；字幕、页眉和导航不代替正文说明。登记后的结构检查拒绝缺失、空白、错场或跨窗标签，但不证明文字语义正确或学员已理解。

正常改选分镜只在原制作偏好绑定仍有效时更新到新的已选方案；原绑定已过期时继续阻断，旧确认仍保留。编码和解码成功但六项合同未核验就绪时，内部任务技术完成，登记状态仍为 `held`，界面明确候选已生成、待核验且未登记，并保留当前候选供作者检查。此时不归档旧成功导出、不改变正式引用、不登记阶段、不复制桌面成品；当前合同就绪后沿原登记流程继续。编码失败与其他错误仍报告失败，不用待核验掩盖执行失败。

这属于作者自检、制作交接和固定问题的定向验收，沿用每阶段当前方案一次盲审，不增加一个标签审阅阶段。旧冻结课程不因插件更新自动修改或重新生成。[合同命令、字段与验证边界](../skills/corporate-training-motion/references/51-production-contract.md)

## 安装

[下载完整 DSH 插件包](https://github.com/hebokenn/kgxc-corporate-course-skill/releases/download/v6.8.2/kgxc-course-plugin-v0.8.24.zip)，解压后在插件目录运行（完整退出 DSH 后安装，再重新打开）：

```sh
python3 scripts/install_plugin.py --host dsh
```

也可双击“安装制课插件.command”。重新打开 DSH 后在左侧选“课程工作台”。保留宿主既有账号、权限、媒体和其他插件配置；不自动下载模型。当前仅验证 macOS Apple 芯片上的本机 DSH。

升级前先完整退出 DSH，再运行安装器，完成后重新启动。安装器检测到桌面宿主仍在运行时会停止，避免前后端资源错配；仅刷新页面或停用再启用插件不能代替本次升级的完整重启。审阅调用随插件停止而取消，已消费用量和失败记录保留，重开不重放。课程暂停状态持久化，暂停期间不会新发检查或修改。

## 交付与清理

制作期间及交付后，原件、逐字稿、分镜、小样、配音、缓存和旧版本默认保留在课程工程内。保存成品只校验复制当前视频、字幕和封面到桌面 `ai 制课/<课程名称>/`，不删除过程文件。

保存后显示实际文件夹路径，并可点击“打开保存文件夹”在 Finder 查看本次视频、字幕和封面；打开前核对本课交付记录与文件字节。保存与重复保存均去除交付目录及三份文件继承的macOS隐藏标记，保留其他文件属性，防止文件已写入却在Finder不可见。成品回看页和文件处理弹窗均有入口。

交付后主动显示文件处理弹窗：**保留全部（推荐）／稍后提醒／查看并选择清理**。关闭窗口不删除；明确要求保留的课程记录选择，不重复弹窗阻塞制作。保留或稍后提醒无需扫描清理资格。只有选择“查看并选择清理”才扫描本课文件，版本快照目录计入历史版本；清理检查有缺项时仍可保留，且不把已保存成品显示成保存失败。清理前列出本课文件数量、大小和分类，只有再次明确点击“确认清理所列过程文件”才执行；文件或版本改变会拒绝旧确认并要求重新查看范围。独立原件在实际清理前核验另存，桌面成品保留。“全程不用确认”是制作委托，不构成删除授权。

保留工程时可以继续查看和编辑，也可稍后重新打开文件处理选择；经明确确认清理后，历史会话通过小型交付记录播放、跳转章节和下载当前成品，不恢复已清理工程。
