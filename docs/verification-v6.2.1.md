# 6.2.1 验证范围

本版是教学与制作指引修订，联合教学模块为2.0.3。新增原件覆盖与取舍方法，讲清业务目标、岗位现场、完整语义剪接及封面独立设计；不新增自动判断业务正确、审美或学习效果的程序。

## 指引核对

逐项对照经确认的九类经验：原件查漏，业务目标与条件，现场管理，精简及主选修取舍，对象动作与花字，品牌及配色，独立封面，局部修订及剪接，实际看听范围。通用方法分别进入教学设计、品牌、封面、音画衔接和花字参考，并从相应入口可发现。

课程具体金额、目标比例、页数、片段数量和内部调参不固化为通用标准。原件没有的指标不补造；主课与选修的数量由本课任务决定。普通封面制作不增加固定审批；有效确认、已有录音和历史课程不因安装更新自动改写。

## 验证与边界

两个Skill入口的结构检查通过；README检查确认“版本更新”仍为最后一个内容章节。既有安装器7项及主页/打包入口14项测试通过，共21项，覆盖干净与重复安装、篡改检测、配置和课程保留、升级回滚，以及主页错误时禁止创建或覆盖发布包。本轮未用关键词匹配测试冒充教学效果验证。

另按发布流程检查包文件清单与ZIP CRC，进行隔离及重复安装，并核对项目与安装副本。正式发布时对公共下载的完整字节校验SHA-256，与SHA256SUMS及本次构建一致。分发文件的实际结果保存在发布回执，未完成项目不宣称通过。

本地封面修订采用用户明确确认的独立草稿，原版Logo及课程名称保留，工程来源、交付副本和播放器接线以哈希核对。静态封面替换阶段保持视频和字幕原字节；用户进一步要求嵌入视频后，检查实际编码首帧和过渡，核对原音频数据包及时间戳、字幕、章节与总时长不变。私人课程原件、讲稿、成片及这些封面不进入公共Skill仓库或安装包。

静态封面检查及用户对封面方向的确认，不等于整课正常速度完整试听或最终视频认可。本版没有重新验证WorkBuddy原生宿主制作完整课程，也不把安装副本检查写成宿主业务验收。
