# 插件 0.8.22 / 核心 6.8.0：高质量输入与一次盲审

本轮仅完善插件及本地合成夹具，不启动真实课程制作、配音、渲染或模型审阅。公共发布仍保持原正式版本。

## 当前行为

- 逐字稿、当前已选分镜、实际小样、全片每阶段对当前方案只独立盲审一次。分镜实际输入只投影已选方案，未选或歧义选择拒绝送审。
- 问题冻结为稳定清单；一次集中自动修复后做一次当前证据定向验收，未解决则保留卡点，不自动再次盲审或继续修复循环。
- 修改哈希、继续、重开、升级及次数不限不重置已消耗盲审；明确用户新选实质方案才另记周期，保留历史与累计用量。
- 制作端前置准备任务/情境/动作/依据/示范/反馈，通读检查自然口语与信息增量；程序只检查正文、已配置问候和占位，提示精确重复及疑似套话，不冒称语义通过。
- 酷果新课模板包含品牌问候；已有已确认原句优先。界面区分首次盲审发现与当前清单验收，不将已修复问题当成当前未解决。
