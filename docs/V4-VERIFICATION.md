# 4.0.0 更新验收

日期：2026-10-20。范围：本机 macOS Apple 芯片、WorkBuddy 5.8.3、原有媒体运行环境。本更新包是本地交付，未发布新的远端版本。3.4.0的历史环境记录保留在 [VERIFICATION.md](VERIFICATION.md)。

1. 前置教学设计：保留电子课程设计模块1.0.0的方法，接入统一入口。原始素材先转成工作任务、可观察目标、结构取舍、示范、练习和反馈，选择后展开完整课件稿。
2. 持续工作台：新课及恢复默认打开；设计、选择、阶段审阅与视频编辑共用工程。保存原说明、时间、产物指纹和变更历史；修改关联内容后提示重新审阅。
3. WorkBuddy适配与交付：联合安装两个模块；兼容本地解释器配置、已有目录创建、127.0.0.1直连、后台服务恢复；保留旧技能备份与既有个人运行配置。

## 使用

解压后双击“安装或更新.command”。默认更新本机Codex与WorkBuddy的两个Skill并保留媒体配置。新机器用 `./install.sh --agent both` 准备完整环境。已有自改Skill须显式 `--replace-skill`，安装器先备份再替换。

在WorkBuddy新对话中调用 `corporate-training-motion`。继续工程时给课程路径，默认从已保存的设计、选择和阶段恢复。交互确认有六个节点：素材、结构、完整课件稿、视觉声音、代表样段、整课候选；用户可明确合并或委托，既有授权按范围复用。
