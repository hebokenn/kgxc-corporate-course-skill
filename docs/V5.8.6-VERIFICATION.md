# 5.8.6 推荐声音与可移植参考

本版把用户明确授权公开的 didi / pipi 配对参考纳入 Skill 源码和安装包，完整干净安装推荐男声 didi、女声 pipi，未指定性别时使用 didi。它们使用同一固定版本 Base 模型，个人选择、同名私有参考和原课程录音继续保留。

## 实际检查范围

- 23 项声音选择与声音库回归覆盖干净默认、无私有库的男女声选择、参考哈希、个人同名优先且损坏时报错、预设与模型变体、配置备份、不修改随包参考、中文命名和已有录音保护。
- 21 项仓库回归覆盖安装器与 README 打包门槛；错误主页在清单及 ZIP 写入前停止，旧包和校验文件保留。统一新课脚本另查默认 didi、字幕、素材入口及覆盖保护。
- 使用空个人配置与空声音库，复用本机已安装的固定版本 Base 运行环境，从包内参考实际合成同一通用文案的两段试听。didi 约 15.62 秒，pipi 约 20.72 秒，交付倍率均为 1.0。WAV / MP3 全量解码通过，本地 ASR 检查两段完整内容及结尾，识别字形与同音字不作为权威发音判断。
- 安装包检查 ZIP CRC、Skill / bundle 清单及 SHA-256；隔离安装、重复安装、安装后的默认解析和实际安装配音探针分别核对。公共发布另核对正式 tag、公开 Release、附件及完整下载字节的哈希。
- 本机项目、Codex 与 WorkBuddy 安装副本同步；原私有默认、参考录音与配置保持原文件哈希。公共素材只包含已授权的两套参考与通用试听，不带原课程、来源参考片或机器路径。

本次是已有 macOS Apple 芯片主机上的源码、隔离安装和真实音频生成验证，复用了已安装媒体环境与模型缓存；不等于在全新电脑重做系统依赖下载。没有据此宣称本次完成原生 WorkBuddy 的整门新课、人工全程试听或用户对新试听的最终认可。
