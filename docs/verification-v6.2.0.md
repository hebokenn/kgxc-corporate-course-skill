# 6.2.0 验证范围

本版将新课选色落实为可恢复的数据与实际编译行为。未指定时从六套合格色板随机抽取，默认候选不含绿色；用户指定与已确认画面优先。选色与有声片段抽样分别保存，各自恢复不重抽。

## 选色与实际构图

新增 `test_course_palette.py` 的15项行为测试通过，覆盖：

- 真实随机种子与筛选后候选池可重现同一结果；重复读取和恢复不调用随机源、不重写记录。
- 新建分镜流程课程自动保存一套色板，未据此确认分镜或小样；旧工程与既有实际配色确认保留。
- 用户指定品牌色优先；禁用色不能被忽略，没有候选时不退回默认绿；不合格文字对比被拒绝。
- 换色须记录原因，旧色板保留；改色更新分镜并使受影响确认过期，保留已确认逐字稿与片段表现选择；当前分镜JSON与审阅页展示同一色板，推荐方案仍未自动选择。
- 17类教学构图全部经过色板绑定检查；24种视觉方案分别用明、暗色板编译，保留原素材身份及配方目录。
- 手写灰绿卡片、错误画布底色与不匹配绑定会报错；真实产品本色只豁免对应对象，不豁免旁边的教学卡片。
- 真实CLI保存并复用记录。

渲染与选路11项回归包含明、暗色板的真实Canvas像素检查：画布与强调区域读取的RGB必须等于已保存色值；同时检查动效过程、正反向定位、编辑、独立打包恢复与实际短视频导出。像素夹具不代表课程已完成美观、听看或用户验收。

## 范围边界

本次没有重做旧课程、重录旁白或修改已确认小样。颜色检查覆盖声明的教学画布、文字、容器、线条及显式动效颜色；位图内容、特殊原生实现和正常速度观感仍须检查实际画面。安装副本检查不等于重新在WorkBuddy原生宿主完成一门课。技术结果与课程质量、真实学员理解和用户最终认可分别记录。
