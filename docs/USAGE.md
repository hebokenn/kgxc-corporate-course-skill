# 酷果星创企业课程 Skill 使用指南

[返回首页](../README.md) · [查看真实效果](../README.md#实际效果) · [安装与依赖](DEPENDENCIES.md)

日常制作通过Codex对话和本地工作台完成。企业课程入口为 `$corporate-training-motion`，已包含导演方法、网页/插画实现、品牌包装和编辑工作台，无需另装两个制作Skill。

## 1. 安装后先确认环境

按[首页一键安装](../README.md#快速开始)完成准备。终端运行：

```bash
"$HOME/.local/bin/kgxc-course" doctor
```

完整准备就绪应显示：

```text
编辑导出环境：就绪；Aiden 原速配音：就绪
```

Codex本人登录；Blender本人安装。模型、媒体环境由完整安装器自动准备，默认无需TTS API Key。仅复制Skill文件不等于环境已经齐全。当前完整验证范围为Codex本地执行、macOS Apple芯片。

## 2. 整理资料并第一次调用

把Word、PDF、制度正文、原图和系统截图放在一个资料目录，在Codex打开可写课程工作目录。告诉Codex受众、目标和原文位置，把下面的课程名换成实际名称：

```text
请使用 $corporate-training-motion 为酷果星创制作《收货核对流程》内部课程。
受众是新入职门店同事，原始资料见我提供的文件，以原文为准，不新增业务规则。
先整理规则台账和逐字稿交我确认，再设计分镜和制作有声样片。
默认使用Aiden原速，字幕单行无标点，画面标题按内容保留。
根据内容选择实物、截图、图表、流程或泳道，不强制整课大地图。
完整课程使用已批准R5/R8片头片尾，替换本课名称并保留固定问候与结束语。
每门新课从建档开始接入工作台，最终交付MP4、SRT和可编辑工程ZIP。
```

Codex会建立 `inputs/`、`project/`、`delivery/`、`packages/`。先锁定原文条件、例外和口径，再安排画面，避免仅凭标题补造业务规则。

## 3. 按阶段确认

| 阶段 | 你重点看什么 | 确认后进入 |
|---|---|---|
| 规则与逐字稿 | 原文条件、数字、例外、讲解顺序与术语是否准确 | 导演设计与分镜 |
| 导演与分镜 | 场景和动作能否讲清知识，标题与画面是否合适 | 真实配音和有声样片 |
| 有声样片 | Aiden语速、发音、画面动作、字幕可读性与接缝 | 整课制作 |
| 最终课程 | 完整内容、实际编码画面、音频、字幕、片头片尾与可编辑交付 | 最终交付 |

已有明确确认沿用，不重复要求选音色。技术检查不代填负责人意见；完整课仍需实际观看和听校。

## 4. 打开工作台

可以直接对Codex说：

```text
打开这门课的内容编辑工作台，给我实际本地网址。
```

已安装快捷入口时，也可将路径替换成实际课程目录：

```bash
"$HOME/.local/bin/kgxc-course" serve "$HOME/Documents/酷果课程试用"
```

启动后打开打印出的本地网址，不使用作者电脑的固定端口。工作台默认监听本机127.0.0.1，关闭终端中的服务后需重新启动。每门新课都应有自己的可编辑数据和实际画布。

## 5. 常用编辑方法

| 想修改什么 | 操作 | 会发生什么 |
|---|---|---|
| 字幕错字、时间 | 在“字幕”选择片段，改正文、起止秒数，再应用 | 实时更新字幕；不会自动重录原配音 |
| 停留太短或太长 | 在“画面”选择场景，调整句尾停留秒数并应用 | 在句尾插入或调整静音与画面冻结，后续时间同步变化，原声不变速 |
| 裁掉空白或冗长片段 | 打开“剪辑”，输入起止秒数，或Shift拖动波形选区；先试听，再裁剪 | 画面、声音、字幕同步前移；保留原始录音和素材 |
| 画面标题、要点、位置 | 在“画面”选择登记对象，修改文字或水平/垂直位移并应用 | 当前画布中的对应对象变化；应检查新位置是否遮挡 |
| 图片 | 在“素材”选择登记素材并上传PNG/JPEG/WebP | 替换该素材的所有引用，原素材仍保留，可恢复 |
| 撤回操作 | 使用撤销/重做，或从“历史”恢复为草稿 | 可以回到之前的编辑状态，恢复后按需保存 |
| 保存和导出 | 点击“保存工程”，再“导出”；选择整课或所需区间 | 导出MP4、SRT和可编辑ZIP，预览与导出使用同一个渲染器 |

![通过起止时间和波形选择裁剪区间](media/workbench-cut.png)

直接减少“新增停留”适合缩短人为添加的空等；剪辑选区适合移除某段实际时间。剪到讲话时核对剩余句意、字幕和接缝。改字幕不会改变录音；改讲解内容时请让Codex同步更新配音与时间轴。

## 6. 后续修改可直接这样说

**修改业务讲解：**

```text
根据我补充的原文修订第二节，先列出需要改变的讲稿内容。
确认后用同一Aiden原速更新配音、字幕和工作台，不改其他已确认小节。
```

**只改视觉：**

```text
这一版只调整画面和动效，复用已确认原音。
保持字幕单行无标点，修改后从当前工作台版本重新导出并检查。
```

**继续编辑和导出：**

```text
打开这门课的工作台，保留原始素材和录音。
把当前已保存版本导出为整课MP4、SRT和可编辑工程包，报告实际检查范围。
```

## 7. 拿到哪些文件

- `inputs/`：原始资料。
- `project/`：实际源码、素材、音轨、编辑数据和检查记录。
- `delivery/`：当前视频、字幕及对应记录。
- `packages/`：可编辑课程ZIP。

ZIP解压后可继续打开内置工作台。换电脑时仍需完成媒体运行环境安装，不能把ZIP理解为无需环境的独立应用。已有课程不因安装/更新Skill自动迁移或重新渲染。

约9秒的[技术样例MP4](https://raw.githubusercontent.com/hebokenn/kgxc-corporate-course-skill/main/docs/media/course-demo.mp4)适合了解实际画面、Aiden配音与字幕；完整课使用的R5/R8包装另见[首页效果](../README.md#实际效果)。
