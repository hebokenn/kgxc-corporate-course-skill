# 5.8.4 验证范围

本版修复本地命名声音的CLI调用，增加中文ID支持。只包含通用代码、说明与合成测试，不包含真实用户声音、参考片或私人课程。

- 18项声音测试覆盖实际CLI解析、中文ID、参考哈希、默认男女声、运行配置保留、路径形式拒绝，以及公共预设和参考克隆兼容。
- 7项安装器测试覆盖安装、重复运行、已有修改保留与替换备份等行为；另从本版完整ZIP隔离安装并执行声音测试，核对版本与清单，重复安装和已有私有配置保留。
- 发布后核对源代码与tag、公开下载的全部安装包字节和SHA256SUMS。具体哈希见Release资产。
- 合成夹具只验证调用与文件行为，不证明真实克隆相似度、发音、情感、完整课程品质或宿主原生使用已验收。真实试听与用户选择保留在各自本地工程。

不重配已冻结课程，不分发私人声音，也不把用户特定语速或音调写成所有课程的全局参数。
