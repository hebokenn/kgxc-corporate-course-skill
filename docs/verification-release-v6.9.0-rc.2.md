- 新增34项回归全部通过。包含具体段落/句子/出现次数、脚本与音频摘要、布局和编号、逐条与同时呈现、前条保留、音效引用、双篇CLI、共同白板节拍、字幕/章节/声音依赖和每课片头预算。拒绝比例估时、排序、max钳制及含糊短语触发。
- 实际合成H.264检查出现前、出现时及稳定帧。正确末态但第三条提前的反例仍拒绝；实际片头像素静止测量和伪造帧率反例单列。拼接SAR元数据变化时，抽帧与帧摘要不再因过滤器重初始化重复计数。
- 原执行链95项、动作19项、README16项、review-host36项回归通过。review-host使用本地合成提供者，不是外部模型真实推理。
- 调色15项通过。历史调色失效测试的合成分镜确认缺少现行执行链前置，首次失败记录保留；该项仅在测试内明确隔离发布前置，以检查换色后的确认失效。生产门禁未放宽，执行链负例独立保留。

## 能力边界

编号编码检查依赖当前工程登记的节点、词时、编号组及真实区域/颜色探针，不能自动理解任意外部画布，像素存在性不等于OCR或语义正确。未登记的图形须制作端逐项核对。多个相关课使用明确传入的spec/video一起检查，不扫描或改动无关工程。

片头预算来自本课用户选择，统计整个包装、标题停留及正文前等待；没有全局1.5秒或2秒模板。变更包装后应实际重算字幕、章节、音效与时间线，绑定当前依赖。依赖摘要失效检查不代替判断语音是否已重复降速。

技术抽帧、合成回归及编码音效证据不代表完整连续看听、声音自然度或用户接受，不新增同阶段盲审。没有活动DSH/Codex宿主热升级、真实课程连续视听或真实学员效果验证。上一预览版的宿主权限隔离及连续看听限制仍适用。

## 打包与安装

使用正式build_release.py与build_plugin.py构建当前版本ZIP和SHA256清单；从套件ZIP解压后执行隔离skill-only安装，并逐项核对安装清单。插件ZIP校验完整压缩数据、版本及Skill清单。结果以对应GitHub Release附件和本地发布回执为准，不将隔离安装称作活动应用已升级。公开发布后另下载完整附件复核字节，与本地清单一致才登记发布完成。
