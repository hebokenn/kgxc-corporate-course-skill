# v5.0.2 验证记录

本版将既有动效库接入实际制作，增加恢复时的制作交接与新的动作音效。联合包包含 corporate-training-motion 5.0.2 和 elearning-course-design 2.0.0。5.0.0 的原生宿主记录保留在 [V5-VERIFICATION.md](V5-VERIFICATION.md)。

## 本版检查

- 71 项技能自动回归通过，包含渲染选路、保留编辑后升级、恢复交接、课件与完成分支保护、21 个真实音效、稳定轮换、原旁白保护、混音绑定、新课配置前混音与可编辑工程恢复。
- 5 组既有独立脚本检查、7 项安装行为测试通过；两个 Skill 的格式、引用与资源清单检查通过。
- 新版 ZIP 的 CRC 与完整文件哈希清单通过；隔离安装两个模块、重复更新及 5.0.0 到 5.0.2 升级通过，已有配置和原版备份保留。公开发布后另行下载并核对安装包哈希与安装入口。
- 已从 WorkBuddy 实际安装目录运行 resume，返回制作接续与新音效默认；保存的文档和确认记录保持不变。
- 已从 WorkBuddy 实际安装目录调用导出工具完成 6 秒、1920×1080、30fps、180 帧的 H.264/AAC 有声技术片，全量解码通过。逐字、遮罩、模糊、渐变、描线、镜头及时间定位确定性已用实际画面核对。技术片不含正式课程旁白。
- 新音效按 7 类动作提供 21 个本地 WAV，计划保存实际素材哈希，混音单独输出。音量、波形和编码检查不等于用户听感认可。

## 验证边界

5.0.2 没有向原生 WorkBuddy 对话发送创作任务。安装目录中的命令、恢复和导出已验证；宿主模型是否在真实聊天主动完成新增自动选路，尚未验收。没有强制触发真实自动上下文压缩，也未以短技术片代表完整课程的艺术质量或学习效果。

本版未重新执行完整媒体环境或 Aiden 模型的首次下载；运行时和锁定依赖未变，使用已有 macOS Apple 芯片环境。隔离安装指新目标目录，不能据此称为全新操作系统验收。

安装更新不会自动迁移、改写或重渲既有课程；已完成工程不会因恢复自动重制。业务内容、风格与小样的用户确认和主观听看分别报告。
