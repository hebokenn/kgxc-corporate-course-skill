# 插件 0.4.0 本机验证

2026-11-05。本机适配版本 0.4.0，课程核心源码 6.3.3，教学设计模块 2.0.4。未发布公共版本。

## 会话与课程

- DSH Electron 实际点击“将PDF课程转为视频课程”历史会话，自动显示对应的 既有课程编辑器及原对话；与旧测试课程分离。
- 实际点击“新建课程”进入独立新会话，左侧“开始一门新课程”，不载入全局最近课；返回旧会话可恢复对应课程。
- 完整退出并重开 DSH 后，当前课程会话可恢复相同课程；首次升级从本条会话的成功制课工具结果迁移关联。
- 回归覆盖逐会话持久关联、全局最近课程不介入、新建时保留旧稿、失败及无关工具不建立关联、晚到响应不填回已离开的编辑区。

## 人工选择

- 当前 DSH 实际模型已通过 kgxc_course_update 保存 D-01/D-02/D-03 为 open，再调用原生 ask_user_question；可选择时长、受众和缺口处理，不代选。
- 实际桌面验证第三题选项能够切换，并恢复测试前选项，未提交真实业务选择。旧界面最后一题停留且反馈很弱，容易误以为点击失效。
- 原生选项现居中显示，复用同一待回答请求、宿主回答草稿与返回前题的能力，不复制一套确认队列。
- 按用户最新要求，最后一道单选题的真实点选直接触发宿主发送整组答案。真实客户端事件回归验证：默认推荐、重开、前题自动跳转、过期卡片、多选和已锁定提交均不会误发。
- 使用宿主 sessionStatus 的 pendingInteraction 自动展开收起的对话；该行为有客户端回归覆盖。
- 自定义文字仍可通过宿主原有提交/回车发送；关闭或超时不是批准。没有替用户提交当前业务答案，也未将当前选择测试记为课程结构确认。

## 检查范围

27 项针对性检查通过：11 项 Python、16 项 Node；另检查 JS 语法、Skill 元数据、包内清单与主页结构。Python 原有测试退出时出现 detached subprocess 的 ResourceWarning；测试最终通过，临时夹具的清理按测试原有流程完成。

Codex 检查通过本地插件发现、MCP 握手、九个共用工具发现、实际环境调用及合成课程恢复；未启动 Codex 模型生成。上述结果不代表整课成片交付或用户内容验收。
