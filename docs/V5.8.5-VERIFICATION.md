# 5.8.5 工作台性能与生命周期

完成课程由现有工作流判断，不把候选、技术检查或自动关机等同于用户认可。完成后无导出且空闲120秒，服务端退出；未完成课程继续保持服务。状态和任务轮询不续期。

导出排队、渲染、编码、打包、结果JSON落盘，已进入的HTTP请求和下载流均受到保护。未保存编辑和播放通过页面会话保留服务，窗口离开或租期过期后解除。自动关闭不会删除任何课程文件；原启动器可重新打开课程。

## 验证范围

- 9项生命周期回归覆盖120秒默认阈值、持续轮询、请求与关闭竞态、导出各阶段及最终落盘、未完成和已修改课程、未保存编辑、播放与会话过期、真实服务进程退出、端口释放和原启动器重新打开。
- 6项性能缓存回归覆盖并发共用一次复核、文件编辑/替换/缺失、证据更新、失败重试和有界缓存。
- 相关工作台与工作流回归、安装器测试、隔离安装和重复安装，以及源码、包清单与公共下载哈希分别验证。

状态复核缓存只保存摘要与检查结果，不缓存解码像素。首次检查仍执行完整验证，后续未变化输入才复用结果。生命周期轮询只查元数据；文件变化后重新检查完成状态。

服务生命周期、页面活动和缓存实现与既有渲染指纹分开，保持冻结课程的原确认算法。更新不重新渲染旧课，不发布私人课程、声音库或本机配置。这些技术验证不构成原生WorkBuddy完整制课、人类听看或用户最终验收证明。
