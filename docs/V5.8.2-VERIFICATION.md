# v5.8.2：内容导演方法与复核入口

本版补齐自动接续入口与通用制作方法，保留v5.8.1已验证的人物、对象状态和批量编码证据门槛。它不包含某门私人课程的逐字稿、视频、声音、分镜生成器或固定时间表。

## 已执行的本地验证

- `test_direction_review.py`：7项。不同任务保留各自口播、用途、对象和动作时刻；按实际变换、表演键、显隐与补充峰值取帧；裁剪后源帧不指向别的画面，保留停留边界；CLI不覆盖工程或旧证据；必要的重复构图只作为内容判断线索；完成课程与课件分支不启动视频制作。
- 其中一个真实渲染用例使用公开合成的排班调整、任务接收和稳定比较，180帧、30fps。使用当前原生画布，正反向定位一致，实际MP4全量解码和两项对象隔离编码证据通过。动作时长、固定阅读和有目的的镜头变化来自该用例；没有读取私人课程工程。
- `test_character_performance.py`：6项。两角色自己的标定、反应/视线、编辑和反向定位仍有效；全镜头变化、目标文字更名、错误状态或整场观察不能冒充主体动作；900帧批量对象证明保持通过。
- `test_new_course_workbench.py` 与 `test_continue_and_sound.py` 检查新建、制作接续、审批不变、实际编辑器打包及声音链路的兼容性。当前变更不新增用户审批，不改变已完成课程。

代码与实际运行证据用于确认入口、内容绑定、取证和渲染契约。合成静音用例不是有声培训成品，也不证明任意课程的语义表达、审美、听感或学习效果已获认可。制作端仍依据当前逐字稿选表现，按实际编码画面和正常速度观察复核，用户最终验收单独记录。
