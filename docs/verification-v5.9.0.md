# 5.9.0 验证范围

本版验证全课分镜、逐段选择、三段分层随机抽样和真实生产导出的连接。测试通过不等于真实课程的审美、听感或用户验收通过。

## 流程与覆盖

新增12项行为测试，覆盖：

- 旧工程不自动迁移；授权迁移保留已确认教学方案、逐字稿和旧分镜历史。
- 全部口播与练习原文按顺序出现一次；漏段、重复、摘要替代原文、少于三种备选或重复方案被拒绝。
- 导入文件中自填的选择不构成批准；未明确选择和确认分镜时不能抽样或开始生产。
- 随机抽取三个不同完整片段，种子与候选池可复现；恢复不重抽，重抽须有原因，篡改计划不能通过。
- 场景使用真实sourceStartFrame/sourceEndFrame；支持停留映射，裁剪掉源帧、导出漏段、场景空档或选错方案均被拦截。
- 默认新工程configure保留分镜绑定；裁掉一个样段时不启动导出线程。
- 用真实合成音视频验证登记，缺少当前生产源码与画布回执时拒绝。冻结小样可与整课扩展并存；更换已抽样素材会使批准失效，新增素材不无故撤销有效确认。合成媒体仅用于测试登记，未冒称实际课程效果。

整包回归覆盖229项用例。首次在系统Python中发现缺少媒体依赖，改用现有配置的媒体运行环境；其中13项渲染用例受macOS沙箱进程通信限制未能启动Chromium，在相同源码下重跑相关20项渲染测试后全部通过。其余216项通过，未通过修改断言或跳过用例消除失败。安装器7项和README发布门槛14项另行通过。

## 现有实课验证

在用户已授权的本地课程执行全量分镜：50段口播与练习原文，按完整教学情节组织为43个片段，共129种画面备选，覆盖全部6个单元与3组练习反馈。问候、过渡和虚构声明并入相邻教学情节，不单独作为只有引子的样段。情境出现人物、概念不用人物为本课已知偏好，不写成所有课程的通则。

主工程保留既有outline/script确认，43个分镜全部待用户选择，未登记任何新小样认可。隔离副本使用qa-operator模拟选择与确认，固定种子抽到情境、概念、过程各一段；恢复后抽样一致。未抽到的练习类型与其他高风险段仍被明确列为生产检查范围。缺一段、选错方案、移除源帧、开头场景空档和导出裁掉末帧的反例均被拒绝。

课程原件、逐字稿、实际分镜、QA副本和页面截图留在私人工程，未进入公共源码或安装包。工作台实际页面已检查三方案展示、推荐、待选状态和禁用的提前抽样按钮；文字分镜尚未获得新用户认可，未生成新课程动态小样。
