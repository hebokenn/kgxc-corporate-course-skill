## 代码适配的原因与影响

| 变更 | 原因 | 对制作结果的影响 |
|---|---|---|
| 安装器、用户配置发现、独立环境 | 旧环境只存在于作者电脑 | 制作内容规则保持；路径和运行器改为本机自动生成，已有个人值保留 |
| 默认Chromium可配置 | 新同事未必安装作者使用的Chrome | 同一个工作台渲染器；需仍检查实际编码和布局，不能把“浏览器能开”当成成片检查 |
| 内置R5/R8背景、字体、声音、跟踪及标题合成 | 旧换课名链路依赖包外工程 | 保留批准的动作、品牌和配乐，只换课名；新编码可能有正常像素/压缩差异。新标题和声音接缝仍需审核 |
| 专用KGXC建档模板 | 此仓库用于企业内部课程 | 默认带企业品牌、固定问候/结束语；空逐字稿不能被当作已满足固定结束语的完整课 |
| Qwen3自动部署与生成检查 | 用户要求安装即准备配音 | 权重在用户数据目录，不进入仓库；Aiden自然速度，不修改旧课录音 |

## 当前边界与后续方法

- 已验证主机：macOS27.2 arm64、Node25.8.1、FFmpeg9.0.2、Blender5.2.2 LTS、CodexCLI0.163.0-alpha.10.2；隔离Python3.12.13及依赖锁定版本。它不是全新Mac虚拟机；系统ffmpeg/Node和已登录Codex由主机提供。
- Homebrew缺失/权限首次安装、Homebrew自动安装ffmpeg/Node、全新系统首次登录Codex和手动安装Blender，未在此主机上移除软件重做。后续在干净Apple芯片Mac按README安装，逐项核对doctor和demo；失败时保留错误，不能标为全自动完成。
- Windows、Linux、IntelMac、其他AI工具、其他系统/Node/Blender版本、纯网页/云端、移动端浏览器均未验证。完整自动安装在非macOS arm64明确提示范围。
- 真实业务资料的完整长课、负责人审核、真实新配音全程听校、全片字幕/品牌遮挡检查，按Skill规定逐课完成；短技术样例不是业务验收。
- Azure等可选外部服务、Remotion静音原型、修改三维几何后完整重渲，不在本次安装验收范围。

## 可复现入口

```bash
python3 -m unittest discover -s tests -v
bash -n install.sh
python3 scripts/build_release.py
"$HOME/.local/bin/kgxc-course" doctor
"$HOME/.local/bin/kgxc-course" demo "$HOME/Documents/酷果课程验证" --verify
```

`tests/smoke_installed.py`用于独立临时样例的实际浏览器编辑测试，需要传入已安装Skill、全新r0样例、报告路径，并使用安装器生成的媒体Python和配置；它会修改这个测试样例，请勿对正式课程运行。

本地结构化结果见 `verification.json`；公开仓库、固定tag、Release附件和远端安装入口的发布后复核记录在GitHub Release说明。所有测试临时课程、模型、用户配置和原始日志均留在仓库外，不把开发者路径或真实认证值打包。
