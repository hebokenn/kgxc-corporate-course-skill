正文样例实际导出检查包含全片解码、正反向seek和登记文字/素材绑定；品牌视频亦已全解码。截图采集前后的保存工程哈希一致。测试不替代业务审核、全课听校或实体设备验收。

品牌预览带原配乐；固定欢迎语、结束语由当课配音加入，并按完整课程流程检查。标题、动作与声音的具体制作规范仍以Skill说明为准。所有品牌与第三方素材沿用[原用途及许可说明](../../THIRD_PARTY_NOTICES.md)。

这些文件是仓库首页的说明素材；本次只更新文档与展示，不替换v3.4.0安装包、不改变已有课程。
