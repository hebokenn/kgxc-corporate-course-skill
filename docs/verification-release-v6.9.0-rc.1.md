test_execution_contract_release.py使用隔离检查器验证聚合、拒绝覆盖参数及复制竞争；不能当成真实媒体放行。test_delivery.py的13项替换授权检查并stub Finder，只验证复制/哈希/保留。实际Finder和正式门禁须另有真实回执。
