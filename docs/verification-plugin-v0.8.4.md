# 插件0.8.4 / 核心6.7.4 制作核验恢复

本地开发更新，公共下载仍0.6.0/6.5.0。独立审阅接受后，制作调用的失败不应迫使未改变的成品重复盲审；长会话也不应在每轮核验重复发送全部历史核对包。

## 本轮变更

- 原制作agent的单次核验使用当前完整私人核对包和原生系统指令；保留身份、持久历史、prepared handle、取消信号和模型配置，仅本次实际出站排除旧消息与工具历史。结束后恢复普通制作行为，并记录真实投影审计。
- 分镜制作包去除阶段不可编辑的document/native副本与重复prior报告；必要原件、逐字稿、当前方案、分镜、要求与确认、制作指令和本轮独立发现完整保留。当前方案保留全部units、content_points与source_refs，仅将重复来源汇编及旧修订历史留在原文件，并提供档案路径、SHA和字段字节数。旧包路径及实际字节哈希归档，新尝试不覆盖。
- 显式同轮制作恢复要求最新失败、同版本及完整绑定、真实已接受盲审、无制作报告/修复/在途预约。新调用使用新key并累计；原失败、未知用量与历史保留。成果修改后仍需新独立审阅。
