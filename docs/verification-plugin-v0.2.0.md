# 插件 0.2.0 本机验证 · 2026-11-05

本次只做本机开发与安装，未推送或公开发布。适配版 0.2.0 内含本机核心 6.3.1；公共稳定版继续保留 6.3.0。

## 已取得的实际证据

- DSH 0.2.1-rc.3 Electron 原生窗口：显示“逐字稿编辑”，人工界面移除新建、环境检查、路径和工具状态表单。
- 合成逐字稿可以手工修改并自动保存。选择一段，调用现有已配置 DSH 官方模型，展示实际返回的建议，再局部替换。已核对前后两段保持原样；没有写入正式逐字稿、补填课程确认或自动编码。
- 有真实场景的兼容技术夹具：改字后使用相同 CourseRenderer 在实际画布中更新字幕；原正式文件不因预览改动而修改。未制作场景的课程明确显示逐字稿预览与等待画面。
- 点击渲染后，兼容技术夹具实际生成 9.033333 秒、1920×1080、H.264 / AAC 视频及字幕；任务 `548217bcb600` 实际完成。此夹具使用预生成配音，覆盖编辑器到既有导出器的接入，不能代表当前分镜流程、全课制作或业务验收。
- 19 项相关回归：6 项编辑草稿状态、5 项共用服务、4 项文字选择及真实绑定、2 项宿主模型/渲染消息契约、2 项 DSH 注册与 HTTP 访问边界。
- 前一轮真实模型已通过原生工具保存教学方案；未选择视频分支时实际导出被拒绝，课程 revision 仍为 2，确认记录未被补填。

## 实现边界

本版完成基础逐字稿编辑与预览。三栏关键帧及风格编辑、角色音色、语速与时间线联动、低成本新配音段落试看，是后续讨论方案，未作为本版完成能力展示。

修改稿件后的整套配音/场景重建仍交给本课 DSH 对话复用既有制课流程；本次没有用真实业务课程完成这一全流程验收。请求固定点击时稿件，有未确认前置或宿主制作失败会显示失败原因，不把请求登记当作编码完成。独立网页与 Codex 共用编辑草稿；Codex 的网页行内模型改写尚未接入。
