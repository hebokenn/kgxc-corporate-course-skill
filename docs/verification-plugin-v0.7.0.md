## 已实现行为

- 复用既有课程阶段和真实产物，三个正式节点分别审阅实际逐字稿、实际小样和当前成片；分镜是制作预检。
- 验收项来自当前原件、学习目标、要求与偏好。关键项没有通过时不能普通确认或正式交付；空表不能作为完整示例。
- 持久化请求和调用预留、绑定正文/素材/实际媒体指纹、局部精确修复与新成果复核、旧版和差异保留、人工并发修改保护。
- 每轮汇总、待确认与重新打开、保留输入、继续审阅、按意见修复与复审、累计耗时和实际可得token用量。
- 每节点默认三轮累计自动返修、十二次模型调用；已配置token预算也受约束；两轮无改善要求根因分析，追加范围另记。
- 插件停止会取消进行中的模型流；持久暂停可阻止新检查和返修。已配置token预算但旧调用用量未返回时停止新调用，防止未知用量绕过预算。
- 升级器阻止在DSH桌面宿主运行时原地替换插件，要求完整退出、安装后冷启动；仅刷新不作为升级方式。
- 模型与计费通道绑定实际DSH选择；失败不降级到其他供应商。AI通过、用户确认和正式桌面保存分开。

## 能力限制

当前DSH的Codex适配器只接收文本和图片，不提供连续视频/音频语义理解。实际帧会解码并在可用时通过宿主附件提交；音轨与时长用ffprobe核对，字幕读取实际文件。完整连续视听与末尾听审仍记为无法验证并阻塞，不以抽帧、静音机器播放、波形或ASR冒称完成听审。

自动修改器支持讲稿精确替换和已有画面/人物/字幕的局部修复，再走既有真实导出。需要重做配音、改核心目标或缺少制作能力时，保留实际失败原因，不会用旧声音和旧报告冒充修复完成。用户主动更改核心目标需先更新方案和本课依据；不会由审阅模型自行改变。
