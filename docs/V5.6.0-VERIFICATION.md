# 5.6.0 验证范围

新增逐场视觉证据门槛、可见轮廓测量工具，以及连接动画结束后默认清除移动标记的行为。新工程默认启用visualHygieneRequired，契约文件保护该要求；已有冻结工程按原规则，明确采用时再启用。

新增7项回归覆盖：透明画布留白与实际轮廓的差别、隐藏主体的差分测量、单轴对齐、两个真实注册动效在开始/运动/结束阶段的圆点行为、显式保留状态标记和禁用标记、全部场景覆盖、当前编码像素、旧视频哈希、预览图/错帧/越界证据、缺少观察和未解决问题、旧工程与删除契约。测试使用合成图形，仅证明技术行为，不充当美术或真实课程观看证明。

课程Skill的149项回归通过。打包与发布另外核对文件清单、ZIP CRC、安装/升级与个人配置保留、公开源码版本、实际公开下载包的SHA256。发布包不含私人课程、配音、业务资料或用户截图。

逐场检查器核对证据范围、哈希和真实像素；它不能自动判断人物视觉重心、连线是否符合业务语义、运动是否自然或课程是否好看。制作端仍需查看完整场景与相关动态、排查复用组件，并分别记录技术检查、实际观看范围和用户最终验收。
