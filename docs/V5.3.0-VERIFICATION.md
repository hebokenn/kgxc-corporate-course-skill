# 5.3.0 验证范围

本版将三种视觉风格与逐段内容表现分开。新导演方案声明 `style_scope=visual`，风格卡保存配色、字体、图形材质和画面气质，构图、动作与镜头在内容分镜中组合。未声明该字段的旧工程保留原确认算法，安装不会自动改写它们。

本地66项行为回归通过：22项分支与批准检查、19项实际动效与防降级检查、11项恢复检查、7项继续制作与声音检查、7项安装器检查。新增用例验证：视觉方案无需motion选项；只给动作说明而无视觉属性会被拒绝；扩展分镜与动作不使视觉选择或冻结小样批准失效，但完整导出的当前制作指纹会改变；配音、字幕、美术规范、实际渲染源码或冻结MP4变化仍会失效。

在隔离的收货核对技术夹具中，实际打开本地工作台，看到三份相同教学内容的视觉预览，并核对风格卡显示配色、字体、图形材质和画面气质。推荐未自动选择，内容分镜仍单独显示实际动作。此夹具不是用户课程，也没有代填业务批准。

Skill格式、JavaScript语法和Git差异检查通过。发布包通过现有文件清单、ZIP CRC、隔离安装与重复安装流程核对；公开下载另以SHA256SUMS复验，结果保存于发布回执。保留已有工具与声音配置，不上传私有课程资料。

这些检查证明新规则与版本边界实际生效，不自动评价课程美术、动作自然度、完整课程观看效果或用户接受程度。本次没有新增原生WorkBuddy自主制作验收，也不将规则更新等同于任何课程已经重制完成。
